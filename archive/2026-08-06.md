1. [Towards Physics of Multimodal Pretraining: Knowledge Flow, Modality Synergy, Early Unification, and Recipes](https://arxiv.org/abs/2608.05000v1)
   - 分类：Multimodal Pretraining / MoE
   - 研究价值：值得精读
   - 关联：为构建原生统一的多模态基础模型提供实验性指导，直接影响多模态生成和理解模型的设计选择。
   - 痛点：多模态预训练的架构、数据和训练策略仍然依赖大量经验调参，缺乏对模态如何在统一模型中协同或竞争的基础理解。本领域常见“晚期对齐”或“分阶段训练”方法，但少有受控实验刻画语言、视觉理解和视觉生成之间知识流动的因果影响。而数据规模、复杂度和tokenizer设计等因素又可能改变结论，导致无法形成可复现的预训练配方，严重阻碍多模态基础模型的可扩展设计。
   - 方法：采用大规模受控实验方法，在合成数据和多个真实数据集上，系统变化模态组合、架构共享程度、归一化策略和训练时序，测量跨模态迁移方向和强度。通过解耦语言、视觉理解与视觉生成任务，揭示知识流的不对称规律。并用早期统一阶段设计测试，最终将归纳的规律浓缩为高效训练配方，在13.5B MoE模型、2T token规模上验证其普适性。
   - 结果：研究确立四个核心发现：(1)跨模态知识流具有明显的非对称性，语言→视觉的迁移与视觉→语言不同；(2)数据复杂度决定模态协同还是竞争，共享attention+归一化+模态特定FFN能增强协同；(3)从第一层开始联合训练多模态明显优于后期对齐或顺序训练，且避免了“vision laziness”现象，即模型过度依赖语言先验而忽视视觉；(4)基于上述规律导出的食谱仅用5%算力即可复现强生成性能，并在多组13.5B MoE模型上取得一致验证。

2. [DreamWAM: Beyond RGB Future Prediction for World Action Models](https://arxiv.org/abs/2608.04996v1)
   - 分类：World Models / Robotics
   - 研究价值：值得精读
   - 关联：针对世界行动模型的表示学习，提出了超越RGB的结构化未来状态预测，与视频预测、机器人操作和基础世界模型研究高度相关。
   - 痛点：当前世界行动模型（WAMs）大多只在RGB像素空间中预测未来，导致动作相关的状态变化与纹理、光照、背景等无关变化纠缠在一起。这使模型难以学到真正通用的因果表征，在环境扰动或分布偏移下动作成功率显著下降。需要一种能够显式预测与动作相关的未来状态结构化表示的方法，而又不增加部署时的计算负担。
   - 方法：提出DreamWAM，将未来状态建模为外观、运动、几何与语义四种互补视图。训练时，RGB和运动在联合隐空间中去噪，使用轻量门控残差分支预测深度和语义；VideoDiT和ActionDiT之间共享attention，使动作分支能学习这些未来状态预测。推理时将额外分支全部关闭，仅用RGB输入，因此部署成本与RGB-only基线一致。
   - 结果：在LIBERO基准上，DreamWAM将无卷动和联合视频-动作推理的成功率分别从97.30%和98.00%提高到98.40%和98.90%；在LIBERO-Plus扰动下提升更显著，从51.36%到63.44%、从69.16%到75.47%。真实世界操作中，在光照、背景和物体布局变化下平均成功率74.4%，超过Fast-WAM-Joint的55.6%，表明结构化未来状态预测是提升动作鲁棒性的关键。

3. [Objects as Audio-Visual Modal Sound Fields](https://arxiv.org/abs/2608.05145v1)
   - 分类：3D Scenes / Audio-Visual Learning
   - 研究价值：值得精读
   - 关联：将听觉模态引入到物体级3D重建中，与多模态感知和场景理解形成互补，为生成式AI在交互场景中的应用提供新思路。
   - 痛点：3D重建通常只关注几何和外观，完全没有考虑物体在受到物理打击时产生的声音，而这些撞击声携带了材质、刚度、内部结构等丰富信息。现有的撞击声合成要么依赖昂贵的物理仿真，要么需要大规模对应数据，因此难以用于真实物体的快速重建和交互应用。如何在少量录音下构建物体级声音场并与视觉模型统一表示，是一个开放问题。
   - 方法：提出AV-MSF，基于3D Gaussian Splatting并融入密集3D视觉特征作为几何感知先验，利用视觉几何来约束声场空间。把每个物体的撞击声场表示为紧凑的、具有物理意义的模态参数（如频率、阻尼、振幅），只需几个冲击声录音即可估计这些参数，从而实现少量录音下的声音场重建，并且在渲染时通过物理参数驱动即可输出与撞击位置相关的声波。
   - 结果：在真实世界两个数据集上，AV-MSF取得了最先进的撞击声渲染效果，比物理模拟和数据驱动基线都更好，并同时支持接触点定位和物体声音编辑等下游应用。该方法说明视觉结构先验能大量减少声场重建所需数据，为未来多模态物体表征提供新思路。

**主要痛点**
- 扩散模型推理成本高，动态推理的停止准则仍需改进。
- 多模态统一预训练缺乏理论指导，模态协同/竞争机制不明确。
- 世界模型和动作模型过度依赖RGB，忽略几何、语义等动作相关信息。
- 3D重建缺少声学、触觉等物理模态，限制多模态交互。
- 生成模型在医学等安全关键领域缺乏可解释性和跨生成器鲁棒性。

**方法趋势**
- 前缀价值学习用于动态提前停止扩散去噪。
- 多模态预训练中进行成体系对照实验，推导最优架构和训练配方。
- 在联合潜空间预测外观+运动+几何+语义的结构化未来状态。
- 将物理声音场参数化为模态参数，并与3D视觉特征融合。
- 通过离散码本和层级注意力机制来增强可解释性和跨域泛化。

**结果信号**
- 扩散策略迭代次数减少2.7倍，性能保持甚至提升。
- 13.5B MoE级别的多模态预训练仅用5%算力达到强生成性能。
- 世界行动模型在鲁棒性上提升明显，真实操作成功率提高约18%。
- 音频-视觉声音场重建的渲染效果超越物理模拟和数据驱动基线。
- 医学深度伪造检测跨生成器AUC/F1提升9+，无需像素标注。

1. [The Loss Does Not See the Basis, but Adam Does](https://arxiv.org/abs/2608.05136v1)
   - 分类：Optimization Theory, Matrix Factorization
   - 研究价值：值得精读
   - 关联：揭示优化器选择对低秩隐式偏置的根本影响，直接关系高效训练与最终泛化。
   - 痛点：训练因子化模型（如低秩矩阵分解）时，优化器对隐式正则化的影响至关重要，但 Adam 与梯度下降的行为差异及其原因尚不清楚。实践中 Adam 虽收敛快，却往往得到更高秩的解，在欠定任务上泛化更差，而梯度下降天然偏向低秩解。此前缺乏理论框架解释这一现象，导致优化器选择只能依赖经验。该论文解决了这一基本机制问题，为高效训练提供理论指导。
   - 方法：论文提出规范对称性分析框架，将优化器分为规范等变（梯度下降、动量、共享标量 Adam、Muon、Shampoo）和非等变（Adam、RMSProp）。通过结构定理证明无记忆等变规则等价于 Gram 决定的前置条件，利用传递定理将梯度流的路径偏置推广到共享标量流。并通过构建从逐坐标到共享标量的单参数族，隔离各向异性为关键原因，从理论上解释 Adam 如何破坏低秩偏置。
   - 结果：在欠定矩阵感知上，Adam 恢复误差显著高于等变优化器；共享标量 Adam 单调恢复低秩偏置。在低采样密度下梯度下降比 Adam 在 held-out 误差上低 43-44%，且有效秩更低。在 Transformer 中，Adam 使等价初始化的 $W_Q^T W_K$ 相对距离相差 56%，表明优化器选择从根本上决定解的结构和泛化。

2. [Toward Skill-Native LLMs: Skill Entropy for Benchmarking and Training Long-Horizon Reasoning](https://arxiv.org/abs/2608.05139v1)
   - 分类：Long-Horizon Reasoning, Skill Transfer
   - 研究价值：值得精读
   - 关联：提出技能熵作为可复用训练信号，显著提升长程跨技能推理能力，对高效训练有直接价值。
   - 痛点：当前 LLM 在长程推理时需要在不同技能间切换（如先数学推导再规划），但现有基准通常只评估单一技能，缺乏对技能切换难度的度量。因此模型在跨技能任务上表现不佳，且缺少针对性训练信号来强化这种能力。该论文填补了评估与训练两个方面的空白，为提升长程推理效率提供新工具。
   - 方法：定义 Skill Entropy（技能熵）量化从一种技能切换到另一种技能的难度，并基于 558 个技能构建跨技能长程推理基准 Skill^2-Bench。提出 Skill-Entropy RL 框架，模型在每一步不仅预测答案，还预测所用技能，奖励结合步骤正确性与模型预测技能序列和黄金技能序列的对齐程度，从而引导模型学会正确的技能切换顺序。
   - 结果：在 Skill^2-Bench 上，Qwen3-4B-Instruct 从 34.4% 提升至 68.4%，Qwen3-1.7B 从 14.6% 提升至 40.1%，均优于强基线。该训练信号同样适用于 OpenR1-Math 等外部数据，说明技能熵是可迁移的通用训练信号。评估 8 个前沿模型和 4 个开源模型，发现高熵任务性能下降，证实了技能切换间隙的存在。

3. [Towards Physics of Multimodal Pretraining: Knowledge Flow, Modality Synergy, Early Unification, and Recipes](https://arxiv.org/abs/2608.05000v1)
   - 分类：Multimodal Pretraining, Training Recipes
   - 研究价值：值得精读
   - 关联：系统揭示多模态预训练的内在机制，并给出可操作的高效训练配方，对降低预训练成本至关重要。
   - 痛点：统一多模态预训练设计空间巨大，但缺乏对模态间知识迁移、协同与竞争机制的深刻理解。实践者常凭直觉设置架构和训练顺序，导致计算浪费和性能次优，例如延迟集成会引发“视觉懒惰”。该论文旨在提供受控实验证据，建立多模态预训练的“物理原则”，以提升训练效率和效果。
   - 方法：通过合成和真实大规模数据集的受控实验，分离语言、视觉理解与视觉生成之间知识流的方向与不对称性；比较不同架构选择（共享注意力、归一化、模态特定 FFN）和训练策略（早期统一 vs 后期对齐）。基于发现推导高效预训练配方，并最终在 13.5B MoE 模型上以 2T token 规模验证结论。
   - 结果：共享注意力+模态特定 FFN 能促进模态协同；早期联合训练优于后期对齐，有效避免视觉懒惰。数据复杂性决定模态之间的协同或竞争关系。在 2T token 规模下这些发现依然成立，且仅用 5% 计算预算即可达到强生成性能，为多模态预训练提供了高性价比的配置指导。

**主要痛点**

- 长程推理任务中技能切换与信用分配缺乏有效度量和训练信号
- 多模态预训练和推理中的模态交互机制不明，导致算力浪费
- 稀疏数据、资源受限语言的训练成本高，需要高效数据与模型压缩方法
- 安全微调防御和部署时的不确定性校准需要更可靠的方法

**方法趋势**
- 规范对称性分析优化器、轻量曲率预条件化、动态去噪步数
- 技能熵、答案回溯信用分配、层次图记忆、程序化数据生成
- 受控多模态实验、模态路由、结构化未来预测、自蒸馏
- LLM 驱动的内核生成、稀疏剪枝、向量量化隐私压缩
- IRT 评估、风险证书、空空间安全门、可争论界面

**结果信号**

1. [Reward Structure Shapes the Interaction Between Episodic Exploration and Neural Memory in Reinforcement Learning](https://arxiv.org/abs/2608.05111v1)
   - 分类：RL Exploration / Memory Interaction
   - 研究价值：值得精读
   - 关联：直接研究强化学习中的探索与记忆交互，为部分可观测决策提供设计原则。
   - 痛点：强化学习在部分可观测环境中面临着探索和记忆的双重瓶颈：代理必须探索以遇到奖励状态，并记住经验以优化策略。然而，探索奖励和记忆架构通常被孤立评估，它们的交互未被测量；标准的稀疏奖励概念混淆了时间信号密度与奖励实际监督的信息，导致无法解释为何相同奖励信号在不同环境下产生不同效果。这种理论盲点使得设计记忆架构和探索奖励时缺乏原理性指导。
   - 方法：采用受控实验设计，在三个环境中交叉使用探索奖励和多种神经记忆架构，这些环境变化记忆内容的获得方式：主动发现并无监督保留、单线索奖励监督、纯计划调度。通过操控奖励（将密集奖励直接监督所需潜在记忆、施加可避免的小惩罚）验证模式由奖励结构而非密度驱动，并将稀疏奖励形式化为观测锚定奖励机，区分结构稀疏与潜在稀疏。
   - 结果：相同奖励信号在三个环境分别产生了三种不同交互模式：放大架构差异、将架构拉平到共同上限、完全无效。奖励操控证明这些模式由奖励结构而非密度驱动，且可避免的小惩罚诱导策略收敛到次优平稳状态，两个奖励均能解决。形式化词汇解释了每个环境中的记忆保留负担，明确表明探索和记忆是互补的：奖励负责暴露，记忆将暴露转化为回报。

2. [Learning When to Stop: Prefix-Optimal Dynamic Diffusion Policies for Continuous Control](https://arxiv.org/abs/2608.05084v1)
   - 分类：Diffusion Policy / Adaptive Inference
   - 研究价值：值得精读
   - 关联：直接服务于具身智能中的连续控制，减少扩散策略部署开销。
   - 痛点：扩散策略通过迭代去噪获取动作，但迭代步数固定，造成巨大的计算瓶颈。不同动作的难度不同，使用相同的推理步数会浪费算力；而去噪链过早停止则可能使动作质量不足。现有动态扩散方法忽略了中间去噪步骤对动作价值的监督，没有采用原则性的停止标准。需要一种既能减少计算量又能保持甚至提升任务性能的机制。
   - 方法：提出Prefix-Optimal Generative Policies (POGP)，学习每个中间去噪步骤的前缀值函数，通过贝尔曼式递归在去噪链上建立值函数。前缀值函数有两个用途：作为辅助训练目标，鼓励中间输出成为高质量动作；提供测试时停止规则，当继续去噪不再可能产生有意义改进时终止。该方法不需要改变扩散模型架构，在训练和推理时均轻量。
   - 结果：在四个MuJoCo环境下与12个基线相比，POGP将所需去噪迭代减少约2.7倍，同时保持近全任务性能；与最先进的动态扩散基线相比，最终任务性能还提升约3.5%。这表明监督中间去噪步骤不仅支持自适应早期停止，还作为辅助目标改善了学习到的策略。实验在多种控制任务上验证了该方法的通用性。

3. [BridgeVLA++: A Data-Efficient, Generalizable, and Memory-Augmented Vision-Language-Action Framework for 3D Manipulation](https://arxiv.org/abs/2608.05042v1)
   - 分类：Vision-Language-Action / 3D Manipulation / Memory
   - 研究价值：值得精读
   - 关联：直接面向具身操作的VLA框架，解决了记忆和泛化。

### 2. [Representational separation between unitary and channel quantum generative models via shared classical randomness at shallow depth](https://arxiv.org/abs/2608.05110v1)

**原始摘要**
