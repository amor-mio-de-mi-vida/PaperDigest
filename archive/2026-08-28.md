1. [Mechanistic Reaction Prediction via Discrete Flow Matching on Graph-Structured Electron Occupation](https://arxiv.org/abs/2608.27429v1)
   - 分类：Reaction Prediction / Discrete Flow Matching
   - 研究价值：值得精读
   - 关联：与反应预测、离散扩散模型、机理建模相关
   - 痛点：现有反应预测模型大多直接在分子拓扑上进行启发式图编辑，或采用从头生成产物分子的策略，无法刻画反应中电子重新分配这一底层本质，导致机理可解释性缺失；且这些方法通常依赖昂贵的基元步骤标注，难以迁移到未见反应类型；在结构复杂度和反应类型等分布外场景下性能急剧下降，也无法预测副产物，严重制约了其在合成规划中的实际应用。
   - 方法：MAELLE将化学反应建模为电子占据向量上的离散流匹配，使用连续时间马尔可夫链(CTMC)在成键、非键和氢位点构成的图结构整数空间上定义反应物到产物的映射；通过最优传输泛化离散流匹配的混合路径，构造序列化且机理可解释的电子重排编辑轨迹，无需任何基元步骤标注；模型在完整电子再分配上学习，因此天然支持反应机理恢复和副产物预测。
   - 结果：MAELLE在USPTO-480K基准上取得与领先反应预测模型相当的Top-k匹配准确率，竞争力得到验证；更重要的是，在结构复杂度和反应类型两种分布外测试中，MAELLE的准确率下降幅度显著小于现有方法，维持了稳定性能；此外，模型自动恢复的电子重排轨迹与已知化学反应机理一致，并能预测副产物，展示了从单步产物预测到机理级建模的跃迁。

2. [CLAP: Cross-Embodiment Video World Models are Zero-Shot Physical Simulators](https://arxiv.org/abs/2608.27406v1)

   - 研究价值：值得精读
   - 关联：与视频世界模型、机器人具身智能、跨模态学习相关
   - 痛点：现有动作条件视频世界模型被限制在单一机器人具身，无法利用互联网上海量异构视频数据蕴含的通用物理规律；不同机器人平台的动作表示差异巨大，且人类视频中通常没有动作标签，导致跨具身学习难以实现；因此，模型在真实世界零样本任务部署时泛化能力不足，单具身数据瓶颈严重，阻碍视频生成模型成为真正的物理模拟器。
   - 方法：CLAP提出跨具身动作条件视频生成框架，通过末端执行器位姿、语言指令和潜在动作三种动作空间统一异构机器人数据；设计课程式跨具身学习流程，先用无标签视频训练潜在动作以学习跨域物理先验，再在末端执行器动作空间上进行grounding，实现零样本部署；此外支持few-shot适应，为训练单具身世界模型提供新范式。

3. [PAWBench: How Far Are We from Probabilistically Aligned World Modeling?](https://arxiv.org/abs/2608.27345v1)
   - 分类：World Models / Evaluation Benchmark
   - 研究价值：值得精读
   - 关联：与视频生成评估、世界模型概率建模相关
   - 痛点：当前视频生成模型被广泛用作世界模型，但许多物理过程在相同初始条件和动作下存在多种有效演化方式，因此世界模型不仅应生成合理视频，还需重构可能行为的概率分布；然而现有评估只检查单个视频的合理性，不检验重复采样是否恢复真实分布，导致“看似合理但分布错误”的模型无法被识别；这种概率对齐缺失成为世界模型落地的重要障碍。
   - 方法：PAWBench将概率对齐形式化为分布层准则，定义视频生成模型作为随机采样器应满足的条件；引入包含50个物理场景的PAWBench基准和PAWEval评估协议，将重复视频生成rollout转化为可能物理行为的经验分布，通过比较参考概率系统性地衡量分布匹配程度；并设计干预实验，测试语言提示、初始噪声采样和模型训练能否调节预测分布。
   - 结果：在50个物理场景和11个当前主流视频生成系统上，没有任何模型能够一致匹配参考概率并完整恢复有效行为范围，暴露了分布级偏差；干预实验表明现有提示/噪声调制手段只能部分调整边际分布，无法从根本上实现概率对齐；该工作为未来概率对齐世界模型的评测和改进建立了基础性框架，其评估协议可直接复用于后续模型开发。

1. [LeVJEPA: Efficient & Scalable Video Pretraining without the Heuristics](https://arxiv.org/abs/2608.27395v1)
   - 分类：Video Self-Supervised Learning
   - 研究价值：值得精读
   - 关联：视频预训练高效化，大幅降低计算成本，是通用视觉预训练效率突破
   - 痛点：现有视频自监督预训练普遍依赖不对称架构——EMA教师、stop-gradient、容量受限预测器——或像素空间重建来防止表征坍塌，这不仅引入大量启发式超参，还带来极高计算开销，使视频预训练在通用视觉预训练中缺乏竞争力。本文瞄准这一结构性低效：在保持可证明防坍塌的前提下，去掉所有不对称分支和重建损失，把视频预训练成本降低一个数量级以上，让视频成为通用视觉表征学习的实用数据源。
   - 方法：LeVJEPA采用LeJEPA的collapse-free目标：单个共享编码器对片段全局与局部视图施加不变性损失，仅用SIGReg正则化以理论保证排除坍塌解，彻底移除EMA、stop-gradient和预测器，结构简化为编码器+投影器，目标仅含一个超参数。训练时使用均匀随机token丢弃，显著减少编码器观测token数；由于无分支不对称约束，还可使用块因果注意力训练，在不损失精度的前提下将时序顺序建模内化到编码器自身。
   - 结果：在相同epochs和相同数据上，LeVJEPA以5.6–20.8倍更少预训练计算匹配或超越V-JEPA 2（ViT-S/B/L）；在匹配总FLOPs时，ImageNet-1K上超过最强视频基线7.6分，运动中心基准保持竞争力；相比在同样视频帧上训练的DINOv2，外观中心评测接近、运动中心准确率近乎翻倍。这些结果表明，去除视频预训练的计算开销后，视频可成为通用视觉预训练的高效且在某些维度更优的基底，也验证了无启发式自监督目标在大规模视频上的可行性。

2. [TTPO: Test-Time Policy Optimization](https://arxiv.org/abs/2608.27448v1)
   - 分类：Test-Time Training / LLM Reasoning
   - 研究价值：值得精读
   - 关联：将RLVR扩展到测试时训练，无需真实标签即可持续优化推理策略，与高效推理和自适应推理相关
   - 痛点：RL和OPSD等主流后训练依赖真实标签，无法在测试时继续训练；直接替换为多数投票伪标签又非常脆弱——一次错误投票会污染教师并误导每个token。本文的关键观察是这种失败存在非对称性：无论投票本身正确与否，与伪标签不一致的rollout通常就是错误的。这为构建无标签测试时训练提供了可靠信号，但需要设计既不过拟合错误伪标签、又能有效利用多数投票动态收紧自监督的优化目标。
   - 方法：TTPO构建非对称目标：对与伪标签一致的rollout用OPSD蒸馏，对不一致rollout用Grouped RL惩罚，并从两个方向细化——蒸馏分支降低已收敛位置的权重，RL分支只惩罚高置信错误。该设计使两种更新在伪标签频繁出错时仍保持合理梯度；同时采用多数投票路由，模型越好则自监督信号越紧。整体流程无需真实标签即可在线更新策略，token级选择进一步抑制噪声并保留高效特性。
   - 结果：在五个竞赛级数学基准上，TTPO无需任何标签即匹配有标签OPSD的最终性能；将Qwen3-1.7B在TTT设定下从38.0%提升至45.2%（+7.2个百分点），无thinking模式下提升+25.2%到+36.4%；还展示强跨任务泛化能力。相比有标签训练，TTPO在训练/推理总预算上更高效，为无法获得人工标注的推理场景提供了一种可落地的测试时优化方案，并验证了基于失败不对称性设计的可行性。

3. [SWE-Prime: Fewer Trajectories, Better Performance](https://arxiv.org/abs/2608.27449v1)
   - 分类：LLM Agent / Data Curation
   - 研究价值：值得精读
   - 关联：通过数据选择提升SFT效率，用更少轨迹获得更优agent能力，直接降低训练成本
   - 痛点：当前基于成功轨迹的SFT隐含假设“成功即高质量”，但成功轨迹中常包含无效、冗余甚至危险的逐步操作，直接使用会把噪声监督和不良问题解决行为教给模型。尤其软件工程agent轨迹长、工具调用复杂，人工筛选成本极高，而现有数据选择方法多停留在轨迹级粗筛，难以定位序列内部有害片段。因此需要一种能在不破坏上下文前提下、细粒度剔除低质监督的数据选择方法，以用更少的训练数据获得更强的agent性能。
   - 方法：SWE-Prime是两阶段、多粒度的SFT数据选择方法。第一阶段基于过程质量、结果质量和数据代表性对完整轨迹进行轨迹级粗筛，选出一批高质量且有代表性的成功轨迹；第二阶段将轨迹内连续步骤聚合成语义段，分别评估每段对最终答案的贡献、可学习性和潜在风险，得到段级可训练性标签。训练时保留全部段作为上下文，但只对选中段计算loss，从而在保持序列完整性的同时完成噪声抑制。
   - 结果：在SWE-Bench Pro和SWE-Bench Verified上，使用SWE-Prime选出的10%轨迹子集进行SFT，相对全量resolved数据的训练分别带来12.2%和24.2%的绝对提升，且显著超过随机子集和现有筛选基线。消融显示轨迹级与段级筛选各自贡献重要，段级筛选是主要增益来源。这表明高质量、代表性、细粒度去噪的小规模轨迹集完全可能比大量未筛选的成功轨迹更有效地训练软件工程agent。

**主要痛点**
- 训练/推理计算成本高，视频预训练、VLA推理等场景尤甚
- RLVR等后训练依赖真实标签，测试时无法继续优化
- SFT数据中成功轨迹含噪声，需要细粒度筛选
- 大规模图/索引系统内存与构建开销大

**方法趋势**
- 无启发式自监督目标、流式解码、测试时策略优化
- 多粒度数据选择、技能/知识库协同进化、行为感知验证
- 低精度/消费级硬件预训练、按需架构增长
- 多哈希嵌入、时序CSR二分查找、随机采样倒排索引

**结果信号**
- 预训练算力降低5.6-20.8倍，推理控制频率达30Hz
- 无标签TTT匹配有标签OPSD，10%轨迹SFT超过全量
- 小模型+技能超越大模型，稀疏更新避免遗忘
- 嵌入表减98%，索引构建快3.7倍

2. [FlashVLA: Streaming Action Decoding for Fast and Asynchronous VLA Inference](https://arxiv.org/abs/2608.27384v1)
   - 分类：VLA / Efficient Inference
   - 研究价值：值得精读
   - 关联：直接解决VLA模型部署延迟痛点，与机器人实时控制紧密相关
   - 痛点：VLA模型在实际机器人部署中受高推理延迟和不稳定异步执行限制，尤其流匹配模型需多步迭代解码，计算开销大。现有高效推理方法只提升控制频率，异步方法只减少空闲时间，难以同时实现低延迟和准确的时序一致性。
   - 方法：提出流式动作解码框架，维护多个噪声级别的动作块缓冲，采用块级因果注意力解码，每个推理步骤生成一个可执行动作块。块级自回归公式隐式保持动作连续性，无需额外未来状态条件，实现平滑异步执行。
   - 结果：在模拟和真实实验中，FlashVLA在单GPU上达到≥30Hz控制频率，推理速度大幅提升，同时保持任务性能，异步执行平滑稳定。

   - 研究价值：值得精读

- 关键词：LLMS can design, large language models, effective algorithms for well-specified, algorithms for well-specified operations, LLM query can already, query can already produce
- 链接：<https://arxiv.org/abs/2608.27296v1>

**原始摘要**

We ask whether large language models (LLMs) can design effective algorithms for well-specified operations research (OR) problems. We study inventory control, queueing network control, and assortment optimization. We evaluate two levels of LLM use: at level 1, the model receives one problem instance and returns a solution for that instance; at level 2, it receives only the problem class description and broad parameter ranges, and returns an algorithm that maps instance parameters to solutions. Human input is minimal: we give one untuned prompt that describes the problem, and the model has access to a Python sandbox tool with a fixed compute budget. The strongest model we test, gpt-5.6-sol, matches or outperforms the best existing method on almost all evaluated instances. This holds even at level 2, where the returned algorithm is fixed before seeing the evaluation instances. Performance also improves sharply across models released less than eight months apart, suggesting that this capability is moving quickly. Thus, for the well-specified operations problems we study, a single untuned LLM query can already produce algorithms competitive with specialized methods. These results suggest that frontier LLMs can be a serious empirical baseline for algorithm design in well-specified OR problems.

### 1. [UrbanGround: From Local Perception to Spatial Agency in a Real-Scale City](https://arxiv.org/abs/2608.27456v1)

- 来源：arXiv
- 关键词：agent, real-scale city., reasoning, multimodal, large language models, HOW FAR current MLLM
- 链接：<https://arxiv.org/abs/2608.27456v1>

**原始摘要**

Multimodal large language models (MLLMs) can interpret a street view, but urban agency depends on whether such local evidence remains useful after the agent starts to move. In this paper, we investigate how far current MLLM agents can turn local urban perception into reliable action in a complicated real-scale city. We propose UrbanGround, the first sandbox to make this question testable in a physically constrained replica of Hong Kong built from territory-wide 3D geospatial data. UrbanGround supports closed-loop interaction from a first-person view and provides an interactive map for navigation. Agents can directly enter the 3D city and explore from a first-person view. Our analysis follows the growth of the spatial problem through three research questions. We first test whether an agent can ground a local scene well enough to answer spatial questions after active observation. Then we ask whether that grounding supports navigation as destinations become farther away and less explicit. Finally, we examine whether the resulting behavior survives changes in route availability and pedestrian motion. Contemporary MLLM agents usually show useful atomic abilities in visual recognition and short-range spatial reasoning, while orientation and pedestrian-aware movement remain unreliable. Their central failure emerges over extended exploration, where local abilities do not compose into sustained goal-directed behavior and errors accumulate without effective correction. We hope UrbanGround will support broader study of how far current MLLM agents can explore reliably in complex, open-ended urban environments.

### 2. [RedEvoAgent: Automatic Red-Teaming Agent with Experience-Driven Skill Evolution](https://arxiv.org/abs/2608.27439v1)

- 来源：arXiv
- 关键词：agent, automatic red-teaming, red-teaming methods often RELY, deciding-tool attribution for skill, experience-driven skill evolution. llm-based, skill. the attack skill
- 链接：<https://arxiv.org/abs/2608.27439v1>

**原始摘要**

LLM-based agents are increasingly deployed in product-level execution harnesses, where jailbreaks can trigger harmful tool use and persistent state changes, creating greater risks than unsafe text generation alone. Existing automatic red-teaming methods often rely on fixed attacks, while recent agentic attackers coordinate multiple jailbreak tools and show stronger potential through trajectory-based retrieval. However, such retrieval can reuse misleading experiences due to retrieval bias and unclear tool credit, and full trajectories add context overhead while reducing interpretability. We propose RedEvoAgent, a black-box red-teaming agent that distills cross-case attack trajectories into a concise, human-readable attack skill. The attack skill adaptively evolves through tool-effectiveness profiling and Deciding-Tool Attribution for skill updates, and a validation ratchet that retains only updates improving validation performance. Experiments on multiple benchmarks, target models, and target execution harnesses show that RedEvoAgent outperforms fixed and agentic baselines, improves tool efficiency, and transfers across attacker models and target execution harnesses.

### 3. [Persona-Execution Separation: An Architecture Pattern for Evolving LLM Agents under Execution Audit](https://arxiv.org/abs/2608.27427v1)

- 来源：arXiv
- 关键词：LLM agents, persona-execution separation, drift execution, pattern applies WHEN multi-user, WHEN multi-user deployment execution, multi-user deployment execution audit
- 链接：<https://arxiv.org/abs/2608.27427v1>

**原始摘要**

Large language model (LLM) agents in governed organizations must let the persona (instructions, tone, self-presentation) evolve freely, while keeping execution (stateful, audited work) traceable. A single trust domain does not satisfy both cheaply. We present Persona-Execution Separation (PES): persona and execution reside in different trust domains, connected by a governed contract bridge. The persona is singly-homed and may drift; execution is faceless and audited. Status summaries may return; data bodies remain in the restrictive domain except a graded data-loss-prevention (DLP) exception; identity stays continuous. An approval matrix, DLP, and audit enforce the crossing. PES follows from three goals---free drift, execution traceability, and decoupling. Under LLM representational indistinguishability, any single-domain mechanism that meets all three must re-introduce typed change objects, an external gate, and a stable audit anchor: PES rebuilt at higher coupling cost. A development/pilot case in a regulated digital-employee platform records five decisions over one month, each with a rejected alternative. A mechanism check on the shipped implementation found no execution-side re-validation under persona perturbation (five model configurations) and no persona fingerprint on hard-asserted fields. A probe of a recovered pre-separation build found the governed execution path decoupled from the persona by omission, not by construction; a later wiring change could reverse that isolation, which PES makes an audited architectural rule. The pattern applies when multi-user deployment, execution audit, and expected persona churn hold jointly.

### 4. [INTENT-AS-A-TOOL Makes it Easy to Track Agentic Misalignment](https://arxiv.org/abs/2608.27348v1)

- 来源：arXiv
- 关键词：agentic misalignment, reasoning, chain-of-thought, large language models, post-hoc COT labels, intent-as-a-tool complements COT monitoring
- 链接：<https://arxiv.org/abs/2608.27348v1>

**原始摘要**

As large language models (LLMs) are deployed as autonomous agents, safety failures increasingly involve consequential actions. We study agentic misalignment, where agents take harmful actions under goal conflicts and pressures. Using chain-of-thought (CoT) monitoring, we find that harmful execution is often preceded by intent signals in reasoning. However, post-hoc CoT labels are too coarse to show how intent changes during generation. We introduce INTENT-AS-A-TOOL, an approach that adds intent-targeted tools to give the model a dedicated channel for expressing commitment to a target behavior. The probability of calling an intent tool provides a judge-free, fine-grained signal of the model's tendency to pursue that behavior. Our results show that INTENT-AS-A-TOOL complements CoT monitoring, expands post-hoc CoT labels into dense trajectories, and identifies critical steps for online intervention. These findings suggest that action preferences are useful for tracking agentic misalignment during reasoning. Our code and data are accessible: https://github.com/RebeccaZhang22/intent-as-a-tool.
