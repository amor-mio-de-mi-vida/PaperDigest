1. [Good Pretraining, Bad SFT: Checkpoint Quality Across the Training Stack](https://arxiv.org/abs/2609.08966v1)
   - 分类：LLM Training / Checkpoint Selection
   - 研究价值：值得精读
   - 关联：揭示预训练指标在SFT选点上的失效，为训练管线提供可直接使用的checkpoint评估新准则，与模型训练决策强相关。
   - 痛点：语言模型完整训练流程中，预训练阶段通常以预训练损失或benchmark分数选择最佳checkpoint作为后续SFT起点，但论文在30B MoE全栈训练中发现该假设可能失效：在预训练上表现更好的checkpoint在SFT后不一定表现更好，意味着仅凭预训练指标选点不可靠，造成算力和数据资源浪费，还可能让下游模型性能次优。这为训练流程设计引入了关键痛点。
   - 方法：论文在完整30B混合专家训练管线上进行系统性实证，对比不同checkpoint经过SFT后的下游表现，并引入solution density概念——度量局部权重扰动下保留下游性能的能力——作为新的checkpoint质量指标。通过分析预训练loss、benchmark分数和solution density与最终全栈训练性能的关系，揭开传统选点准则的盲区。
   - 结果：结果显示，预训练阶段更好的checkpoint并非总是SFT后的最优起点，而solution density能更可靠地预测全栈训练后的性能，即能够抵抗局部权重扰动的checkpoint更适合作后续训练起点。该发现直接挑战了仅由预训练损失选择checkpoint的常见做法，为训练流程设计提供了新的参考。结果对大规模模型训练效率与最终质量有直接指导意义。

2. [Training-Free Task Vectors for LLM Behavioral Control](https://arxiv.org/abs/2609.09054v1)
   - 分类：LLM Model Editing / Inference-time Control
   - 研究价值：值得精读
   - 关联：提出无需微调即可构造任务向量的方法，为LLM行为控制提供高效、可组合的免训练新工具，与参数高效微调和推理时控制密切相关。
   - 痛点：传统task vector通过微调模型与预训练初始点之间的权重差来获得语义方向，但微调成本高，难以在大型模型上快速获得可组合的编辑方向；激活空间的steering vector虽然便宜，却缺乏task vector在加法、减法上直接支持行为组合和遗忘的算术性质。因此需要一种既不依赖微调又能保持算术性质的免训练任务向量构建方法。
   - 方法：提出Training-Free Task Vectors (TFTVs)，仅利用前向传播统计把激活空间的steering vector映射为权重空间的rank-one编辑，完全免去微调。该方法推导出满足加法（行为学习）、减法（行为遗忘）及多编辑组合的代数约束，并利用这些约束保证编辑方向的语义一致性。通过行为放大/抑制/组合等实验验证编辑效果。
   - 结果：实验表明TFTVs在多种LLM行为控制任务上能够有效放大、抑制和组合目标行为，同时保持一般知识和问题解决能力；相比现有的task vector、steering和LoRA等基线，TFTVs在控制强度和知识保留上都达到更优或持平。实验结果还验证了免训练构建任务向量的可行性和实用性，为低成本模型行为编辑提供了新路径。

3. [Mask Forcing: Improving Autoregressive Video Diffusion Distillation via Dual-Noise Masking Rollout](https://arxiv.org/abs/2609.09123v1)
   - 分类：Video Generation / Diffusion Distillation
   - 研究价值：值得精读
   - 关联：解决AR视频扩散蒸馏中的模式坍缩问题，在不引入真实视频或后训练的前提下提升生成质量和效率，直接推动实时视频生成蒸馏。
   - 痛点：自回归(AR)视频扩散模型在通过分布匹配蒸馏(DMD)压缩为因果学生模型时，由于反向KL目标存在mode-seeking行为，学生分布容易坍缩到教师分布的少数模式，导致生成视频出现明显过饱和和过平滑，视觉质量与真实感受限。需要一种不改变生成框架且无需额外真实数据的方法来缓解训练中的模式坍缩，提升蒸馏效果。
   - 方法：提出Mask Forcing策略，即Dual-Noise Masking Rollout：在自回归学生模型的自我rollout训练中沿空间和时间轴随机施加掩码，将更干净（噪声更小）的教师信号或原始token注入到带噪输入中，激励学生rollout探索教师分布中尚未覆盖的区域；同时更干净的token作为去噪引导帮助其他更噪token，从而减少中间预测误差累积。该方法不依赖真实视频数据或额外post-training。
   - 结果：在多个AR视频扩散蒸馏方法上应用Mask Forcing后，生成视频的视觉质量和真实感显著提升，计算开销未明显增加，且优于现有蒸馏方法。实验证明该方法能有效缓解reverse-KL导致的模式坍缩，同时抑制误差累积，为高效自回归视频生成蒸馏提供了实用改进策略。

**主要痛点**
- 大型模型预训练选点信号失真，SFT后最优checkpoint可能偏离预训练最优，浪费计算资源。
- 模型行为编辑依赖高成本微调，缺少可组合且无需训练的高效手段。
- 生成式扩散模型蒸馏易陷入模式坍缩，质量与速度难以兼顾。
- 多领域训练数据配比常靠直觉而非实验，领域覆盖缺口难以在后训练阶段修复。
- 主流RL/环境搭建方法计算开销大，制约训练与推理效率提升。

**方法趋势**
- 通过全栈训练分析引入solution density等新checkpoint质量指标。
- 利用前向统计构造免训练task vectors，保持算术性质。
- 在蒸馏rollout中使用双噪声随机遮蔽，融合干净引导信号。
- 对五域simplex系统采样与SFT组合，量化领域覆盖和align缺口。
- 借鉴Adam思想为离散skill/材料设计一阶记忆与二阶编辑预算；用LLM自动生成环境并加入高效RL pipeline。

**结果信号**
- solution density能更好预测SFT后全栈性能，指导checkpoint选取。
- TFTVs免训练即可实现行为控制，且知识保持更好。
- Mask Forcing显著改善AR视频扩散蒸馏质量，且不引入额外数据。
- 各领域存在10%-40%内部最优覆盖，且SFT不能完全修复mid-training缺口的代价。
- 简化AVI等方法在中等规模博弈中可达接近MCTS性能但成本大幅下降；RL环境开发成本可被LLM+高效框架大幅压缩。

   - 结果：在8个真实世界与4个仿真操纵任务上，PPS将π0.5基座策略的平均绝对成功率提升53个百分点，在基座原本完全无法求解的任务上也出现从0到1的突破，同时保留失败恢复等基座原先具备的广泛能力。与LoRA微调、从零训练专家、残差策略以及此前推理期引导方法相比，PPS在成功率与能力保持上均取得更优结果。实验说明速度空间上的“参考−任务”代理差能够作为稳定、轻量的推理期策略适配信号。

1. [Procedural Graphs: Self-Evolving Execution Structures for LLM Agents](https://arxiv.org/abs/2609.09153v1)
   - 分类：LLM Agent / Procedural Memory
   - 研究价值：值得精读
   - 关联：将知识图谱范式引入Agent的程序性知识管理，可作为长期Agent自我改进的结构化记忆基础。
   - 痛点：大型语言模型Agent在执行长程多步任务时，一般仅把当前轨迹当作输入进行自回归式生成，缺少对任务流程中程序性知识的显式编码，例如哪个操作必须在前、哪个分支条件会触发何种动作。当轨迹变长后，模型很容易遗忘初始目标、以非法顺序调用工具或反复执行同样无效尝试；同时，新的经验无法沉淀为可复用结构。现有基于记忆或检索的方法只能附带取出历史文本，并未把“做什么/按什么顺序/在何种条件下做”等程序性规则表示为可导航、可演化的算子，因此难以从根本上降低Agent在规划上的符号化混乱。
   - 方法：提出Procedural Graph概念，类比知识图谱对事实三元组的组织方式，把过程性知识表达为(过程,关系,过程)三元组。运行中，框架先从图中定位Agent的活跃节点，再由轻量guidance model把活跃节点附近的子图转化为当前步的情境指导，起“偏置但不替代”的选择性作用。为了使图保持自演进，采用LLM refiner对比一次失败轨迹与一次成功轨迹，并以保持或提升留出验证得分为目标编辑图的拓扑与节点属性，被拒绝的错误编辑保留为负例，从而逐步向高价值执行结构迭代。
   - 结果：从只有最小执行骨架的初始图出发，自动构建出的图可以在任务成功率上与人工专家精心设计的图持平甚至更好；并且当先验知识存在错误时，系统还能有效修复有缺陷的专家图。在多个数据集、任务类型与不同规模LLM上，该机制相较memory-based基线有稳定收益；加入自我演化后性能进一步提升，且无需人工干预，表明该结构让LLM Agent具有持续累积高质量过程知识的能力。

2. [Co-Evolving Harnesses and Models: On-Policy Correction Helps Weaker Models Catch Up Where Imitation Fails](https://arxiv.org/abs/2609.09134v1)
   - 分类：Agent Harness / Model Adaptation
   - 研究价值：值得精读
   - 关联：回应了Agent harness与模型权重更新相互冲突的问题，对轻量模型在垂直场景下的迭代落地有直接指导意义。
   - 痛点：在Agent开发中，系统提示、工具集、执行钩子和上下文管理构成的harness与模型权重共同决定任务表现，但两者很少被联合优化。自动harness进化可以让小模型在领域任务上接近大模型，不过专家经验如何迁移给弱模型一直棘手：把强专家在演化后harness下产出的完整轨迹用于模仿训练，会在多个任务中显著拉低结果，因为弱模型不具备专家规划所需能力，还会破坏其原有规划风格与harness的匹配，理论与实践都缺少兼容式共同演化的方案。
   - 方法：论文剖析了弱模型在演化harness下模仿完整轨迹产生模型-harness失配的原因，并提出On-Policy专家纠错流水线。它由一个meta-level MLE智能体负责自动找到弱模型自身rollout里最具决定性的失败回合，仅让专家重写该局部回合代码，而保留该回合前的规划及之后的执行上下文，从而不抹掉弱模型自身的规划特点。随后harness演化与轻量模型微调交替进行，把环境侧的适应性与权重侧的知识更新按次序结合，构成经济和持续的co-evolution流程。
   - 结果：在7个真实企业Agent任务上验证，如果使用专家完整轨迹，则Qwen3-Coder和Gemma 4在所有任务上均回退4~30个点；而新On-Policy纠错方法消除了此类回退，并把harness演化所得收益与模型适配收益叠加起来。更重要的是，该方法保证了弱模型仍能按自己的风格和harness协作，因此可以仅用轻量微调即可在垂直任务上追赶强模型，同时显著节省调用成本，形成了可复用的技能迁移流程。

3. [ToolLoop: Closed-Loop Tool-Use Data Synthesis via Decomposed Generation and Dynamic Self-Feedback](https://arxiv.org/abs/2609.09072v1)

   - 痛点：高质量工具调用数据是训练语言模型正确使用外部API的核心，但当前合成方法主要采用先生成、后过滤的方式，用静态事后校验过滤低质量样本，造成大量冗余、类别不均衡与高成本，且无法在生成过程内纠正错误。先采样函数名生成查询再生成调用的反向推导在闭环验证上也稀缺，这限制小模型学习鲁棒工具选择与参数填充的能力。

### 3. [Proxy Policy Steering](https://arxiv.org/abs/2609.09148v1)
