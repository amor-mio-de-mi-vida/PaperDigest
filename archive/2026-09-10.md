1. [Programmable World Model](https://arxiv.org/abs/2609.10540v1)
   - 分类：Video World Model / Programmable Generation
   - 研究价值：值得精读
   - 关联：与生成式AI中的可控视频世界模型和长时程一致性高度相关，是本次最值得精读的方向。
   - 痛点：当前视频世界模型虽然能生成越来越真实、可交互的画面，却难以在长时程交互中维持持久且可编程的世界状态，也无法可靠地控制实体属性、离屏对象和游戏规则，导致生成视频缺乏一致性与可操控性，难以直接用于可玩游戏或复杂交互应用。传统方法把状态演化与视觉渲染耦合在一起，缺少显式、持久且可编程的全局状态表示，因而在计数、状态追踪和规则约束上容易失效。这严重限制了世界模型在游戏、仿真和交互式内容生成中的实用价值。
   - 方法：论文提出 Programmable World Model，将世界状态演化与视觉观测生成解耦。智能体把自然语言指令翻译为可执行程序，指定实体状态与状态转移规则；轻量引擎执行程序并维护显式持久的全局状态，包括离屏实体与非视觉属性。方法进一步引入状态增强的 3D 有向包围盒作为中间表示，与目标相机轨迹一起确定性地编译为像素对齐的时空条件信号，驱动预训练视频模型作为生成渲染器，从而支持可玩游戏与持久世界状态。
   - 结果：作者进一步提出 CombatStateBench 基准，用于系统评估可编程世界模型在实体计数、状态保持和长时程一致性方面的能力。在该基准上，所提方法取得 94% Count Accuracy 与 98% State Accuracy，显著超过现有交互式视频世界模型，并支持连贯的长时程生成。实验结果表明，将显式状态演化与生成渲染分离，能够有效构建持久、可编程且可交互的世界模型，为可控视频生成与游戏模拟提供新路径。

2. [Guiding Image-to-3D Generation with Test-Time Partial Observations](https://arxiv.org/abs/2609.10531v1)
   - 分类：Image-to-3D Generation / Test-Time Guidance
   - 研究价值：值得精读
   - 关联：与生成式3D和测试时引导生成高度相关，对提升生成模型几何可控性有直接启发。
   - 痛点：单图到3D生成模型虽能产生视觉上吸引人的三维资产，但其几何结构往往只被输入图像松散约束，难以满足需要几何保真度的应用；现实场景中测试时可能获得部分几何观测，如稀疏深度或表面点，但现有预训练模型无法直接利用这些证据，重新训练或微调成本高且可能破坏生成先验。因此，如何在无需重训练的前提下，把测试时部分观测注入图像到3D生成过程，并保持射线一致性与几何有效性，是亟待解决的问题。尤其当观测不完整或视角分布变化时，生成结果容易出现几何漂移。
   - 方法：论文提出一种免训练框架，将测试时部分几何观测融入预训练图像到3D生成模型，无需重训练或微调。方法在模型占据表示上定义射线一致的观测似然，同时结合表面占据证据与自由空间证据，通过测试时引导修正生成过程。该引导适用于 SAM 3D 及其多视角扩展，在生成采样中显式注入几何约束，从而在不修改底层模型的情况下提升几何保真度。
   - 结果：实验表明，在不同可观测程度下，该引导方法都能显著提升几何保真度与视觉质量，并可与多视角扩展结合使用。结果证明，预训练图像到3D模型能够通过显式测试时引导有效整合部分几何观测，补充其学到的生成先验而无需修改模型参数。这为实际部署中利用稀疏、不完整的测试时证据提供了实用方案，也说明测试时引导可成为连接生成先验与几何证据的通用接口。

3. [Frequency-Conditioned Flow Matching for Vision-Language-Action Models](https://arxiv.org/abs/2609.10405v1)
   - 分类：Flow Matching / VLA
   - 研究价值：值得精读
   - 关联：与扩散/流匹配生成建模和机器人动作生成高度相关，方法可迁移到其他轨迹生成任务。
   - 痛点：机器人动作是时间相关轨迹，其频率分量在不同尺度上编码运动且能量分布高度不均匀。然而基于 Flow Matching 的视觉-语言-动作模型通常直接在时间坐标中生成动作，没有显式建模或系统利用这种频率异质性，导致高频细节与低频运动难以兼顾，生成动作的精度和泛化性受限。尤其在复杂操作任务中，不同频段对轨迹平滑性和末端执行器精度贡献不同，忽略频率结构会限制生成质量与鲁棒性。
   - 方法：论文提出 FreqFM，一种面向 VLA 模型的频率条件 Flow Matching 框架，把动作频率从隐式轨迹属性提升为贯穿生成管线的显式条件维度。具体在 DCT 频率坐标中，FreqFM 构造频谱匹配的源分布，自适应平衡不同频率上的训练目标，并利用对应参考传输尺度约束各频率的引导残差。该方法可直接集成到已有 Flow Matching 动作专家中，无需改变 VLA 主干网络。
   - 结果：在 LIBERO、LIBERO-Plus 与 VLA-Arena 基准上，FreqFM 一致提升性能，其中在 LIBERO-Plus 上取得 9.3 个百分点的增益。作者还在六个真实机器人任务上验证了方法有效性，表明频率条件建模能改善动作生成质量与泛化能力。结果说明显式利用动作频率异质性，是提升 Flow Matching VLA 模型性能的有效途径。

**主要痛点**
- 视频世界模型缺乏持久可编程状态与长时程一致性。
- 图像到3D生成受限于几何保真度与测试时观测利用不足。
- 扩散/流匹配模型在动作、语音和科学成像中仍面临频率建模、少步采样与逆问题约束等挑战。

**方法趋势**
- 将状态演化与生成渲染解耦，并用可执行程序与中间表示控制视频生成。
- 在测试时用观测似然引导预训练生成模型，免训练注入几何约束。
- 频率条件Flow Matching、自蒸馏一致性轨迹和扩散先验数据一致性等生成建模改进。

**结果信号**
- Programmable World Model在CombatStateBench达到94%计数与98%状态准确率。
- FreqFM在LIBERO-Plus提升9.3点，并在真实机器人任务验证。
- 无教师一致性轨迹语音增强达到PESQ 3.01、ESTOI 0.87、SI-SDR 19.07 dB。

### 高效训练与推理

- 论文数：34

**今日推荐精读 Top 3**

1. [ConvMem: Convolutional Memory for Long-Context Reasoning](https://arxiv.org/abs/2609.10441v1)
   - 分类：Long-Context Reasoning / Training-Free Memory
   - 研究价值：值得精读
   - 关联：直接针对长上下文推理的延迟与训练成本瓶颈，属于高效推理方向，可作为免训练长文本记忆的新范式。
   - 痛点：大语言模型的固定上下文窗口使其难以处理超长输入，而MemAgent等顺序记忆方案通过分段读取并迭代更新固定大小记忆来扩展有效上下文，却带来两个突出问题：一是逐段串行处理导致推理延迟随输入长度线性增长、吞吐受限；二是该方法依赖昂贵的强化学习训练，不仅成本高，还容易在特定数据集上过拟合，迁移到分布外任务时性能明显下降。
   - 方法：ConvMem把长上下文推理重新表述为分层卷积，仿照CNN把被查询提示的LLM视为卷积核，让它对文本片段逐层归纳，把原本线性的推理链压缩成对数深度的树。框架引入可配置步幅（Configurable Strides）与跳跃连接（Skip Connections）以保证证据的捕获与跨层传播，并用多核卷积（Multi-Kernel Convolution）把复杂查询分解为彼此解耦的语义通道；整个过程无需任何训练，天然支持文本片段与推理线程的大规模并行。
   - 结果：在RULER-HotpotQA与RULER-2WikiMultiHopQA上，ConvMem一致优于免训练基线，验证了分层卷积式记忆在长上下文推理上的有效性。由于无需RL训练，它避免了RL模型对参数化先验的过拟合风险，在分布外任务上表现更稳健。同时该设计支持跨文本片段与推理线程的大规模并行，把推理路径从线性链缩短为对数树，为长上下文场景提供了低延迟、易部署的替代方案。

2. [Forgetting Only What Matters: Layer-Selective Unlearning toward Robust LLMs](https://arxiv.org/abs/2609.10439v1)
   - 分类：Machine Unlearning / Layer-Selective Updates
   - 研究价值：值得精读
   - 关联：以层级稀疏更新替代全参数重训/宽泛更新，直接降低遗忘训练的代价，并关注量化后推理阶段的遗忘稳健性，属于高效训练与推理交叉方向。
   - 痛点：现有机器遗忘方法多采用宽泛或固定的参数更新，在擦除敏感、受版权保护内容的同时容易损伤模型通用能力，且遗忘效果脆弱：当模型部署后经历训练后量化等变化时，被遗忘的知识可能部分重新涌现。如何在只改动尽可能少参数的前提下实现精准遗忘，并让遗忘结果在8-bit乃至4-bit低比特量化等部署条件下依然稳健，是LLM安全合规落地亟待解决的具体痛点。
   - 方法：FOM-UL提出层级遗忘框架，用forget-to-retain显著性分数在Transformer各层中挑选“对遗忘集影响大、对保留集不敏感”的层，把参数更新集中在少数最有效的层上，其余大部分模型保持不动。这种目标化更新策略一方面改善遗忘-效用权衡，另一方面减少被低比特舍入抹掉的小幅弥散更新，从而在经验上提升量化鲁棒性，作者明确不声称具有形式化擦除保证。
   - 结果：在TOFU、KnowUnDo与MUSE风格评测上，FOM-UL相较GA、NPO、KLD、SURE、ReLearn与LUNAR类强基线残留记忆更少，同时保留集效用接近原始模型。在8-bit与4-bit训练后量化下，它保持更强的记忆抑制与效用保持能力，对抗性提示下遗忘内容被恢复的比例也更低。整体上给出了提升定向遗忘、效用保持与部署稳健性的高效层级遗忘方案。

3. [PACE: Perceived-Latency-Aware Cascading Service Routing and Filler Control for QoE-Efficient Retrieval-Augmented Dialogue Serving](https://arxiv.org/abs/2609.10372v1)
   - 分类：Serving Systems / Retrieval-Augmented Dialogue QoE
   - 研究价值：值得精读
   - 关联：直接面向检索增强对话服务的推理时延与体验质量优化，是推理服务系统效率方向的代表性工作，且已在部署系统上验证。
   - 痛点：检索增强对话服务的用户体验主要由感知首响应时间PTFR决定，但已有工作分别优化级联路由、语义缓存或自适应检索，缺乏对“答案由哪个源生成”与“等待窗口用什么内容填充”的联合控制。此外路径填充内容可能与最终答案相互冲突，缓存中的过期回答会显著损害质量，高负载下RAG路径的延迟急剧上升，这些部署中的具体问题此前缺乏量化。
   - 方法：PACE把PTFR形式化为QoE目标，在质量与成本约束下联合优化答案来源与填充内容，包含三个机制：一是负载自适应级联路由器，根据当前负载动态决定走LLM还是RAG路径；二是联合路径填充控制器，协调等待期间的填充内容以避免与最终答案冲突；三是波动感知缓存准入策略，依据内容波动性决定缓存条目可用性，并对控制器设置门控规则保证不劣于基线，暴露时间以单个hold period为界。
   - 结果：在75k条CarQA请求与人形机器人销售服务部署中，级联路由把纯LLM的P95 PTFR降低约一半（c16下0.29s vs 0.53s）；自适应控制器达到0.41s P95，高负载下比RAG快2.4倍且质量相当；填充控制器减少94%的调用且零冲突，波动感知准入把过期回答占比从86%降至0%。门控规则保证控制器不劣于基线，并首次量化了已部署服务中填充答案的冲突风险。

**主要痛点**
- 长上下文推理受固定窗口限制，顺序记忆式方法延迟随长度线性增长且依赖昂贵RL训练。
- LLM敏感知识难以精准遗忘，宽泛参数更新损伤通用能力，且低比特量化后遗忘容易被逆转。
- 检索增强对话服务缺乏对答案来源与等待期填充内容的联合控制，高负载下首响应延迟与过期回答显著恶化体验。
- 联邦训练受通信延迟与掉队者效应拖累，生成式模型（VLA、扩散/一致性语音增强）采样步数多、部署成本高。

**方法趋势**
- 免训练的分层卷积式记忆，把线性链式长上下文推理改写为对数深度树并支持大规模并行。
- 层级显著性筛选（forget-to-retain score）实现层选择性遗忘，提升量化鲁棒性并降低训练代价。
- 以感知首响应时间为目标的级联路由、填充控制与波动感知缓存准入联合优化。
- SDN全局视图驱动的同步/异步客户端划分、频域条件流匹配、免教师一致性蒸馏与多语数据配比课程。

**结果信号**
- ConvMem在RULER长上下文多跳问答上超越免训练基线且可大规模并行。
- FOM-UL在TOFU/KnowUnDo/MUSE上残留记忆更少、效用接近原模型，8-bit与4-bit量化后仍保持优势。
- PACE在75k请求上把P95 PTFR减半、减少94%填充调用、过期回答从86%降至0%。
- HybridFLow达80%精度快33-40%；FreqFM在LIBERO-Plus提升9.3点；免教师蒸馏达PESQ 3.01/SI-SDR 19.07dB。

### 具身智能 / 强化学习

**今日推荐精读 Top 3**

1. [Show-Harness: Just a VLM Agent Can Play Robots](https://arxiv.org/abs/2609.10522v1)
   - 分类：Embodied Agents / VLM Robot Control
   - 研究价值：值得精读
   - 关联：与具身智能中VLM智能体直接控制机器人、跨本体泛化高度相关。
   - 痛点：当前视觉语言模型虽具备广泛世界知识，但把这种知识可靠地转化为机器人控制仍很困难。现有VLA方案通常需要针对特定本体做大规模预训练或微调，闭源前沿模型难以直接零样本控制机器人，开源小模型也难以低成本部署。同时，不同机器人本体之间缺乏统一、紧凑且可解释的语义动作接口，导致意图到动作的映射脆弱、示范采集依赖专业遥操作硬件。因此如何用统一接口释放基础VLM的具身能力是核心痛点。
   - 方法：提出Show-Harness，一个具身执行框架，通过紧凑语义动作单元连接VLM意图与机器人动作。VLM负责离散语义动作推理，本体特定解释器将语义动作确定性映射为本地机器人动作，保持VLM对细粒度物理决策的直接责任。还提出GUMI，把同一语义动作空间扩展到GUI示范采集，让人和智能体无需专用遥操作硬件即可跨本体“玩”机器人。该设计不增加模型容量，也无需昂贵的本体特定预训练，即可适配闭源前沿VLM和少量GPU小时微调的开源小模型。
   - 结果：在多项任务、本体和环境上，搭载Show-Harness的VLM智能体表现出稳健泛化，优于代表性智能体和VLA范式。实验证明闭源前沿VLM可直接用于零样本机器人控制，开源小VLM仅需少量GPU小时微调即可低成本部署，GUMI也能支持跨本体GUI示范采集。结论是合适的接口可以在不增加模型容量、不做昂贵本体预训练的情况下，从基础VLM中释放大量具身能力。该结果凸显语义接口设计对具身智能的重要性。

2. [DUET-DINO: Simultaneous Cross-View World Modeling for Latent Planning in Robot Manipulation](https://arxiv.org/abs/2609.10506v1)
   - 分类：Robot Manipulation / Latent World Models
   - 研究价值：值得精读
   - 关联：与具身智能中基于世界模型的7-DoF机器人操作和latent planning直接相关。
   - 痛点：动作条件潜在世界模型可预测未来视觉表征，从而支持零样本目标条件机器人规划，但其对细粒度空间和旋转动作的预测不可靠，难以覆盖完整7-DoF末端执行器控制。单视角模型缺乏全局场景与夹爪中心互补信息，独立双视角模型又未显式建模跨视角一致性，导致在角度敏感、抓取提升等任务上规划误差累积。如何用跨视角世界建模提升全动作空间规划可靠性，是机器人操作中的关键痛点。
   - 方法：提出DUET-DINO，一种同时跨视角潜在世界模型。它通过跨视角条件联合学习来自静态侧视相机和腕部相机的动作条件预测，利用全局场景与夹爪中心互补信息，支持完整7-DoF动作空间上的潜在规划。模型在DROID和RoboArena数据集上从零训练，并与V-JEPA 2及DINOv3等表征进行对比分析。方法核心是跨视角条件机制而非简单融合，使预测同时保留全局布局和局部交互细节。
   - 结果：在空间范围较大的reach、强调朝向的angled-reach以及多目标grasp-and-lift任务上，DUET-DINO持续优于单视角和独立双视角基线，成功率分别达到92%、72.5%和60.0%。模型从零训练于DROID和RoboArena，并在视觉分布偏移下保持稳健泛化。分析还发现V-JEPA 2腕部视角预测会低估细粒度动作引起的视觉动态，而DINOv3预测更能捕捉动作条件场景变化，从而带来更强下游规划。

3. [Semigroup-JEPA: Latent Dynamics Consistency for Zero-Shot Physics Generalization](https://arxiv.org/abs/2609.10464v1)
   - 分类：World Models / Reinforcement Learning
   - 研究价值：值得精读

### 1. [Programmable World Model](https://arxiv.org/abs/2609.10540v1)

- 关键词：world state, programmable world, video world, persistent world, world models, agent
- 链接：<https://arxiv.org/abs/2609.10540v1>

**原始摘要**
