1. [Model-Aware Schedules Improve Generation via Fiberwise Optimal Transport](https://arxiv.org/abs/2609.11842v1)
   - 分类：Diffusion Schedules / Optimal Transport
   - 研究价值：值得精读
   - 关联：直接关系到扩散/流匹配的噪声调度、最优传输与少步生成，是生成模型训练效率和采样质量的重要方法。
   - 痛点：扩散与流匹配的噪声/信号调度通常依赖人工设计或模型无关的最优传输动能目标，未考虑具体预测器在不同时间步的误差分布，导致训练与采样的计算分配次优，尤其在少步生成场景下 FID 等指标受限。此外，不同预测目标（x0、epsilon、velocity）、架构和数据集下缺乏统一的调度建模范式，既难以解释强基线为何有效，也难以为新模型自动构造更优路径。
   - 方法：作者在固定时间与状态位于概率路径时，将兼容的信号/噪声分解视为一条仿射纤维，在该纤维内用真实分解与预测器诱导分解之间的最优传输代价定义纤维内预测风险。将这一风险与系数路径的动能泛函结合，可在给定系数曲线上闭式求解最优时间分配；该构造可推广到一般线性预测目标，风险剖面还能从早期基线检查点估计，甚至使用冻结的解析分配模板。
   - 结果：在 DDPM 与流匹配上跨预测目标、训练配置、风险估计检查点、数据集和架构进行实验，模型感知调度一致优于强基线，其中 CIFAR-10 流匹配在 16 次函数评估下实现 38.6% 的相对 FID 降低。每个模型无关动能基线定义自身动能参考坐标，归一化到单位面积后，不同独立训练模型的风险剖面和训练调度形变高度对齐，表明经验普适性；该归一化风险一致性还扩展到更大的条件潜扩散与 2-RF 模型，冻结解析模板保留大部分增益。

2. [Logit Refiner: Improving Visual Autoregressive Models via Intra-Scale Dependency Modeling](https://arxiv.org/abs/2609.11804v1)
   - 分类：Visual Autoregressive Models / Decoding
   - 研究价值：值得精读
   - 关联：面向视觉自回归生成模型的解码瓶颈，与生成式AI中的VAR、图像生成和即插即用增强方法高度相关。
   - 痛点：视觉自回归模型 VAR 采用下一尺度预测，在每个尺度内并行生成全部 token。作者指出这种并行解码等价于均值场式近似，丢弃了同尺度 token 之间的空间依赖，导致无论主干容量多大都会出现局部不连贯样本，说明瓶颈来自解码规则本身而非模型容量或训练不足。现有改进多依赖重新训练或扩大主干，缺乏一种即插即用、低成本恢复尺度内依赖的机制，也缺少对瓶颈来源的受控消融验证。
   - 方法：作者提出 Logit Refiner，一个轻量级自回归模块，在冻结的 VAR 主干特征条件下顺序采样同一尺度内的 token，从而显式恢复被并行解码丢弃的尺度内依赖。该模块可插入任意预训练 VAR 检查点而无需重训主干，仅增加约 10% 参数和不到 5% 的基础模型训练算力；训练时通过可控消融隔离联合尺度内采样、额外容量与额外训练各自的作用，并验证方法对文本到图像等 VAR 变体的通用性。
   - 结果：在 ImageNet 256x256 类条件生成上，方法跨 310M 到 2B 参数主干均持续提升生成质量，使 1.1B 参数模型超越参数量两倍的模型。消融实验表明性能增益关键来自联合尺度内采样，而非额外容量或训练；该均值场瓶颈在文本到图像生成中同样存在，Logit Refiner 也能有效缓解，证明其可作为一种通用解码增强插件。

3. [SenseNova-U1.5: Towards Native Unified Visual Intelligence](https://arxiv.org/abs/2609.11929v1)
   - 分类：Unified Multimodal Generation / Native Visual Intelligence
   - 研究价值：值得精读
   - 关联：直接属于生成式AI与统一多模态模型方向，覆盖图像生成、编辑、文字渲染和多专家后训练，工程与系统参考价值高。
   - 痛点：现有多模态生成系统通常依赖独立视觉编码器和 VAE，理解与生成模块割裂，导致视觉接口信息损失、编辑一致性和主体身份保持困难；同时文字渲染、复杂构图、多参考编辑和交错生成等任务对统一表征与高分辨率原生训练提出更高要求，而面向不同能力的专门专家模型难以整合，后训练也容易在多种能力之间产生冲突。此外，如何让生成模型在训练数据中较少出现结构化格式的情况下，仍泛化到长而复杂的视觉指令，仍缺乏端到端方案。
   - 方法：SenseNova-U1.5 采用 8B-MoT 原生统一架构，去除视觉编码器与 VAE，通过空间一致 patch 重建强化视觉接口，并以精选生成与编辑数据、改进任务形式、结构化提示增强和最高 4K 原生分辨率进行扩展训练。后训练阶段分别优化视觉美学、双语文字渲染、信息图生成和图像编辑专家，再利用多专家 on-policy 蒸馏将能力整合进统一模型；训练代码将开源，包括监督微调、强化学习和 on-policy 蒸馏。
   - 结果：广泛评测显示，SenseNova-U1.5 在图像保真度、文字渲染、复杂构图、多参考编辑和交错生成上大幅进步，同时提升指令遵循并保持主体身份、几何与未修改区域。尽管生成数据对结构化格式暴露有限，模型仍能泛化到长、复杂和结构化视觉指令，证明多模态理解可迁移到视觉规划与创作；整体结果支持原生统一建模作为感知、推理与创造一体化端到端系统的可行路径。

**主要痛点**
- 扩散/流匹配调度忽略模型预测误差，少步生成计算分配次优。
- 视觉自回归并行解码丢弃尺度内依赖，导致局部不连贯。
- 统一多模态生成受编码器/VAE割裂和多能力后训练冲突限制。
- 拓扑空间推理与闭环规划缺乏系统评测，基础模型远低于人类。

**方法趋势**
- 用纤维最优传输风险构造模型感知调度并闭式分配时间。
- 以轻量 Logit Refiner 在冻结 VAR 主干上顺序采样同尺度 token。
- 8B-MoT 无编码器/VAE 统一建模，多专家 on-policy 蒸馏整合能力。
- 用局部去噪目标训练 looped flows，并以概率流积分做推理。
- 扩散超分以高分辨率影像引导 DSM，拓扑基准 MindTopo 评测推理与规划。

**结果信号**
- 模型感知调度在 CIFAR-10 流匹配 16 步下相对 FID 降低 38.6%。
- Logit Refiner 使 1.1B VAR 超越 2B 模型，文本到图像同样有效。
- SenseNova-U1.5 在保真度、文字渲染、编辑和交错生成上显著提升。
- MindTopo 显示所有 MLLM 推理优于规划且远低于人类。
- SEED-UMI 在接触丰富任务达到 70.0% 平均成功率。

1. [GPU-CFR: 80x Faster Counterfactual Regret Minimization by Compiling the Game to Static Dataflow and CUDA Graph Replay](https://arxiv.org/abs/2609.11923v1)
   - 分类：GPU Compiler / Game Solving Acceleration
   - 研究价值：值得精读
   - 关联：高效训练与推理：把一次性编译的静态数据流与 CUDA Graph Replay 结合，消除小 kernel 启动与框架调度开销，是典型的执行调度层面加速范式，可迁移到其它细粒度迭代式训练/求解负载。
   - 痛点：反事实遗憾最小化是少数至今仍在 CPU 上比 GPU 更快的数值负载：每次迭代要遍历多达数十亿状态、数百万次相互依赖的小规模 gather/scatter 步骤，这些步骤通过通用树接口发起；在 GPU 上每个 kernel 只运行数微秒，kernel 启动与框架派发开销完全主导运行时间，导致此前所有 GPU 实现都跑不过优化过的 CPU 代码，博弈求解的加速长期受限于调度而非算力。
   - 方法：作者观察到固定博弈下 CFR 迭代除数值外的一切在首次迭代前已知，据此提出 GPU-CFR 编译器与运行时：把任意博弈一次性编译为静态数据流（扁平边与信息集数组、预计算索引、按深度分层的批处理 pass），固定全部操作序列，仅求解器状态在迭代间变化；再用静态 chance 折叠、深度级执行块与双通道 reach buffer 把框架操作数减少最多 18.1 倍。由于形状、索引与缓冲区地址恒定，CUDA Graph 只录制一次迭代即可单次图启动重放。
   - 结果：在单张 A100、覆盖牌类/骰子/棋盘共八款游戏的套件上，GPU-CFR 比同卡最快的前沿 GPU CFR 快 29.8–80.4 倍，在四款最大游戏上比最快开源 CPU 实现 LiteEFG 快 14–258 倍；仅依赖编译表示、在八线程 CPU 无加速器时已比 GPU 基线快 2.2–51.1 倍，且该 CPU 路径按位复现参考迭代。图构建与图捕捉成本在首次求解内即被收回，在不改动更新规则的前提下全面击败所有 CPU 与 GPU 基线。

2. [Data Scarcity and Model Sparsity: Mixtures-of-Experts Overfit More to Repeated Data](https://arxiv.org/abs/2609.11917v1)
   - 分类：MoE / Data Repetition / Training Efficiency
   - 研究价值：值得精读
   - 关联：高效训练与推理：直接关系到数据受限下 MoE 预训练的可重复性策略与正则化选择，对稀疏模型的训练缩放与数据配方有直接指导价值。
   - 痛点：人类书写文本即将耗尽，重复训练数据已成为标准做法，但已有关于数据重复的研究几乎全部针对稠密 Transformer，对当前主流、计算效率更高的稀疏 MoE 架构基本空白；专家稀疏激活是否与重复数据产生更强的过拟合交互，直接决定数据受限时能否继续依赖 MoE 扩展，而此前没有任何关于重复倍率、稀疏度与退化程度之间定量关系的结果。
   - 方法：作者在 80M 到 1B 激活参数（8.5B 总参数）的模型上系统扫描数据重复倍率、单域与多域数据混合，以及专家数量与专家粒度等 MoE 设置，并与稠密模型在不同重复率下的退化曲线直接对比；同时试验 dropout 等现有正则化手段作为补救。分析层面则测量高重复率下的路由动态与专家专业化程度，刻画与 MoE 过拟合相关的内部机制。
   - 结果：结果显示 MoE 在数据重复下退化明显快于稠密模型，且随稀疏度增加而加剧，其严重程度由总参数而非激活参数决定：80M 稠密模型重复 8 倍几乎无损，MoE 在 4 倍即开始受损，32 倍后反而不如稠密模型。强掩码类正则（如 dropout）可显著缓解过拟合，使 MoE 在数据重复超过 64 倍时仍优于稠密模型，但没有任何方法能追平全唯一数据的表现；MoE 路由普遍在训练早期即稳定，专家专业化与对重复数据的过拟合正相关。

3. [Building py-kvcache: A Performance Characterization of External KV Caching for vLLM with NVMe SSDs](https://arxiv.org/abs/2609.11744v1)
   - 分类：LLM Serving / KV Cache Offloading
   - 研究价值：值得精读
   - 关联：高效训练与推理：长上下文推理服务的 TTFT 优化与外部 KV 缓存准入策略，直接服务于线上大模型推理系统的性能调优。
   - 痛点：前缀缓存可复用已计算的 KV 状态以降低长上下文请求的首 token 延迟，但短前缀或高带宽 GPU 场景下重新计算可能比从外部缓存加载更快，是否启用外置 KV 缓存缺少可依据的定量判据；同时缓存性能并不只取决于设备带宽，而受传输粒度、中间内存占用以及传输进入请求调度时机的影响，现有实现往往忽略这些因素，导致外部缓存在部分部署下收益为负。
   - 方法：作者在 vLLM 中跨 GPU、CPU、NVMe 三层构建外部 KV 缓存，用合成负载、长上下文基准与生产 trace 系统刻画上述折衷，并据此实现 py-kvcache：一个 vLLM KV Offload 连接器，采用异步直接 I/O、有界共享暂存区与调度器感知的预加载，在请求仍处于排队阶段就启动磁盘读取并与计算重叠；最终形成一套与部署配置相关的缓存准入决策方法。
   - 结果：在 80k token 场景下，py-kvcache 从磁盘加载比 LMCache 快 2.0 倍（其中预加载贡献 1.34 倍），GPU/CPU/磁盘三级缓存同时启用时比 LMCache 快 1.23 倍，并接近原生 vLLM KV Offload 的约 4% 以内。LongBench 与 SCBench 表明收益可延伸到不规则前缀链与多轮负载；但 Bailian trace 回放在较弱 GPU 上改善 TTFT，在 H100 上平均请求却低于盈亏平衡点，说明外置 KV 缓存应被当作与具体配置相关的准入决策。

**主要痛点**
- 细粒度迭代负载（如 CFR 博弈求解）在 GPU 上受 kernel 启动与框架调度开销主导，算力无法转化为吞吐。
- 数据受限时代不得不重复训练数据，而稀疏 MoE 在重复数据下过拟合远快于稠密模型，缺乏系统结论与补救方案。
- 长上下文推理的外部 KV 缓存在短前缀或高带宽 GPU 上可能负收益，缓存是否启用缺少可依据的准入判据。
- 扩散/流匹配调度与模型无关，忽略预测误差，导致少步采样质量受限。
- 推理时监控与安全检测对延迟敏感，扰动式或额外生成式方案难以常开部署。

**方法趋势**
- 编译式静态数据流加 CUDA Graph Replay，消除小 kernel 与框架派发开销（GPU-CFR）。
- 跨 GPU/CPU/NVMe 三层系统刻画 + 异步直接 I/O、有界暂存与调度器感知预加载（py-kvcache）。
- 在 80M–1B 激活参数 MoE 上扫描数据重复倍率、专家粒度与正则化，并分析路由/专家专业化。
- 以纤维式最优传输定义模型感知预测风险，闭式求解最优时间分配（扩散调度）。
- 复用投机解码的草稿-目标验证信号做零额外计算的推理时后门检测（SpecGuard）。

**结果信号**
- GPU-CFR 在 A100 上比前沿 GPU 实现快 29.8–80.4 倍、比最快 CPU 实现快 14–258 倍，CPU 路径按位复现参考迭代。
- MoE 在 4 倍数据重复即受损、32 倍后不如稠密模型；强掩码正则可让 MoE 在 64 倍以上重复仍占优但追不平全唯一数据。
- py-kvcache 在 80k token 下加载比 LMCache 快 2.0 倍、三级缓存下快 1.23 倍，但 H100 上生产 trace 平均请求低于盈亏平衡点。
- 模型感知调度在 CIFAR-10 流匹配 16 NFE 下 FID 相对降低 38.6%，风险曲线归一化后跨模型高度一致。
- SpecGuard 在不增加模型计算的前提下跨后门类型与模型家族可靠检测触发行为。

1. [UniMPA: A Unified Memory-Prediction-Action Model via Action-Grounded Transition Modeling](https://arxiv.org/abs/2609.11875v1)

   - 研究价值：值得精读
   - 关联：直接命中具身智能核心：VLA 操作策略的观测-动作映射、未来预测可执行性与经验复用，可作为机器人操作与记忆增强策略的重要参考。
   - 痛点：现有 VLA 模型从观测直接映射到动作，存在“转移动可实现性鸿沟”，并表现为三个相互耦合的问题：一是转移歧义，视觉相似的当前观测可能对应不同操作阶段、暗示不同的后续转移；二是预测-执行错配，视觉上看似合理的未来观测预测未必对应物理上可实现的转移；三是经验-现实错配，历史上可执行的动作模式在当前场景中未必能实现意图转移，需要上下文自适应。这三个问题使仅靠扩大数据或模型规模难以奏效，根源在于观测到动作之间缺少一个以动作为锚的转移接口。

   - 结果：摘要未给出具体量化指标，论文的贡献主要在于提出以动作为锚的转移建模接口，并针对转移歧义、预测-执行错配、经验-现实错配分别设计了持久-选择性未来预测、时序视觉-动作记忆库检索与动作-视觉记忆库原型偏置流三项机制，使未来预测被约束在可执行证据上、历史经验被适配到当前场景。后续需关注其在真实机器人上的操作成功率、长程与接触丰富任务表现，以及记忆库检索、原型偏置流各自的消融结论。

### 4. [Model-Aware Schedules Improve Generation via Fiberwise Optimal Transport](https://arxiv.org/abs/2609.11842v1)

- 来源：arXiv
- 关键词：model-aware schedules, fiberwise optimal transport., diffusion, closed-form optimal TIME allocation., model-aware improvement without further, architectures. our model-aware
- 链接：<https://arxiv.org/abs/2609.11842v1>

**原始摘要**

Here we introduce a model-aware schedule construction based on fiberwise optimal transport. At a fixed time and state on the probability path, compatible signal/noise decompositions form an affine fiber. ### 6. [Thinking with Looped Flows](https://arxiv.org/abs/2609.11801v1)

We observe a visual-textual duality: language memories carry long-range temporal structure better than dense frames, while pixels remain decisive for attribute-level perception. Building on this insight, we propose Caption-once, Frames-onDemand (CFD), a budget-aware edge-cloud agentic framework. The edge runs a single offline captioning pass that builds a dual-track narrative index, an event-level story skeleton plus a clip-level micro-log, cached and reused across queries without re-captioning. At query time, a cloud-side MLLM reasons over the index in a story-first loop centered on a lightweight Visual-Need Router: a per-query gating module that triggers bounded keyframe retrieval only for perceptual questions (appearance, on-screen text, attribute disambiguation) and keeps temporal-structural questions in language space. The router turns visual access into a first-class, query-conditioned cost, capping per-query frame consumption regardless of video length. Experiments on long-video benchmarks demonstrate strong accuracy-efficiency trade-offs while substantially reducing online visual processing.

### 3. [Learning Agent-based Model Predictive Control for Holistic Vehicle Performance](https://arxiv.org/abs/2609.11871v1)

- 来源：arXiv
- 关键词：agent-based model predictive control, learning agent-based, hybrid control scheme, holistic vehicle, multi-agent, agent-based MPC lampc combining
- 链接：<https://arxiv.org/abs/2609.11871v1>

**原始摘要**

Agent-based model predictive control (AMPC) has recently been proposed as a distributed scheme that collaborates with all agents to achieve optimal holistic performance. However, its optimality highly depends on the prediction accuracy that requires all agents or their contributions to be known, which is too idealistic for actual implementation. This research proposes a novel practical hybrid control scheme - learning agent-based MPC (LAMPC), combining the model-based AMPC approach and data-based learning methods to improve the holistic vehicle performance for multi-agent systems. The Gaussian process regression (GPR) enhanced by an online data management strategy serves as the learning core to predict unknown contributions. A novel multi-step prediction mechanism leverages the GPR learning potential along the horizon. The predicted mean, representing the learned unknown contributions, completes the system model in the MPC for more accurate control. Meanwhile, a stochastic framework is formulated to guarantee control safety and feasibility using soft chance constraints based on the prediction variance. Both simulations and experiments show that, with the learning capability, LAMPC outperforms the traditional AMPC. LAMPC can achieve higher tracking performance in well-learned scenarios and always guarantee constraint satisfaction even in less-learned scenarios. Moreover, the proposed hybrid control scheme is efficient for real-time implementation and is flexible to any control agent topology.
