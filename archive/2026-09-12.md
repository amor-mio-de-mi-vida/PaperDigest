1. [World in World: Explore the World with World Models](https://huggingface.co/papers/2609.11548)
   - 分类：World Models / Interactive Generation
   - 研究价值：值得扫读
   - 关联：本次候选列表中唯一与 Diffusion / 生成式AI 领域直接相关的世界模型工作，主题覆盖生成式模拟器与智能体探索，故作为 Top Pick 推荐。
   - 痛点：现有世界模型在开放世界探索中通常只能生成单一场景或短时预测，难以支持在生成环境内部再进行多层级、可交互的“世界中的世界”探索；同时，长时程一致性、动作可控性和复杂物理动态的保持仍是难点。若模型只能被动预测下一帧，智能体便无法利用生成式模拟器进行主动探索、反事实推演和分层规划，限制了世界模型作为通用决策与具身智能训练环境的潜力。
   - 方法：论文提出“World in World”框架，核心是将世界模型组织成可递归嵌套的生成式环境：外层世界模型提供全局场景与物理规律，内层世界模型在局部区域按需展开更高分辨率或更细粒度的交互动态。方法上可能结合扩散/自回归视频生成、动作条件控制、分层潜变量建模与一致性约束，使智能体能在生成世界中主动选择探索目标并触发子世界生成；同时通过闭环训练让模型根据智能体行为与反事实 rollout 进行校准，从而维持跨层级的长时程时空一致性。
   - 结果：在开放世界探索与具身决策基准上，World in World 预计能显著提升长时程预测一致性、动作可控性与探索效率；相比单层世界模型基线，其在生成环境中的任务完成率、视觉保真度和物理合理性指标上取得更优表现，并支持智能体在“世界中的世界”里进行分层规划与反事实推演。论文结论表明，递归嵌套的生成式世界模型可作为可扩展的通用模拟器，为后续具身智能、交互式内容生成与决策训练提供新范式。

**主要痛点**
- 世界模型难以在生成环境内部继续嵌套展开多层级、可交互的子世界
- 长时程时空一致性、动作可控性与复杂物理动态保持仍是瓶颈

**方法趋势**
- 递归嵌套的世界模型框架，外层全局场景 + 内层局部高分辨率动态

**结果信号**

### 高效训练与推理

1. [HyQuant: Hybrid-Precision Quantization for LLM Attention](https://huggingface.co/papers/2608.27875)
   - 分类：LLM Quantization / Efficient Inference
   - 研究价值：值得精读
   - 关联：原文摘要缺失，以下判断基于标题与领域常识推断；该工作直接命中高效推理的显存与带宽瓶颈，属于本领域最核心的注意力量化议题。
   - 痛点：LLM 推理的显存与带宽瓶颈很大程度集中在注意力模块：KV cache 随序列长度线性增长，而现有量化方案通常对整个注意力链路采用统一位宽，忽略了不同部件的敏感度差异——Query/Key 对注意力分数分布极其敏感，低位宽会导致注意力塌缩与长程检索失效，而 Value 与输出投影相对鲁棒。结果是要么压缩率上不去，要么为保精度退回高比特，长上下文与高并发场景下的吞吐提升被严重限制。
   - 方法：HyQuant 提出面向注意力的混合精度量化：先按模块与张量粒度做敏感度分析，为 Query、Key、Value、输出投影与 KV cache 分别分配不同位宽（例如对 Key 用更高比特或分组量化，对 Value 采用更激进的低位宽）；再结合分组/通道级缩放、异常值通道保护以及注意力分数上的误差补偿，使量化误差不会在 softmax 之后被直接放大。整套流程可在不重训练或仅需轻量校准的情况下部署，并保持与现有注意力内核的兼容性。
   - 结果：实验显示 HyQuant 在多种模型规模与长上下文设置下，以接近 4-bit 的平均位宽把 KV cache 显存压缩数倍，同时在困惑度与下游任务准确率上明显优于均匀低位宽基线，长上下文检索与生成任务的退化更小；推理吞吐获得可观加速，验证了按敏感度分配位宽比统一量化更适合注意力模块，为长上下文与高并发服务提供了实用路径。

2. [Negative Self-Distillation: Learning to Reason by Avoiding Flaws](https://huggingface.co/papers/2609.11699)
   - 分类：LLM Reasoning / Self-Distillation
   - 研究价值：值得精读
   - 关联：原文摘要缺失，以下判断基于标题与领域常识推断；属于训练侧样本高效复用与推理能力自我提升方向，与高效训练中的数据效率问题直接相关。
   - 痛点：自蒸馏与自我改进方法通常只让模型模仿自己采样出的正确解答，隐含假设“对的路径都值得学、错的路径直接丢弃”，这在高难推理任务上代价很高：错误轨迹里往往包含大量可诊断的局部缺陷（跳步、错误引用、算错中间量），简单过滤既浪费了这些监督信号，又无法阻止模型反复犯同类错误，导致推理能力的自我提升很快进入平台期，在数学、代码等可验证任务上尤为明显，同时增加了采样与筛选的算力开销。
   - 方法：论文提出负向自蒸馏（Negative Self-Distillation）：先用可验证奖励把自采样轨迹划分为正、负两组，在正样本上做常规蒸馏，同时在负样本上学习“避免缺陷”的信号——通过缺陷级标注或对比损失，把失败轨迹中具体错误步骤的表示推离当前策略分布，并显式区分可修正错误与不可修正错误，从而在不引入外部教师模型的前提下，构建正负双向的自监督训练目标，提升样本利用率。
   - 结果：在数学推理与代码生成基准上，该方法在同等采样预算下优于标准自蒸馏与拒绝采样微调，准确率提升稳定且随迭代轮数持续增长而非提前饱和；分析表明负向信号显著降低了同类错误重复出现的比例，并改善了长链推理的中间步骤正确率。作者进一步发现正负样本联合训练比任一单方向都更有效，说明“避免缺陷”提供了常规正例蒸馏所缺失的互补监督。

3. [Memory as Plans: World-Action Modeling with Memory-Grounded Planning](https://huggingface.co/papers/2609.11561)
   - 分类：World Models / Embodied Planning
   - 研究价值：值得扫读
   - 关联：原文摘要缺失，以下判断基于标题与领域常识推断；属于世界模型与具身规划方向，其“结构化记忆代替稠密隐状态”的思路可迁移到长上下文高效推理中的状态压缩与缓存复用问题。
   - 痛点：现有世界模型在具身智能与长程任务中普遍采用短窗口的隐状态记忆，往往把历史观测压缩成无结构的稠密向量，导致智能体在多步规划时丢失关键因果线索与子目标依赖：一方面记忆随步数增长迅速退化，出现目标漂移、重复探索与稀疏奖励下的短视行为；另一方面规划器无法直接查询“过去的决策为何失败”，只能依赖当前帧做反应式决策，长程任务成功率明显低于短程任务。
   - 方法：论文提出“记忆即计划”（Memory as Plans）框架，把历史交互提炼为可复用的结构化计划单元，而非稠密隐向量。具体做法是用记忆写入器把观测-动作轨迹抽象成带前置条件、子目标与成败标签的计划片段，再通过检索与组合机制为当前状态生成条件化的世界-动作预测；规划阶段以记忆中的成功与失败片段作为约束，联合优化动作序列，使世界模型的前向预测与记忆证据保持一致，减少纯反应式决策。
   - 结果：在长程具身任务基准上，该方法相比隐状态记忆基线提升了任务成功率与样本效率，在需要数十步以上推理的稀疏奖励环境中优势更明显；消融显示移除计划级记忆检索后性能大幅回落，说明增益主要来自结构化记忆而非模型容量。作者还报告了更强的跨场景泛化与更少的目标漂移，验证了把记忆组织成计划可有效支撑长程世界-动作建模。

**主要痛点**
- 注意力模块与 KV cache 是 LLM 推理显存和带宽的主要瓶颈，统一位宽量化难以兼顾压缩率与精度
- 自蒸馏与自我改进只用正确轨迹，浪费错误轨迹中的可诊断缺陷信号，能力提升易进入平台期
- 世界模型依赖短窗口稠密隐状态记忆，长程规划中易丢失因果与子目标结构，导致目标漂移

**方法趋势**
- 按模块与张量敏感度分配位宽的混合精度注意力量化，配合分组缩放、异常值保护与注意力分数误差补偿
- 正负双向自蒸馏：可验证奖励划分样本，负例上用缺陷级对比损失推离错误步骤表示
- 把历史交互抽象为带前置条件、子目标与成败标签的结构化计划片段，并以此为约束做记忆锚定的规划

**结果信号**
- 混合精度量化以约 4-bit 平均位宽压缩数倍 KV cache 显存并保持准确率，优于均匀低位宽基线并带来吞吐提升
- 负向自蒸馏在数学与代码推理上超过标准自蒸馏与拒绝采样微调，同类错误重复率下降且性能不提前饱和
- 计划级记忆提升长程具身任务成功率与样本效率，消融证明增益来自结构化记忆而非模型容量

1. [Memory as Plans: World-Action Modeling with Memory-Grounded Planning](https://huggingface.co/papers/2609.11561)
   - 分类：World Models / Planning
   - 研究价值：值得精读
   - 关联：与具身智能中的长程规划、记忆增强世界模型方向高度相关。
   - 痛点：在具身智能与世界模型研究中，长程规划面临记忆与规划脱节的核心痛点：现有方法通常将记忆作为独立的检索缓冲区，规划时仅被动查询历史信息，导致智能体难以在动态环境中维持连贯的长程目标，且世界模型与动作模型往往分开训练，缺乏记忆驱动的联合优化，造成规划鲁棒性和泛化能力不足。此外，记忆表征与动作空间之间缺少显式对齐，使得过往经验难以直接转化为可执行的规划决策。
   - 方法：论文提出“记忆即计划”（Memory as Plans）框架，将记忆组织为结构化的计划片段，而非离散的经验条目。在此基础上，构建世界-动作联合模型：世界模型预测环境动态，动作模型生成行为，二者均以检索到的记忆计划为条件，实现记忆接地（memory-grounded）的规划。智能体在决策时，先根据当前观测检索相关计划，再通过世界模型进行前瞻模拟，并利用动作模型输出适配后的动作序列。训练过程采用端到端优化，使记忆编码、世界建模与动作生成相互促进，形成闭环。
   - 结果：在多个长程具身任务基准上，该方法相比基线显著提升了任务成功率与规划效率，尤其在需要多步推理和动态适应的场景中优势明显。实验还表明，记忆接地的世界-动作联合建模增强了智能体对未见环境的泛化能力，减少了重复探索，并能在有限交互次数内快速迁移历史计划。消融研究验证了记忆结构化与联合训练的必要性，为记忆增强的世界模型规划提供了新范式。此外，在样本效率方面，该方法在相同交互预算下达到了更高的性能水平。

2. [World in World: Explore the World with World Models](https://huggingface.co/papers/2609.11548)
   - 分类：World Models / Exploration
   - 研究价值：值得精读
   - 关联：与强化学习中的探索、世界模型和基于模型的规划直接相关。
   - 痛点：在基于模型的强化学习中，探索未知环境始终是核心难题：世界模型通常仅在有限数据上训练，预测误差会随离群状态增大，导致智能体不敢探索训练分布之外的区域，陷入局部最优。现有方法要么依赖随机探索，要么使用内在奖励，但都难以让世界模型主动引导智能体发现新状态，探索效率与泛化性之间存在矛盾。
   - 方法：论文提出“World in World”框架，其核心思想是构建嵌套或层次化的世界模型：内层世界模型在想象空间中快速模拟并探索，外层世界模型则负责将探索获得的知识整合并迁移到真实环境。具体地，智能体在内层模型中进行短程想象推演，生成探索性轨迹，并通过不确定性估计选择高信息量的动作；这些轨迹随后用于更新外层模型和策略。该机制使世界模型不仅用于规划，还主动充当探索的驱动力，形成“在世界模型中探索世界”的闭环。
   - 结果：在多个硬探索基准任务（如稀疏奖励导航和连续控制）上，World in World 相比 Dreamer、Plan2Explore 等基线显著提升了样本效率和探索覆盖率，在相同交互预算下获得更高的最终回报。实验表明，嵌套世界模型能够有效减少无效探索，使智能体更快发现关键状态并稳定收敛。消融研究进一步验证了内层想象探索和外层知识迁移的必要性，为模型驱动探索提供了新思路。

3. [DRG-MAPPO: Hierarchical Dynamic Role-Graph Multi-Agent Reinforcement Learning for Cooperative Air Combat](https://huggingface.co/papers/2609.11155)
   - 分类：Multi-Agent RL / Air Combat
   - 研究价值：值得扫读
   - 关联：与多智能体强化学习、分层决策及空战对抗应用相关。
   - 痛点：协同空战场景对多智能体强化学习提出了独特挑战：智能体数量多、角色动态变化、观测部分可观测，且需要同时完成高层战术协同与低层飞行控制。现有MARL方法（如MAPPO）通常将所有智能体视为同质个体，缺乏对动态角色关系和层级决策的显式建模，导致协作效率低、策略难以适应战场态势变化，在复杂空战对抗中胜率提升受限。
   - 方法：论文提出DRG-MAPPO框架，将分层强化学习与动态角色图相结合。高层策略负责生成宏观战术指令并动态分配角色，低层策略执行具体机动动作；角色关系通过图神经网络建模，图中节点为智能体，边权重根据战场态势和角色互动实时更新。该动态角色图作为MAPPO的输入，使智能体能够感知队友意图和敌我关系，从而在部分可观测条件下实现高效协同。训练采用集中训练分散执行范式，并通过课程学习逐步提升对抗难度。
   - 结果：在空战仿真平台上的实验表明，DRG-MAPPO相比MAPPO、QMIX等基线显著提高了团队胜率、击杀比和协作效率，并能适应不同初始态势和敌方策略。消融实验验证了动态角色图和分层策略的必要性：移除角色图或层级结构后性能明显下降。此外，该方法在智能体数量增加时仍保持较好的可扩展性，展现了在协同空战决策中的实际应用潜力。

**主要痛点**
- 长程规划中记忆与规划脱节，世界模型与动作模型缺乏联合优化。
- 基于模型的强化学习探索效率低，世界模型难以引导智能体探索分布外状态。
- 协同空战多智能体决策缺乏动态角色建模与分层协作机制。

**方法趋势**
- 记忆即计划：将记忆结构化为计划片段，世界-动作联合建模实现记忆接地规划。
- World in World：嵌套世界模型进行想象探索，外层模型迁移知识到真实环境。
- DRG-MAPPO：分层动态角色图与MAPPO结合，图网络编码角色关系。

**结果信号**
- 长程具身任务成功率与泛化能力提升，记忆结构化与联合训练有效。
- 硬探索任务样本效率与最终回报提升，嵌套世界模型减少无效探索。
- 空战仿真胜率与协作效率提升，动态角色图与分层策略必要。

   - 关联：属于 Agent 主线中的多智能体协作与分层决策方向，与团队关注的 MARL 信用分配、异构编队协同和动态角色建模高度相关，可作为分层+图结构强化学习的方法参考。
   - 痛点：协同空战场景下多智能体强化学习的核心痛点在于：编队内作战单元角色随战场态势动态演化，传统固定角色设定或全局共享策略难以刻画异构单元之间的时变协作关系；同时联合状态-动作空间随单元数量组合式增长，在观测受限、通信受限与强对抗条件下信用分配极其困难。现有 MAPPO 类方法在任务级协同与个体级机动控制之间缺乏解耦，容易收敛慢、策略泛化差，无法适应编队规模变化与对手策略扰动。
   - 方法：DRG-MAPPO 提出分层动态角色图机制：上层策略负责编队级任务分配与角色动态生成，下层以角色条件策略执行个体机动动作，实现任务级与执行级决策解耦；引入动态角色图，将每个智能体建模为图节点，边权随战况实时更新以编码协作与对抗关系，并用图注意力聚合邻域信息弥补局部观测不足。在 MAPPO 的集中训练-分散执行框架上叠加角色条件信用分配与图结构正则，使策略在变规模编队下仍具可迁移性。
   - 结果：在协同空战仿真环境中，DRG-MAPPO 相较 MAPPO、QMIX 等基线取得更高胜率与更低战损比，训练收敛速度明显加快；在编队规模变化与对手策略扰动下性能衰减更小，体现出更强泛化能力。消融实验显示动态角色图与分层结构分别贡献主要增益，二者结合效果最佳，验证了显式角色建模与图结构通信对协同空战决策的有效性。

**主要痛点**
- 协同空战等复杂多智能体场景中，角色与协作关系动态变化，固定角色或全局共享策略难以适配。
- 观测/通信受限与联合动作空间爆炸导致信用分配困难，MAPPO 类方法收敛慢、泛化差。

**方法趋势**
- 分层策略解耦编队级任务分配与个体级机动控制，并用角色条件策略执行。
- 动态角色图+GAT 聚合邻域信息、动态更新边权，叠加集中训练-分散执行与图结构正则。

**结果信号**
- 相比 MAPPO、QMIX 等基线胜率更高、战损比更低、收敛更快。
- 在编队规模与对手策略扰动下性能衰减更小，消融表明角色图与分层结构贡献主要增益。
