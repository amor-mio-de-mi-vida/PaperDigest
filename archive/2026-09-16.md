1. [PhysStream: Streaming Physics-Grounded Video Generation with Structured Scene Memory and Fine-Grained Motion Control](https://arxiv.org/abs/2609.17521v1)
   - 分类：Physics-Grounded Video Generation
   - 研究价值：值得精读
   - 关联：与视频生成、可控生成和物理仿真交叉，可直接启发扩散视频模型的流式交互控制。
   - 痛点：现有可控视频生成要么在生成前要求给定完整控制序列，无法在生成过程中交互调整，要么只用像素级位置信号约束物体位置，难以表达速度、加速度等物理动力学；多物体桌面刚体场景尤其缺乏细粒度、物理 grounded 的流式控制，导致长时生成中的物理一致性与轨迹可控性不足。像素空间控制没有显式物理量，模型难以从交互中学习真实动力学，也无法支持生成中途改变动作意图。
   - 方法：PhysStream 是自回归图像到视频模型，核心是结构化场景记忆与细粒度运动控制。它在线从已生成帧中导出位置图和物体跟踪图，形成结构化场景记忆，并用稀疏速度增量信号编码物理量，让模型学习底层动力学；训练分两阶段：先以运动控制条件微调双向模型，再训练因果自回归模型并加入结构化场景记忆以提升物理一致性。该方法支持多物体交互和生成中途控制，使模型能根据物理量而非仅像素位置预测未来帧。
   - 结果：在合成基准上，PhysStream 相比最强基线将运动分布距离 FVMD 降低 33%，轨迹误差降低 12%，并支持多物体桌面刚体场景的生成中交互控制，这是此前方法不具备的能力；在真实场景对比中，人类评估者在超过 85% 的比较里更偏好 PhysStream。这些结果表明结构化场景记忆和物理量控制能显著提升流式视频生成的物理一致性与可控性，并为交互式视频生成提供可复制框架。

2. [SlotDiT: Object-Centric Representations for Diffusion Transformers](https://arxiv.org/abs/2609.17414v1)
   - 分类：Object-Centric Diffusion Transformer
   - 研究价值：值得精读
   - 关联：与 DiT latent 设计、视频生成和机器人策略学习直接相关，是表示空间研究的重要参考。
   - 痛点：文本条件 latent diffusion 与 DiT 在视频生成和机器人任务上表现强，但现有方法多依赖像素级或 VAE latent，缺乏显式语义结构，表示空间设计对生成质量、任务完成率和计算效率的影响尚未被系统研究；机器人场景还要求模型能分解物体并预测可执行轨迹，而统一 DiT 框架下不同 latent 表示的取舍缺少公平比较。这限制了可解释、可组合且高效的生成式建模，也阻碍生成模型直接服务下游决策。
   - 方法：SlotDiT 提出在 slot-based object-centric latent 空间运行的文本引导 Diffusion Transformer。给定参考图像和语言指令，模型把场景分解为表示单个实体的 object-centric slots，并以指令和已观察场景为条件，自回归地去噪未来 slot 轨迹来预测场景动态；作者在统一 DiT 框架内系统比较 slot、VAE 和语义对齐表示，以隔离 latent 空间设计对生成与机器人任务的影响。
   - 结果：实验表明，slot 作为 DiT latent 能取得有竞争力的视频生成质量，同时在四个机器人数据集上持续提升任务完成率，并且其紧凑表示比 VAE 和语义对齐 latent 更计算高效。跨数据集一致提升表明该优势不依赖特定任务，说明 object-centric 结构是机器人环境中基于扩散的生成建模的有效归纳偏置，也为下游策略学习提供了结构化 latent 方案。项目页提供可视化与实现细节，便于复现和扩展到新机器人环境。

3. [XPACE: Joint World and Action Modeling from Heterogeneous Experience](https://arxiv.org/abs/2609.17372v1)
   - 分类：Embodied World Model
   - 研究价值：值得精读
   - 关联：与生成式世界模型、视频预测和具身策略学习高度相关，可作为联合建模参考。
   - 痛点：通用机器人需要从异构经验中学习：既有大量无动作视频，也有人类和机器人演示，还要预测动作后果并持续改进策略。现有世界模型与策略往往分离，难以把无动作视频连接到动作学习，也难以利用模型自身模拟器生成新经验来自我改进；机器人演示稀缺时，策略对偏差恢复和未见任务尤其脆弱。因此如何联合建模世界与动作，并桥接异构经验，是具身智能和生成式世界模型的核心痛点。
   - 方法：XPACE 是一个统一具身世界模型，共享视频 backbone，同时充当 world action model 联合预测可执行机器人动作和未来视频，以及 world simulator 预测给定动作的视觉后果。它用无动作视频学习视觉动态，用人类和机器人演示联合学习视频与动作预测，并通过粗到细课程逐步强调机器人控制；进一步让模拟器适应自身生成上下文，合成偏差恢复轨迹并过滤后微调策略。
   - 结果：在 XPENG IRON 人形机器人上，异构训练提升了鲁棒性，并把从人类观察到的技能迁移到机器人演示未覆盖的任务；模型自身模拟器生成的恢复数据进一步提高了真实世界任务完成率。这些结果说明联合世界与动作建模能把异构经验学习与模拟驱动的策略自改进连接起来，为通用机器人提供可扩展范式，也显示视频预测可作为连接异构经验与动作学习的桥梁。

**主要痛点**
- 可控视频生成缺少生成中交互与物理量控制，长时物理一致性不足。
- 扩散 Transformer 的 latent 表示缺乏显式语义结构，生成与下游任务受表示空间限制。
- 具身世界模型与策略分离，难以利用无动作视频和模拟器自生成经验改进策略。
- 单图新视角合成过度依赖生成式 inpainting，易产生幻觉并破坏原场景结构。

**方法趋势**
- 结构化场景记忆、稀疏速度增量信号与两阶段自回归训练。
- 在 slot-based object-centric latent 空间训练文本引导 DiT，并统一比较多种 latent。
- 共享视频 backbone 联合世界/动作建模，粗到细课程与模拟器合成恢复轨迹。
- 遮挡感知 Gaussian-anchor 重建，按缺失区域大小选择 RGB-D 修复或生成式补全。

**结果信号**

- SlotDiT 在四个机器人数据集提升任务完成率，且表示更紧凑高效。
- XPACE 在 XPENG IRON 上提升鲁棒性、技能迁移和真实任务完成率。

1. [JustFit: 200K-Token LLM Serving on a 24 GiB Laptop with Just-in-Time State Management](https://arxiv.org/abs/2609.17475v1)
   - 分类：LLM Inference Serving / KV Cache Management
   - 研究价值：值得精读
   - 关联：直接对应高效推理：面向边缘设备的长上下文 serving，核心是 KV 与执行状态的即时管理，可迁移到任何内存受限的 LLM 推理部署。
   - 痛点：长上下文 LLM 在笔记本等边缘设备上部署时，KV cache 与执行状态会迅速耗尽内存；现有推理运行时即便对模型权重做量化，也无法在 24 GiB 内存中支撑 20 万 token 级别的单请求上下文，使本地长上下文推理的可用窗口被硬件内存硬性限制，难以支撑需要超长生成式推理的编码与推理任务，同时传统方案对 KV 与中间状态的生命周期缺乏细粒度管理，重建开销与内存驻留策略相互牵制。
   - 方法：提出 MLX 上的推理运行时 JustFit，包含 KVExec（压缩 KV 执行）、PhaseSwap（组件驻留与换出）与 StateTrans（保状态的 serving 切换）三个机制，把重建与即时物化、释放解耦，并使其独立于模型权重量化；运行时按执行生命周期协调 KV 与中间状态的物化与回收，在单机内存预算内实现超长上下文的即时状态管理。
   - 结果：在 24 GiB M4 Pro MacBook 上运行 Qwen3.8-27B MXFP4，三次独立运行均完成 196,608 输入 token 与 16,384 输出 token，单请求完成上下文从 mlx-vlm 基线的 30,720 提升到 212,992（6.93×），双请求聚合保留 229,376 位置；独立性能测试中 32K 输入、64 输出探针达 19.11 tokens/s，重复 32K+6K 负载的峰值进程内存中位数为 16,374 MiB，并在 AIME 2026 上答对 29/30。

2. [FlashVector: Agent for Hierarchical Model Serving Stack Optimization](https://arxiv.org/abs/2609.17391v1)
   - 分类：Model Serving Optimization / LLM Agent for Systems
   - 研究价值：值得精读
   - 关联：直接对应高效推理与服务成本：把 agent 优化从单个 GPU kernel 扩展到整条模型 serving 栈，是生产推荐系统降本的代表性工作。
   - 痛点：推荐系统模型 serving 是生产成本的最大来源之一，其吞吐由 GPU kernel、ML 计算图、模型服务器与按需特征处理构成的深层异构栈共同决定；跨层优化需要同时具备多个领域专家的知识，这种能力难以获得也无法随持续增长演进的负载扩展，导致大量成本效率收益未被释放。与此同时，现有 AI agent 虽能在单个 GPU kernel 优化上达到专家水平，却几乎没有自动化整个 serving 栈其余部分的调优。
   - 方法：提出 agentic 系统 FlashVector，把单 kernel 优化 agent 范式推广为可扩展框架，覆盖 GPU kernel、ML 计算图、模型服务器（NVIDIA Triton 的 C++ 代码库）与按需特征变换服务（Python 代码库）等异构技术栈；agent 在这些层上自主发现并落地优化，以整体方式交付性能改进，而非只做孤立 kernel 调优；框架强调可扩展性，使同一套 agent 方法能迁移到更复杂的系统架构与语言栈。
   - 结果：在 Unity 的 Vector 广告平台部署后，FlashVector 在模型服务器上实现最高 2× 吞吐提升与最高 1.98× 延迟加速，在特征存储上实现最高 1.6× 吞吐提升；优化不仅出现在 GPU kernel 与计算图层面，也出现在模型服务器与按需特征变换服务等组件，验证了框架向更复杂系统架构扩展的可行性；该工作把 kernel 级 agent 优化经验系统化地推广到服务器与数据服务代码层。

3. [What Breaks Under Pruning in Smart Homes, and When? Evaluating LLM Degradation Across Architectures and Task Complexity](https://arxiv.org/abs/2609.17515v1)
   - 分类：LLM Pruning / Efficient Inference
   - 研究价值：值得精读
   - 关联：直接对应高效推理中的剪枝选型：给出跨架构、跨任务复杂度的退化画像，对部署剪枝模型做工具调用有直接指导意义。
   - 痛点：剪枝是降低 LLM 部署成本的关键手段，但在需要基于上下文进行工具调用的智能家居场景中，剪枝造成的退化模式仍不清楚；现有评测通常只看聚合任务准确率，无法揭示剪枝究竟先破坏动作的哪些组成部分、在什么任务复杂度下开始失效，也掩盖了稠密模型与 MoE 模型在安全剪枝区间上的巨大差异，使实际选型缺乏可靠依据；更严重的是，剪枝还可能引发过度拒答等行为退化，而这类失败在聚合指标中完全不可见。
   - 方法：系统研究四种 LLM（稠密 Transformer、稠密混合与 MoE）在深度、宽度、混合及专家剪枝下的退化，剪枝后统一进行监督微调，再在三个智能家居数据集、超过 19,500 个实例上评测；除聚合准确率外，还从动作组件（operation、device、argument、value）与任务复杂度两个维度刻画退化，以定位失败发生的位置与时机。
   - 结果：稠密模型的安全剪枝区间很窄、随后出现急剧退化，而 MoE 模型能承受显著更多的剪枝；剪枝总是先损害 grounding 的具体性，再影响 schema 级意图，且激进的稠密剪枝会诱发系统性过度拒答；研究给出跨架构、跨任务复杂度的退化画像，说明为可靠工具执行选择剪枝 LLM 时不能只依赖聚合准确率，并为部署时的剪枝预算提供参考。

**主要痛点**
- 长上下文 LLM 在边缘设备上的 KV cache 与执行状态内存瓶颈
- 模型 serving 跨层异构栈优化依赖专家、难以随负载演进扩展
- 剪枝对工具调用等结构化能力的退化机制缺乏细粒度评测
- 分布式训练因浮点非确定性无法跨硬件可验证复现
- 世界模型与多模态模型训练/推理中模态与表示冗余带来的算力开销

**方法趋势**
- KV 压缩执行、组件驻留换出与保状态 serving 切换的即时状态管理
- agentic 跨层优化：kernel、计算图、模型服务器与特征服务统一调优
- 剪枝后 SFT 并在动作组件与任务复杂度两个维度评测退化
- 固定归约、批序与通信顺序的确定性训练加多审计者集体验证
- 自回归多模态去噪、EEG 门控 ROI、层级自适应 codec 压缩等高效表示手段

**结果信号**

2. [Modality-Autoregressive World-Action Models](https://arxiv.org/abs/2609.17524v1)
   - 分类：World-Action Models / Robot Policy Learning
   - 研究价值：值得精读
   - 关联：与团队的机器人世界模型/策略学习方向高度相关：系统回答 WAM 中应预测哪些视觉模态、如何组织多模态预测，直接影响后续世界模型设计与算力分配。
   - 痛点：世界-动作模型通常将未来预测为 RGB 图像，但 RGB 并非最有效的信息载体：深度、预训练视觉特征与点轨迹能更紧凑地编码几何、语义与运动信息，却缺乏在 WAM 中如何组合这些模态的系统性认识。现有方法多为多模态并行预测或依赖大规模视频预训练，训练代价高，且各模态之间缺少条件依赖，难以判断哪些模态真正提升策略成功率，导致表征选择、预测顺序与算力分配长期缺乏实验依据。
   - 方法：ModAR 采用模态自回归去噪：在预测动作之前，依次对多种未来模态（如点轨迹、DINO 特征、深度图等）进行去噪生成，使每个模态的预测都以先前生成的模态为条件，形成有依赖的预测链。作者从头训练并系统消融训练数据混合比例、所预测模态集合以及 WAM 的具体形式，在统一设置下比较顺序生成与并行、单模态等现有 WAM 形式，并进一步与视频模型初始化的 WAM 基线对比。
   - 结果：实验显示，预测点轨迹、DINO 特征与深度图均带来收益，而额外预测未来 RGB 没有一致收益；ModAR 的顺序生成在所有评估数据规模上取得最高平均成功率。与视频模型初始化的 Flex-π 相比，ModAR 以约 20 倍更少训练 FLOPs 且无需预训练，获得略高的观测平均成功率（75% vs 72%）。在三个真实双臂任务上 ModAR 优于基线，并能随人类视频数据持续改进。
