1. [Video DeltaNet: A Video-Native Hybrid Attention for Livestream Video Generation](https://arxiv.org/abs/2609.20744v1)
   - 分类：Video Generation / Hybrid Linear Attention
   - 研究价值：值得精读
   - 关联：直击视频扩散去噪中注意力算力瓶颈，与扩散/生成式AI的推理效率主线高度相关，可直接迁移到长视频与实时生成场景。
   - 痛点：视频扩散模型在去噪时需反复处理极长的时空 token 序列，注意力成为主要计算瓶颈；线性注意力虽在 LLM 中广泛采用，但直接搬到视频模型会丢失高质量生成所需的细粒度交互。现有做法要么保留全 Softmax 注意力导致推理成本高企，要么用纯线性近似换取速度却牺牲生成质量。同时视频-文本、视频-音频交互仍需全局建模，如何在同一骨干中按模态差异分配注意力预算缺乏系统方案。
   - 方法：Video DeltaNet（VDN）把局部 Softmax 注意力与双向线性记忆结合：线性分支提出 Video Delta Attention（VDA），按帧更新记忆并联合纳入该帧的空间 token，实现长程视频上下文的高效聚合；两个分支使用独立输出投影与可学习门控校准，并通过分阶段教师对齐（staged teacher-alignment）把新通路逐步注入预训练模型。VDN 在 MiniMax H3 上实例化：视频到视频交互走混合注意力，涉及文本或音频的交互仍保留 Softmax，再配合八步蒸馏与优化的 SGLang 服务栈完成部署。
   - 结果：在八张 NVIDIA B200 上，VDN-H3 完成 14.3 秒、768p 视频的 DiT 去噪仅需 6.70 秒，相比同卡数下 50 步稠密 H3 基线获得 14.5× 加速；生成质量与全注意力模型保持一致，验证了混合线性注意力在视频生成中的可行性。该结果表明按模态分配注意力的混合设计可在不牺牲质量的前提下大幅压缩视频扩散推理成本，为实时与长视频生成提供了可复用的架构加蒸馏、服务协同优化范式。

2. [FlowSGS: Improving Flow Matching Priors for Inverse Imaging with Stochastic Interpolants](https://arxiv.org/abs/2609.20769v1)
   - 分类：Flow Matching / Inverse Problems / Posterior Sampling
   - 研究价值：值得精读
   - 关联：属于扩散与流匹配生成先验求解逆问题的核心方向，把流匹配从线性前向模型推广到非线性逆问题，对生成式AI的方法论价值较高。
   - 痛点：流匹配已成为 SOTA 生成模型并被用作即插即用（PnP）先验求解计算成像逆问题，但现有基于流的逆求解器大多假设前向模型是线性的，或在后验采样中引入简化近似，导致对非线性逆问题的适用性与后验正确性存疑。同时扩散与流式 PnP 采样往往需要大量网络评估，推理成本居高不下。因此如何在保留预训练流先验表达能力的同时严格分解后验并降低采样开销，是该方向的核心痛点。
   - 方法：FlowSGS 提出基于流匹配的后验采样方法，用 Split Gibbs Sampling 把后验分解为似然步与先验步：似然步用 Langevin 动力学采样，先验步借助 Stochastic Interpolants（SI）框架把预训练流模型接入，并给出使用 SI 反向时间 SDE 的先验步形式，同时建立与既有 PnP 方法的联系。借助流先验的直线概率路径与一种新的反向时间 SDE 时间步校正技术，FlowSGS 先验步所需网络评估次数少于 PnP 扩散采样器。
   - 结果：在多种逆问题上取得 SOTA 表现，并首次为基于流的逆求解器给出非线性逆问题（傅里叶相位恢复）的实验验证；由于先验步网络评估更少，推理开销相比 PnP 扩散采样器明显下降。这表明确切的 Split Gibbs 后验分解结合 SI 反向 SDE 与时间步校正，可在保持甚至提升重建质量的同时，把流匹配先验推广到非线性、非高斯似然的计算成像任务，为生成式先验的严谨后验采样提供了新范式。

3. [Paint-Anything: Unified Any-Color Control for Image Generation and Editing](https://arxiv.org/abs/2609.20816v1)
   - 分类：Controllable Image Generation & Editing
   - 研究价值：值得精读
   - 关联：面向生成与编辑统一的可控性，含新数据集与基准，是扩散生成模型细粒度条件控制的重要推进。
   - 痛点：专业设计与创意工作流需要精确的任意颜色控制，即用任意 24 位十六进制值指定物体目标颜色，并同时覆盖生成与编辑两种任务。已有颜色生成、编辑与上色方法往往依赖专用颜色表示或特殊推理流程，难以统一；同时真实图像受阴影影响，颜色标签只能近似，导致细粒度 hex 级颜色保真度缺乏统一评测基准。生成与编辑两个任务各自为政，也缺少能同时衡量物体级 hex 颜色准确度的公开基准。
   - 方法：Paint-Anything 学到一个共享的 hex 提示接口，通过物体级颜色监督统一生成与编辑。作者构建数据流水线，经物体定位、感知颜色标注与编辑对合成得到 Paint-500K；由于真实图像阴影使标签仅为近似色，额外引入像素与配对 hex 完全一致的纯色锚点，且只在高噪声时间步使用，低噪声阶段仍由自然图像训练。此外提出 Any Color Benchmark（ACBench），包含 ACBench-T2I 与 ACBench-Edit，用于评估物体级 hex 颜色保真度。
   - 结果：在 FLUX.2-4B 上，Paint-Anything 相对基座模型把 ACBench-T2I 与 ACBench-Edit 分数分别提升 85.3% 与 28.3%，消融实验支持其纯色锚点与高噪声时间步训练配方；在对比方法中取得最高平均 CompColor 分数。结果表明统一的 hex 提示接口能在不引入专用推理流程的前提下实现高保真任意颜色控制，Paint-500K 与 ACBench 也为后续任意颜色控制研究提供了可复用数据与评测基础。

**主要痛点**
- 视频与长序列扩散模型的注意力计算瓶颈难以兼顾生成质量与推理效率
- 生成式逆求解器缺乏后验分布级评测，且对非线性前向模型支持不足
- 精确可控生成（如任意 24 位 hex 颜色）缺少统一接口与标准基准
- 前馈 3D 高斯与生成式 3D 潜变量存在空间冗余、结构先验利用不足
- 扩散/流策略与具身世界模型缺少前瞻性与接触级动力学建模

**方法趋势**
- 混合局部 Softmax 注意力 + 双向线性记忆，配合教师对齐与蒸馏、服务栈优化
- Split Gibbs 后验分解 + Stochastic Interpolants 反向时间 SDE 的流先验采样
- 共享 hex 提示接口 + 纯色锚点仅在高噪声时间步监督，并构建 ACBench
- 复用冻结生成式 3D 潜变量作结构先验，结合后处理剪枝与循环精炼
- 从去噪轨迹几何、未来运动或人类触觉潜表示中抽取可靠性信号

**结果信号**
- VDN-H3 在 8×B200 上 6.70 秒完成 14.3 秒 768p 视频去噪，14.5× 加速
- FlowSGS 在多类逆问题上 SOTA，并首次验证非线性傅里叶相位恢复
- Paint-Anything 在 FLUX.2-4B 上 ACBench-T2I/Edit 分别提升 85.3%、28.3%
- PosteriorBench 揭示现有生成式逆求解器存在显著分布匹配差距
- GeoAAC 真实操作成功率 53.3%→74.4%，MoWAM、Foresight 等扩散策略在 OOD 与真实任务上稳定提升

### 高效训练与推理

**今日推荐精读 Top 3**

1. [Video DeltaNet: A Video-Native Hybrid Attention for Livestream Video Generation](https://arxiv.org/abs/2609.20744v1)
   - 分类：Video Generation / Hybrid Linear Attention
   - 研究价值：值得精读
   - 关联：与高效推理直接相关：把视频扩散中昂贵的全局 Softmax 注意力替换为帧级双向线性记忆加局部注意力的混合方案，并在真实推理栈上取得 14.5 倍端到端加速，是长视频生成降本的关键路径。
   - 痛点：视频扩散模型在去噪过程中需要反复处理长时空 token 序列，全局 Softmax 注意力的计算与显存开销随帧数、分辨率快速膨胀，成为直播视频生成的主要瓶颈；而直接把 LLM 中流行的线性注意力搬到视频模型上，又会丢失高质量生成所需的细粒度时空交互，导致画面质量与运动一致性下降。更困难的是，同时承载文本、音频等模态的既有注意力通路不能随意替换，因此现有方案难以同时兼顾长序列效率与生成保真度。
   - 方法：论文提出 Video DeltaNet（VDN），用局部 Softmax 注意力与双向线性记忆混合建模长程视频上下文；线性分支引入 Video Delta Attention（VDA），每帧整体更新一次记忆并联合纳入该帧的空间 token，两个分支通过独立输出投影与可学习门控进行校准。训练上采用分阶段教师对齐流程，把新注意力通路逐步注入预训练模型 MiniMax H3，仅在 video-to-video 交互中替换 Softmax，涉及文本与音频的交互仍保留原注意力，从而在不动多模态对齐的前提下获得线性复杂度收益。
   - 结果：在 MiniMax H3 上实例化后，配合八步蒸馏与优化过的 SGLang 推理栈，VDN-H3 在 8 张 NVIDIA B200 上完成 14.3 秒、768p 视频的 DiT 去噪仅需 6.70 秒，相比相同卡数下 50 步稠密 H3 基线取得 14.5 倍加速，同时生成质量得以保持。该结果说明帧级线性记忆加局部注意力的混合设计可以在视频生成中同时获得长上下文能力与显著推理效率收益，为高吞吐视频服务提供了可复制的工程范式。

2. [Score Centering Stabilizes Off-policy Reinforcement Learning](https://arxiv.org/abs/2609.20807v1)
   - 分类：LLM RL Training / Training-Inference Mismatch
   - 研究价值：值得精读
   - 关联：与高效训练直接相关：定位 RL 训练引擎与推理引擎之间持续累积的漂移是失稳主因，并给出可加修正项，无需为对齐引擎牺牲 rollout 吞吐。
   - 痛点：LLM 强化学习对训练引擎与推理引擎之间的微小差异极为敏感，即所谓的训练-推理不匹配（TIM）；彻底消除这种差异需要牺牲 rollout 吞吐，代价过高，因此实践中只能容忍它存在。作者进一步指出，真正导致训练不稳定乃至崩溃的主因并非瞬时误差，而是训练侧与推理侧之间随每一步训练持续累积的持久偏差（drift），而已有的重要性采样类纠偏方法并未直接针对这一累积项，在量化推理等误差较大的场景下效果有限。
   - 方法：论文从理论上分析 TIM 下 RL 不稳定的来源，推导出一个可加的「score centering」修正项：在计算策略梯度时对分数函数做中心化，抵消训练侧与推理侧之间持续累积的偏差，因此方法不改变采样流程，可与截断、量化推理等既有设置叠加。由于修正项是可加的，它还能与重要性采样天然组合形成互补方案，不需要额外超参搜索或昂贵的引擎对齐工程，从而在保留高吞吐 rollout 的同时稳定训练。
   - 结果：在 0.6B 到 30B 参数规模的模型上，仅使用 score centering 就在量化条件下的表现追平甚至超过基于重要性采样的方法，而且训练与推理的不匹配程度越严重，优势越明显；在 staleness（陈旧 rollout）实验中，score centering 与重要性采样的组合也优于纯重要性采样基线。这说明该修正并非只针对某一种误差来源，而是提升 off-policy RL 训练稳定性与 rollout 效率的通用手段。

3. [On-Demand Attention: Language Models Know When to Recall](https://arxiv.org/abs/2609.20734v1)
   - 分类：Long-Context Inference / Sparse Attention Decoding
   - 研究价值：值得精读
   - 关联：与长上下文高效推理直接相关：把「是否读取全局历史」交给模型自身的轻量 recall head 决策，并在 vLLM 中落地为实际解码加速。
   - 痛点：推理与智能体负载越来越依赖长上下文，但标准全注意力解码在每一步都要读取不断增长的历史 KV，无论这些历史对下一次预测是否有用，导致解码成本随上下文长度线性增长，成为服务端吞吐的主要瓶颈。已有的稀疏或局部注意力方案通常按固定模式裁剪历史，忽略了模型本身其实已经「知道」何时需要回看哪些信息这一信号，因而往往在效率与精度之间被迫二选一，难以在长上下文下同时保证速度与质量。
   - 方法：论文先通过实验表明预训练模型的解码状态中已经包含能预测「全局读取是否有益」的信息，据此提出 On-Demand Attention（ODA）：一种 local-first 解码方法，用一个轻量 recall head 在生成过程中根据预测收益动态决定是否调用全局注意力。训练时只更新 recall head、冻结预训练权重，并完整保留历史 KV cache 供后续随时召回；作者还在 vLLM 中实现了 GPU 侧的条件执行，把减少的全局读取转化为实际的解码加速。
   - 结果：在 Qwen 与 Gemma 系列模型（包括混合注意力骨干）上的实验表明，选择性召回能够恢复局部注意力下损失的大部分精度，同时显著减少全局注意力读取次数；vLLM 实现把读取减少转化为长上下文下相对全注意力的实际解码加速。结果验证了「让预训练模型自己决定如何访问其保留信息」这一长上下文推理范式的可行性，为服务端长上下文部署提供了可直接落地的工程方案。

**主要痛点**
- LLM/视频/长上下文推理中注意力与 KV 读取随序列增长，成为训练与推理的主要成本瓶颈
- RL 后训练受训练-推理引擎不匹配、轨迹级稀疏奖励与仿真交互成本高的多重制约
- VLA/世界模型推理延迟高，难以支撑高频闭环控制与长时程任务
- 智能体可信度与评测缺乏对完成度虚报、分布精度、多语言语域与评测预算的客观度量

**方法趋势**
- 混合/线性注意力（Video DeltaNet、dQwen3.5）与按需稀疏全局注意力（On-Demand Attention）
- 可加的 score centering 修正与自适应退役的 on-policy 蒸馏（RetireOPD）
- 无渲染特权教师 + on-policy 微调（OPTED）、观测 token 联合监督（ActObs）、测试时引导（TraceFlow）
- 经典规划器与 VLA 分工（SkipVLA）、紧凑未来运动预测（MoWAM）、触觉世界动作模型（Agile-WAM）

**结果信号**
- VDN-H3 在 8×B200 上 6.70s 完成 14.3s/768p 视频去噪，较 50 步稠密基线加速 14.5×
- score centering 在 0.6B–30B 上追平或超过重要性采样，且不匹配越严重优势越大
- RetireOPD 在 ALFWorld/WebShop 相对 RL 基线提升 14.1–18.8% / 11.8–19.0%，且超过技能条件教师
- OPTED 以约三个数量级更少的仿真交互达到直接 RL 的闭环性能，驾驶分数提升 1.6× 与 9.5×

1. [Agile-WAM: An Agile Tactile World Action Model for Contact-Rich Robot Control](https://arxiv.org/abs/2609.20761v1)
   - 分类：Tactile World Action Models / Contact-Rich Manipulation
   - 研究价值：值得精读
   - 关联：接触丰富操作策略与世界动作模型，与本团队具身智能主线高度相关
   - 痛点：接触丰富操作中，触觉世界动作模型（WAM）虽能联合预测未来世界状态与动作，但现有方法依赖大规模预训练生成式骨干，推理延迟高、难以部署到需要高频闭环控制的真实机器人；同时视觉与触觉信号的时间尺度差异极大——相邻视觉帧高度相似，而触觉在接触瞬间剧烈突变——单一时间尺度建模难以同时刻画慢变视觉动态与快变接触动态，导致策略无法兼顾控制精度与实时性。
   - 方法：Agile-WAM 把视觉与触觉观测编码到共享隐空间，并以该隐空间为源直接构建“视觉-触觉到动作”的流匹配过程，联合生成动作块隐表示与未来视觉/触觉隐表示；核心设计是多时间尺度多模态预测：视觉隐表示用更大的时间偏移监督，触觉隐表示预测下一帧以捕捉细粒度接触动态。整个架构保持轻量，不依赖大型生成式骨干、也不显式生成未来视频，从而在保留世界建模能力的同时维持低推理延迟。
   - 结果：在 9 个仿真与 5 个真实接触丰富操作任务上，Agile-WAM 的成功率稳定超越最强基线，真实实验总体成功率相对提升 29.4%，同时推理延迟仅 11.9 ms，满足高频机器人控制需求。结果说明无需重型生成骨干也能实现多模态世界动作模型，为接触丰富操作提供了精度与速度兼顾的可行架构。

2. [GeoAAC: Geometry-Based Adaptive Action Chunking from Denoising Trajectories in VLA Policies](https://arxiv.org/abs/2609.20776v1)
   - 分类：VLA / Adaptive Action Chunking
   - 研究价值：值得精读
   - 关联：VLA 策略的动作生成与推理效率，是具身智能落地的关键环节
   - 痛点：现有 VLA 策略普遍使用固定动作块长度（action horizon），但一次 rollout 中不同任务阶段对动作连续性、控制精度与闭环反馈的需求差异很大：精细接触阶段需要短块快速纠错，自由运动阶段长块更高效。固定长度无法随控制需求自适应，导致在 LIBERO-Pro、RoboCasa365 等长程或分布偏移任务上性能受限；而已有自适应方法通常需要额外训练或多次生成，显著增加成本。

**原始摘要**

We therefore introduce a benchmark of 20 real scenes, from coherent streams to violent splashes, captured by seven synchronized, calibrated 4K cameras at 60 fps, with manually refined per-view liquid and container masks and fixed evaluation splits. We instantiate it in SportSAGE, a design probe pairing a four-module highlight pipeline with a graph interface, and report feedback from 12 soccer fans. Participants were satisfied with the quality of the generated highlights and narratives, and used the graph interface to search, navigate, and interpret the match highlights. These results provide early evidence that one small, human-readable schema can ground agent generation and support human interpretation at the same time.

### 6. [On-Demand Attention: Language Models Know When to Recall](https://arxiv.org/abs/2609.20734v1)

- 来源：arXiv
- 关键词：attention, recall HEAD, reasoning, trains ONLY the recall, language models KNOW WHEN, selective recall recovers MOST
- 链接：<https://arxiv.org/abs/2609.20734v1>

**原始摘要**

Reasoning and agentic workloads increasingly demand efficient long-context inference. Yet full-attention decoding reads the growing history at every step, regardless of its benefit to the next prediction. We show that a pretrained model's decoding states already contain information predictive of this benefit, before the global read. Building on this finding, we introduce On-Demand Attention (ODA), a local-first decoding method that uses a lightweight recall head to selectively invoke global attention as its predicted benefit changes during generation. ODA trains only the recall head, leaving pretrained weights unchanged and the complete historical KV cache available for future recall. We further implement GPU-side conditional execution in vLLM, translating reduced global reads into practical decoding speedups over full attention at long context lengths. Experiments across Qwen and Gemma models, including hybrid-attention backbones, show that selective recall recovers most of the performance lost under local attention while substantially reducing global reads. These findings support long-context inference in which pretrained models guide their own access to the information they retain.

### 7. [Chronicle: Cut-Point Replay for Regression Testing of LLM Agents](https://arxiv.org/abs/2609.20625v1)

- 来源：arXiv
- 关键词：LLM agents, cut-point tests, cut-point replay, benchmark, guarded tools cut-point, repetitions and cut-point
- 链接：<https://arxiv.org/abs/2609.20625v1>

**原始摘要**

Large language model responses are non-deterministic, so failures in LLM agents are hard to reproduce: a failure depends on inference that is not bitwise reproducible, on tools that read changing state, and on a multi-step trajectory that a re-run rarely repeats. Record-and-replay makes a run reproducible, but existing agent tooling records runs only to trace or score them, not to test a code change against them. We present Chronicle, which records an agent run at its non-deterministic boundaries as immutable envelopes and replays it from the record. Its central operation, cut-point replay, serves a chosen subset of boundaries from the record and executes the complementary subset live with new code, turning a recorded incident into a regression test that runs in continuous integration. On a benchmark of 6 recorded failures with simulated model boundaries, recording adds 23 μs per crossing (0.008% of an assumed 300 ms model call), full replay issues zero model calls and is bit-stable across 20 repetitions, and cut-point tests fail on faulty code and pass on guarded and benign changes for all 6 incidents. In a mutation study of the guarded tools, cut-point tests catch every mutant that lets the recorded unsafe action through, while a baseline that stubs every boundary, using the same assertion, catches none. Chronicle and the benchmark are publicly available at https://github.com/theagentplane/chronicle.
