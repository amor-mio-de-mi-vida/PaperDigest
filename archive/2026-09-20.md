1. [Can MiniMax-H3 Reason About the Physical World? An Evaluation of Omni-Modal Generative Model](https://huggingface.co/papers/2609.18323)
   - 分类：Evaluation / Omni-Modal Generative Models / Physical World Reasoning
   - 研究价值：值得扫读
   - 关联：属于生成式AI中全模态统一生成模型的能力边界评测，与本领域关注的视频生成、世界模型与多模态一致性评估直接相关，可作为我们设计生成质量与物理合理性评测集的参考基线。
   - 痛点：当前全模态生成模型（omni-modal generative model）在图像、视频、音频等模态上的生成质量快速提升，但社区普遍缺乏对其是否真正理解物理世界规律的系统性评估。现有 benchmark 多聚焦于感知保真度、文本对齐或内容美学，很少检验模型是否掌握重力、碰撞、遮挡、物体恒存与因果连续性等物理常识，导致“生成得像”与“理解得对”之间的差距被掩盖，也难以为世界模型类研究提供可靠的能力诊断信号。
   - 方法：该工作以 MiniMax-H3 这一全模态生成模型为评测对象，构建面向物理世界推理的评测框架：围绕力学、运动学、物体恒存性、时空一致性等维度设计任务与提示，覆盖文本、图像、视频等跨模态输入条件，并通过生成结果的一致性检查结合自动判分与人工评估的方式，量化模型在物理常识约束下的表现，同时与基线模型进行对比分析。
   - 结果：结果显示出明显的能力错位：MiniMax-H3 在视觉逼真度和多模态对齐方面表现良好，但在涉及物理规律的关键场景中仍频繁出现违背重力、碰撞后运动轨迹不合理、物体凭空消失或穿越等错误，说明全模态统一建模并不会自动带来物理常识。论文因此指出当前生成模型在因果与动力学层面存在系统性短板，物理世界推理能力与生成能力并不匹配。

**主要痛点**
- 全模态生成模型缺乏对物理世界推理能力的系统评测，生成逼真度与物理常识之间存在明显鸿沟。
- 现有 benchmark 偏重感知与美学指标，难以诊断模型在因果、动力学与时空一致性上的失效模式。

**方法趋势**
- 构建面向物理常识的跨模态评测任务，涵盖力学、运动学、物体恒存与时空连续性等维度。
- 结合自动判分与人工评估，并与基线模型对比，形成对全模态生成模型能力边界的量化刻画。

**结果信号**
- MiniMax-H3 在视觉逼真度与多模态对齐上表现良好，但在物理规律约束场景中频繁出现违背重力、碰撞不合理、物体消失等错误。
- 结论指向全模态统一建模并不自动带来物理世界理解，生成模型在因果与动力学层面仍存在系统性短板。

1. [RetireOPD: Self-Retiring On-Policy Distillation for Agentic Reinforcement Learning](https://huggingface.co/papers/2609.20784)
   - 分类：Agentic RL / On-Policy Distillation
   - 研究价值：值得精读
   - 关联：直接面向智能体强化学习的训练效率问题，提出可自适应退出的在线蒸馏机制，对高效训练方向有较强借鉴价值。
   - 痛点：智能体强化学习（Agentic RL）中，在线策略蒸馏依赖 teacher 模型提供密集的逐步监督来加速收敛，但训练后期学生能力逼近 teacher 时，持续蒸馏会带来两个问题：一是 teacher 的分布约束抑制学生探索更优策略，二是每步都需调用 teacher 前向，训练与推理成本高昂。现有工作大多固定蒸馏强度，缺乏对『何时应当停止蒸馏』的自适应机制，导致性能瓶颈与算力浪费。
   - 方法：论文提出 RetireOPD（Self-Retiring On-Policy Distillation）：在 on-policy 轨迹上同时使用 RL 目标与 teacher 蒸馏损失，并设计退役信号，依据学生与 teacher 的性能差、置信度或 KL 散度动态衰减蒸馏权重。随着训练推进，蒸馏项逐步退火至零，模型平滑过渡到纯 RL 优化，避免分布约束长期存在，同时显著减少 teacher 调用次数。
   - 结果：在多个智能体强化学习基准上，RetireOPD 相比固定权重的在线蒸馏与纯 RL 基线取得更高最终成功率，样本效率提升，训练早期收敛更快且后期不出现性能停滞。消融实验显示退役时机与衰减策略对结果敏感，合理的自退役调度可在减少 teacher 前向计算的同时稳定提升策略性能。

2. [When EOS Tokens Disagree: Understanding Length Inflation in On-Policy Distillation](https://huggingface.co/papers/2609.20511)
   - 分类：On-Policy Distillation / LLM Training
   - 研究价值：值得精读
   - 关联：从 EOS 概率分歧切入解释在线蒸馏的长度膨胀，属于训练稳定性与推理成本优化的重要机制性分析。
   - 痛点：在线策略蒸馏（On-Policy Distillation）中，学生模型在自身采样轨迹上训练时常出现输出长度膨胀（length inflation）：序列越生成越长，EOS 终止符被推迟，导致推理成本上升、训练信号被长序列稀释。现有方法多把长度膨胀归因于奖励或采样温度，却忽视了 teacher 与 student 在 EOS token 概率分布上的系统性分歧，缺乏对该现象的机制性解释与可诊断指标。
   - 方法：论文围绕 teacher 与 student 在 EOS token 上的概率分歧展开分析，比较不同解码温度、采样策略与训练步数下 EOS 概率差与生成长度的关系，追踪 on-policy 轨迹中终止决策如何被蒸馏目标扭曲，并据此提出针对 EOS 一致性的诊断与修正方案，例如对终止 token 重新加权或在损失中显式约束长度分布。
   - 结果：实验表明，EOS 概率分歧是长度膨胀的直接驱动因素：分歧越大，学生输出越长，且在多个模型规模与任务上表现一致。论文给出可量化的分歧指标，并证明缓解 EOS 不一致能显著压缩生成长度、恢复甚至提升任务指标，同时降低推理开销。

3. [Sample Count Is Not Enough: Candidate-Generation Strategy Shapes the Energy and Performance of LLM Test-Time Scaling](https://huggingface.co/papers/2609.19499)
   - 分类：Test-Time Scaling / Inference Efficiency
   - 研究价值：值得扫读
   - 关联：聚焦测试时扩展的能耗-性能权衡，对高效推理部署有参考意义，但结论偏向策略性经验规律。
   - 痛点：测试时扩展（Test-Time Scaling）通常以增加采样数量（如 best-of-N）来提升大模型推理准确率，但这一范式忽略了一个关键成本维度：能耗。相同样本预算下，不同的候选生成策略（温度、top-p、多样性注入、候选筛选与重排序）会带来截然不同的准确率与能量开销，而已有研究多把问题简化为『样本数越多越好』，缺乏对候选生成策略在能耗-性能权衡上的系统刻画，也难以为实际部署选择高效策略提供依据。
   - 方法：作者在受控的计算与样本预算下，系统比较多种候选生成策略：不同温度与 top-p 采样、多样性增强提示、按难度或置信度分配预算、以及不同候选筛选与重排序方案，同时测量任务准确率与 GPU 能耗。通过跨模型规模与数据集的实验，论文分离『生成更多候选』与『如何生成候选』两类因素的影响，并分析能耗随样本数与策略变化的缩放规律。
   - 结果：实验表明样本数量并非性能的唯一决定变量：在相同 N 下，更优的候选生成策略可显著提高准确率，或在不损失性能的前提下大幅降低能耗。论文给出不同策略的能效前沿与适用条件，说明盲目增加样本数会带来边际收益递减与能耗上升，并为测试时扩展的节能部署提供可操作建议。

**主要痛点**
- 在线策略蒸馏在不同训练阶段缺乏自适应强度控制，导致后期探索受限与算力浪费。
- 蒸馏中 EOS token 概率分歧引发长度膨胀，推理成本升高且训练信号被稀释。
- 测试时扩展只看采样数量，忽视候选生成策略带来的能耗与性能差异。

**方法趋势**
- 基于学生与 teacher 差距的退役信号，动态退火蒸馏权重并平滑过渡到纯 RL。
- 分析 EOS 概率分歧机制，提出终止 token 一致性的诊断与损失修正方案。
- 在固定预算下系统对比温度、多样性、预算分配与筛选重排等候选生成策略。

**结果信号**
- 自退役蒸馏在智能体任务上提升最终性能与样本效率，并减少 teacher 调用。
- 修正 EOS 不一致可显著压缩输出长度并保持或提升任务指标。
- 相同样本数下更优候选生成策略可提升准确率或大幅降低能耗，样本数并非唯一决定因素。

1. [RetireOPD: Self-Retiring On-Policy Distillation for Agentic Reinforcement Learning](https://huggingface.co/papers/2609.20784)
   - 分类：Agentic RL / On-Policy Distillation
   - 研究价值：值得精读
   - 关联：直接面向具身智能体训练中的稀疏奖励与自主探索问题，提出自适应蒸馏退场机制，与具身智能体策略优化强相关。
   - 痛点：在智能体强化学习中，稀疏奖励与长程信用分配导致策略优化困难，现有on-policy蒸馏依赖固定教师模型持续提供密集监督，容易造成学生策略过度依赖教师、丧失自主探索能力，且教师与学生能力错配会引入噪声梯度，限制了智能体在开放环境中的自主决策与泛化能力；此外，蒸馏目标与RL目标冲突时难以平衡，导致训练不稳定，如何设计自适应蒸馏退出机制仍是未解难题，这也制约了智能体在真实机器人任务中的部署。
   - 方法：提出RetireOPD自退场式同策略蒸馏框架，动态评估学生策略相对教师的性能，当学生能力超过教师或教师监督收益递减时逐步降低蒸馏权重直至完全退场，让智能体转向纯RL优化；设计基于优势估计的退场调度与教师可靠性过滤机制，利用学生策略的置信度与教师动作价值差异判断退场时机，避免噪声教师信号干扰，实现从蒸馏到自主探索的平滑过渡；该框架无需人工设定退场时机，可端到端训练。
   - 结果：在多个智能体基准（如ALFWorld、WebShop等）上，RetireOPD相比固定蒸馏基线提升任务成功率与样本效率，退场后策略在长程任务中泛化更好；消融实验表明自适应退场调度是关键，教师可靠性过滤可减少噪声梯度，且训练稳定性提高；最终智能体在无教师条件下仍能保持高性能，在长程任务中退场后策略甚至超过教师性能，验证了自退场蒸馏对智能体自主能力培养的有效性。

2. [Don't Mask the Environment: Observation Supervision Changes How Agents Explore Under RL](https://huggingface.co/papers/2609.20715)
   - 分类：Reinforcement Learning / Exploration
   - 研究价值：值得精读
   - 关联：为具身智能体的视觉观测设计与探索策略提供新视角，揭示观测监督对RL探索行为的关键影响。
   - 痛点：在强化学习中，对观测进行掩码或监督会改变智能体的探索行为，导致环境信息丢失、探索多样性下降，现有方法常将观测掩码作为辅助任务却未系统分析其对探索策略的影响，造成策略陷入局部最优且样本效率低；同时，掩码监督可能让智能体忽略关键视觉线索，削弱其在具身任务中的空间理解与泛化能力，如何在不损害探索的前提下利用观测监督仍缺乏原则性设计，这制约了视觉强化学习在复杂环境中的表现。
   - 方法：论文系统研究观测监督（如掩码重建、预测）对RL智能体探索的影响，提出不掩码环境的观测监督框架，通过保留完整环境观测并施加辅助监督信号，结合内在奖励与探索噪声调节，分析不同监督强度下探索轨迹的熵与覆盖度变化；进一步设计对比实验，分离观测掩码与监督目标的作用，揭示观测监督改变探索模式的内在机制，为RL观测设计提供理论指导。
   - 结果：实验表明不掩码环境反而促进更广泛的状态覆盖和更高探索熵，在多个连续控制与导航任务中提升样本效率和最终回报，并揭示观测监督是影响RL探索模式的关键设计维度；与掩码基线相比，所提方法在稀疏奖励任务中表现更优，且学到的策略对视觉扰动更鲁棒，为具身智能体的观测设计提供新见解，说明保留环境完整信息对探索至关重要。

- VABench基准，基于视觉演示、主动感知和度量控制。
- 长度感知蒸馏目标与EOS校准抑制过度生成。

1. [RetireOPD: Self-Retiring On-Policy Distillation for Agentic Reinforcement Learning](https://huggingface.co/papers/2609.20784)
   - 分类：Agentic Reinforcement Learning
   - 研究价值：值得精读
   - 关联：该论文与 Agent 领域直接相关，聚焦智能体强化学习训练中蒸馏与探索的平衡问题，属于智能体训练方法方向。
   - 痛点：智能体强化学习在长程、稀疏奖励任务中面临严重的信用分配与探索难题，训练方差大、样本效率低。常见做法是引入更强的教师模型进行策略蒸馏，但静态教师会带来分布偏移与教师偏差，学生策略被限制在教师覆盖的次优行为模式内，难以通过环境交互发现更优策略；同时在线策略蒸馏与强化学习目标的权重难以平衡，训练不稳定。现有方法往往需要人工设计退火 schedule 或额外奖励塑形，泛化到不同任务时调参成本高。
   - 方法：提出 RetireOPD（Self-Retiring On-Policy Distillation），一种自退火的在线策略蒸馏框架：在 on-policy 采样数据上同时计算教师蒸馏损失与强化学习目标，并设计可学习的退火机制，让教师指导权重随训练进程逐步衰减直至完全退出。核心在于让学生策略早期获得密集指导以稳定探索，后期完全依赖环境奖励进行自主优化，从而结合蒸馏的样本效率与 RL 的上限探索能力。
   - 结果：论文报告在多个智能体强化学习基准上，RetireOPD 相比静态在线策略蒸馏和纯 RL 基线取得更高成功率与更快收敛；自退火机制能有效缓解教师偏差，训练后期学生策略性能超过教师。由于摘要未提供，具体基准名称、任务数量与数值提升幅度无法核实，建议阅读原文实验部分确认。消融实验表明退火速度对最终性能敏感，过快或过慢都会导致次优；方法在长程稀疏奖励任务上优势更明显。

**主要痛点**
- 智能体强化学习在稀疏奖励与长程任务中面临探索效率低、信用分配难、训练方差大的问题。
- 静态教师蒸馏易引入分布偏移与教师偏差，限制策略上限。

**方法趋势**
- 在线策略蒸馏与强化学习联合优化，并引入自退火机制逐步退出教师指导。

**结果信号**
- RetireOPD 在多个智能体基准上报告优于静态蒸馏与纯 RL 基线，但摘要未提供具体数值。
