1. [Flash-dLLM: IO-Aware KV Caching and Parallel Decoding for Fast, Memory-Efficient Diffusion LLMs](https://arxiv.org/abs/2609.26796v1)
   - 分类：Diffusion LLM / Inference Acceleration
   - 研究价值：值得精读
   - 关联：直接对应团队关注的扩散大语言模型（dLLM）推理加速方向，KV 缓存与自验证并行解码的组合思路可迁移到其他扩散式生成模型的服务化部署。
   - 痛点：扩散大语言模型（dLLM）通过非自回归并行生成文本，但推理效率低：既缺乏有效的 KV 缓存机制，也缺少可扩展的并行解码方案，导致实际部署受限。已有加速工作把 KV 缓存与并行解码割裂开来研究，忽略了二者联合应用时（缓存复用与并行 token 验证同时进行）出现的 GPU 显存 I/O 瓶颈，使长序列与大 batch 场景下速度与显存双双成为瓶颈。
   - 方法：提出免训练的推理加速框架 Flash-dLLM。首先定位 GPU 显存 I/O 为启用 KV 缓存的 dLLM 推理的主导瓶颈，设计 I/O-aware 的融合 KV 缓存 kernel 以减少冗余显存搬运；在该优化缓存之上提出 KV-cache 驱动的 draft-and-verify 解码策略，由 dLLM 自身同时充当起草器与验证器，无需任何辅助模型，在同一模型中统一并行起草与验证，兼顾解码速度、生成质量以及对长序列和大 batch 的可扩展性。
   - 结果：在数学推理与代码生成基准上，Flash-dLLM 在推理速度和显存效率上一致优于现有最先进的 dLLM 加速方法。相对此前最强基线 Elastic-Cache，它在 GSM8K 上取得 5.1× 加速，在 HumanEval 上取得 11.0× 加速，同时保持生成质量不下降，并在更长序列和更大 batch 下展现出更好的可扩展性，验证了 I/O 感知缓存与自验证并行解码联合设计的有效性。

2. [Diffusion Drafts, AR Verifies: Accelerating Document OCR with Self-Speculative Decoding](https://arxiv.org/abs/2609.26638v1)
   - 分类：Diffusion Language Model / Speculative Decoding / Document OCR
   - 研究价值：值得精读
   - 关联：把扩散并行生成与自回归验证结合用于 OCR，是扩散+自回归混合解码的典型范式，对团队探索扩散生成在确定性/强 grounded 任务上的落地很有参考价值。
   - 痛点：自回归 OCR 视觉语言模型逐 token 串行解码，每步只产生一个 token，推理速度成为文档批量处理的瓶颈。OCR 输出强依赖输入图像、可预测性高，本适合扩散式并行生成，但扩散单步同时预测多个 token 时，每个 token 都是在其他 token 未知的情况下被预测的，直接提交会引入错误，因此如何在保证准确率的前提下安全地接受并行起草的多个 token 是关键难题。
   - 方法：提出 GravityOCR，一种参数共享的 AR-block-diffusion 模型，联合训练并行起草与因果自回归验证两条路径：扩散分支一次生成多个 token 草稿，由同一模型的自回归分支做因果校验后再提交，从而无需额外草稿网络即可每轮提交多个输出 token。因果 AR 路径还支持带序列级与结构级 OCR 奖励的 GRPO 强化学习，既避开扩散轨迹的似然估计难题，又能更新共享的起草器参数。
   - 结果：在 OmniDocBench v1.6 上，AR 路径 GRPO 将 Overall 分数从 94.92 提升到 95.16，且不降低扩散起草效率，最终模型接近原始 GLM-OCR 的 95.48。在 SGLang 服务部署中，GravityOCR 平均每次前向提交 9.7 个输出 token，区域裁剪场景解码提速 3.94×，整页端到端处理较纯自回归解码提速 1.32×，说明自推测解码能实打实转化为线上吞吐收益。

3. [StableVQ: Practical Guidelines for Stable Vector-Quantized Tokenizer Training](https://arxiv.org/abs/2609.26774v1)
   - 分类：Vector Quantization / Discrete Visual Tokenizer
   - 研究价值：值得精读
   - 关联：VQ tokenizer 是自回归与掩码图像生成的离散表征基础，其训练稳定性问题直接影响团队所有基于离散 token 的生成模型实验可复现性。
   - 痛点：向量量化（VQ）是离散视觉 tokenizer 的核心，支撑着现代自回归与掩码图像生成模型。虽然近期共享投影码本方法显著提升了码本利用率，但训练稳定性仍是一个关键却研究不足的问题。作者认为根因在于 Encoder-Decoder 与码本训练的相互纠缠：两个子系统都无法独立完成自身职责，系统只有在二者恰好协同时才能工作，而这种脆弱条件恰恰在训练压力最大时（低码本利用率、不同码本规模与初始化）崩溃。
   - 方法：提出 StableVQ，重新审视每个模块应有的学习目标并分别解耦：Dynamic STE 修正 Encoder 学习目标中的不稳定项，使其在码本利用率低时也能在离散正则下稳健优化重建空间；Region VQ Loss 重新定义码本目标，使其无需依赖 Encoder 振荡来驱动激活即可独立、完整地跟踪 Encoder 输出分布；Decoupled Schedule 认识到二者需要不同的优化动态，为各自分配独立学习率调度。方法建立在共享投影码本之上，轻量且不引入任何可学习参数。
   - 结果：在 ImageNet 上的实验覆盖多种码本规模与初始化设置，StableVQ 一致地提升了训练稳定性、码本利用率与重建质量，表明系统不再依赖 Encoder 与码本之间的偶然协同，而能在低利用率等压力条件下保持稳定。由于不引入可学习参数、可直接叠加在共享投影码本之上，它为离散视觉 tokenizer 的训练提供了一套低成本、可复现的实用稳定性准则。

**主要痛点**
- 扩散 LLM 推理效率低：KV 缓存与并行解码割裂研究，显存 I/O 成为联合优化时的隐藏瓶颈。
- 扩散并行生成中 token 彼此未知，直接提交易出错，需要可靠的自验证/接受机制。
- 离散视觉 tokenizer 的 Encoder 与码本训练相互纠缠，训练稳定性差、难以复现。
- 3D 重建结果缺乏物理可交互性，物体与背景纠缠、遮挡区域未观测。

**方法趋势**
- I/O 感知融合 KV 缓存 kernel + 模型自身 draft-and-verify 并行解码（免训练）。
- 参数共享 AR-block-diffusion 自推测解码，配合序列级/结构级奖励的 GRPO。
- Dynamic STE、Region VQ Loss 与解耦学习率调度，零新增参数的 VQ 稳定化。
- Gaussian-native 耦合式资产构建与源内容移除，生成可移动仿真资产。
- 物理驱动的湍流退化合成数据 + 两阶段盲复原网络。

**结果信号**
- Flash-dLLM 对 Elastic-Cache 在 GSM8K/HumanEval 上提速 5.1×/11.0×。
- GravityOCR 在 OmniDocBench v1.6 达 95.16，解码 3.94×、端到端 1.32× 提速。
- StableVQ 在 ImageNet 上跨码本规模与初始化一致提升稳定性、利用率与重建质量。
- φ-RIE 在 ScanNet++ 上 20mm 匹配 F1 从 0.336 提升至 0.383。

1. [Flash-dLLM: IO-Aware KV Caching and Parallel Decoding for Fast, Memory-Efficient Diffusion LLMs](https://arxiv.org/abs/2609.26796v1)
   - 分类：dLLM Inference Acceleration
   - 研究价值：值得精读
   - 关联：直接相关：扩散 LLM 的推理加速与显存效率优化是高效推理的核心方向。
   - 痛点：扩散大语言模型（dLLM）以非自回归方式并行生成文本，被视为自回归 LLM 之外的重要路线，但其实际部署仍受限于低效推理：现有加速方法通常把 KV 缓存与并行解码分开研究，忽视了二者联合应用时产生的 GPU 显存 I/O 瓶颈，导致缓存复用与并行 token 验证相互拖累。因此，在长序列和大 batch 场景下，dLLM 难以同时获得高吞吐、低显存占用和稳定生成质量，成为落地部署的关键障碍。
   - 方法：本文提出 Flash-dLLM，一个免训练推理加速框架。首先定位 GPU 显存 I/O 为 dLLM 推理主导瓶颈，设计 I/O-aware 融合 KV 缓存 kernel，减少冗余内存搬运；在此基础上提出 KV 缓存驱动的 draft-and-verify 并行解码策略，让 dLLM 自身同时充当草稿模型与验证器，无需辅助模型。该统一设计使缓存复用与并行 token 验证协同工作，在保持生成质量的同时提升长序列与大 batch 的可扩展性。
   - 结果：在数学推理与代码生成基准上，Flash-dLLM 在推理速度和显存效率上持续优于现有最先进 dLLM 加速方法。相对此前最强基线 Elastic-Cache，它在 GSM8K 上实现 5.1 倍加速，在 HumanEval 上实现 11.0 倍加速，同时保持生成质量。实验结果证明，联合优化 KV 缓存 I/O 与并行解码能显著提升 dLLM 的实用部署效率。

2. [Train Where the Quantized Model Goes: On-Policy Distillation for Low-Bit Reasoning](https://arxiv.org/abs/2609.26708v1)
   - 分类：Quantization / On-Policy Distillation
   - 研究价值：值得精读
   - 关联：直接相关：sub-3-bit 量化模型的推理能力恢复属于高效推理与低比特部署关键问题。
   - 痛点：量化感知蒸馏（QAD）能恢复 sub-3-bit 量化模型在短问答上的大部分性能，但数学与代码等长形式推理仍严重受损，长生成常退化为重复循环，耗尽解码预算仍无法完成解答。作者将根因归结为量化放大的 exposure bias：QAD 在固定语料前缀上训练，而量化误差会沿模型自回归轨迹不断累积，导致训练分布与量化模型实际生成分布错位。
   - 方法：本文提出在 QAD 检查点之后引入 on-policy distillation（OPD）阶段，让学生在部署时的量化前向路径上生成，并由冻结的全精度教师在其自身前缀上提供密集 token 级监督，同时结合任务验证器奖励。该设计把教师监督放在量化模型真正会到达的状态上，缓解 exposure bias；整体框架将 QAD 稳定的低比特初始化与 OPD 的在线策略推理恢复相结合。
   - 结果：在四个模型、2.79 与 1.88 有效比特设置下，OPD 将 MATH-500 上 BF16 性能保持率从 35% 提升到 70%，HumanEval 从 66% 提升到 91%，并保持短问答性能。在等预算对比中，其推理增益显著超过继续做 teacher-forced QAD。该框架为 sub-3-bit 量化模型提供了兼顾广泛能力与长形式推理恢复的综合方案。

3. [CliffCompaction: Cost-Efficient Compaction for Long-Horizon Coding Agents](https://arxiv.org/abs/2609.26779v1)
   - 分类：Long-Context Agent / Context Compaction
   - 研究价值：值得精读
   - 关联：直接相关：长周期代理的上下文压缩与 test-time scaling 成本效率是高效推理与训练的关键环节。
   - 痛点：长周期编码代理常需处理跨越百万 token 的上下文，受限于有限上下文窗口，必须在会话之间进行压缩。现有自动压缩方法容易在反复改写、重述和压缩嵌套中引入上下文漂移，既损失忠实性又增加成本，使 test-time scaling 的性能-成本权衡不够高效，尤其在高难 Terminal-Bench 与 KernelBench 任务上表现受限，且随会话增长错误会累积，代理难以持续学习。
   - 方法：CliffCompaction 是一种自动压缩技术，核心原则是保持压缩信息忠实：只做截断或丢弃，绝不改写或重述。它从不压缩“压缩结果”，每一轮只处理原始内容并丢弃先前压缩输出，从而防止上下文漂移累积。作者还提供 scaffold-agnostic 的 API-proxy 实现，可接入 Claude Code、Codex 等 harness，便于实际部署。
   - 结果：在受限上下文下，CliffCompaction 将成本最多降低 50%，同时在 Terminal-Bench 上保持或提升性能，并在 KernelBench 上取得新的 test-time scaling 效率与 SOTA 结果。每 rollout 节省使测试时扩展更划算：以低于两次全上下文运行的成本在 Terminal-Bench 上提升超过 10 个百分点。在 KernelBench 上，200 步后 CUDA kernel 加速 2.23 倍，400 步后达 3.58 倍，超过专用搜索算法与训练代理。

**主要痛点**
- 扩散 LLM 推理中 KV 缓存与并行解码联合优化的 GPU 显存 I/O 瓶颈
- sub-3-bit 量化模型长形式推理因 exposure bias 严重退化
- 长周期编码代理上下文压缩成本高且易漂移
- 服务栈差异导致工具调用与推理评测失真
- 长上下文模型受近端背景干扰忽略远处证据

**方法趋势**
- I/O-aware 融合 KV 缓存 kernel 与 KV 缓存驱动 draft-and-verify 并行解码
- On-policy distillation 在量化前向路径上由全精度教师监督并融合验证器奖励
- 只截断/丢弃、不重写且不压缩压缩结果的忠实自动压缩
- 扩散草稿 + 因果 AR 验证的自推测解码
- 混合粒度代理图与密集奖励 RL 优化协作拓扑

**结果信号**
- Flash-dLLM 在 GSM8K/HumanEval 上相对 Elastic-Cache 加速 5.1x/11.0x
- OPD 将 MATH-500 保持率 35%->70%、HumanEval 66%->91%
- CliffCompaction 成本最多降 50%，KernelBench 400 步达 3.58x kernel 加速
- GravityOCR 每前向提交 9.7 token，区域裁剪解码加速 3.94x
- SWE-Serve 揭示 E2E 测试拒绝约三分之一通过其他测试的补丁

1. [Imperfection for Precision: Upcycling Imperfect Data for High-Precision Robotic Manipulation](https://arxiv.org/abs/2609.26672v1)
   - 分类：Vision-Language-Action / Robot Manipulation
   - 研究价值：值得精读
   - 关联：直接对应具身智能中 VLA 操作模型的数据效率痛点，方法面向真实机器人亚毫米级高精度任务，与本组机器人学习主线高度相关。
   - 痛点：训练视觉-语言-动作（VLA）模型完成亚毫米级高精度操作时，通常严重依赖任务专用、通过遥操作采集的高质量数据，这类数据采集缓慢且成本高昂，成为规模化部署的主要瓶颈。与此同时，目标任务的低精度数据与来自不匹配任务的高精度数据往往被直接丢弃；而若把不同质量的数据简单混合做协同训练，低噪声阶段负责精细动作的生成又会被低精度数据污染，导致操作精度明显退化，难以在削减数据采集成本的同时保住精度。
   - 方法：ε4P 不改变模型结构，而是在 flow-matching 去噪轨迹上对数据来源做路由控制：在噪声较高、主要决定任务语义与全局规划的阶段，使用目标任务的低精度数据以保留高层任务上下文；在噪声较低、决定精细动作细节的阶段，使用来自不匹配任务的高精度数据以迁移底层动作精度。这样两类“不完美”数据按噪声区间各司其职，而不是在整条轨迹上均匀混合，从而把被丢弃的数据源系统性升级为可用的训练信号。
   - 结果：在真实机器人的亚毫米级高精度任务与粗粒度任务实验中，利用额外的低精度目标数据与高精度跨任务数据，策略性能最高提升 31.7 个百分点；当用等量非完美数据替换任务专用高质量数据时，平均性能仅下降 4.2 个百分点，说明该方法能在显著降低高质量数据采集成本的同时基本保持高精度操作能力，作者据此提出以异构非完美数据系统性替代昂贵任务专用数据的可扩展范式。

2. [φ-RIE: From Photorealistic Reconstruction to Interactive Environments](https://arxiv.org/abs/2609.26795v1)
   - 分类：3D Gaussian Splatting / Robotic Simulation
   - 研究价值：值得精读
   - 关联：把真实场景重建直接转化为机器人仿真可用的可交互环境，是具身智能中 sim-to-real 与场景资产化的重要一环。
   - 痛点：照片级重建与可交互物理仿真之间存在明显鸿沟：3D Gaussian Splatting 得到的是整体一致的场景表示，物体外观常与背景纠缠，被遮挡的物体几何与背景内容也未被观测，因此物体无法独立运动、接触或暴露其后方环境。机器人仿真需要的是物体级可编辑资产加上完整背景，而现有流程要么抠出资产却留下破损背景，要么保留原场景却无法交互，视觉保真与物理可交互性难以兼得。
   - 方法：φ-RIE 的核心观察是资产构建与源场景移除应当耦合：同一个物体身份既定义可运动的仿真资产，也定义需要从场景中移除并补全的内容。流水线先由 Scene Observation 提供共享证据，再交给 Coupled Scene Construction，同时生成互相配准的物体资产与补全后的背景 Gaussian，最终在 Interactive Environment 中由仿真器驱动渲染，未被编辑的 Gaussian 被完整保留，使视觉状态与物理状态保持一致。
   - 结果：在 50 个 ScanNet++ 场景上，基于证据的物体选取与配准重试在固定保留率下把 20 mm 阈值下的 matched F1 从 0.336 提升到 0.383；进一步实验验证了生成的资产可在仿真器中执行，操作成功率优于单一生成器基线，并量化了场景转换带来的视觉代价，表明该流程能实现从重建到可交互环境的场景转换。

3. [DreamStream: Towards Policy-Oriented Generative Simulation for End-to-End Driving](https://arxiv.org/abs/2609.26792v1)
   - 分类：Generative Simulation / End-to-End Driving
   - 研究价值：值得精读
   - 关联：面向端到端驾驶策略的闭环生成式仿真与评测指标，是具身智能中“仿真保真度应服务于策略决策”这一核心议题的直接体现。
   - 痛点：端到端驾驶策略的闭环评估需要仿真观测不仅照片级真实，还要保留策略真正依赖的场景特征，否则 sim-to-real 视觉差距会污染策略感知，使评估无法反映真实闭环决策能力。现有平台往往无法控制哪些特征被保留，而 FID 等常用感知指标与策略所需特征的保持程度排序不一致，导致错误地选出对策略扰动更大的仿真器，进而低估或误判策略的真实能力。
   - 方法：DreamStream 是一个生成式闭环仿真器，其核心是仿真器接地的自回归视频模型：以交通布局为引导，从大规模预训练视频模型蒸馏得到，在改变视觉外观的同时显式保留场景布局与动态物体的时序一致性。作者进一步提出 FDπ 多表征指标，用公开端到端策略的场景上下文特征之间的 Fréchet 距离来度量 sim-to-real 差距，并据此把非反应式的 NAVSIM 改造成带对抗驾驶行为与天气变化的交互式基准 Navhard-CL。
   - 结果：在 FDπ 指标下，DreamStream 在 nuScenes 上比最强前作闭环仿真器提升 1.6×，在 NAVSIM 上提升 4.7×，同时对策略感知可观测量的扰动最小；基于它构建的 Navhard-CL 基准把非反应式 NAVSIM 变成带对抗驾驶行为与天气变化的交互式测试环境，暴露出评分器偏差、缺乏恢复行为等此前闭环基准忽略的失效模式，并已开源代码与数据。

**主要痛点**

**原始摘要**

Diffusion Large Language Models (dLLMs) have recently emerged as a promising alternative to autoregressive LLMs by enabling non-autoregressive text generation. However, their practical deployment remains limited by inefficient inference, largely due to the absence of effective Key-Value (KV) caching and scalable parallel decoding mechanisms. Extensive experiments on mathematical reasoning and code-generation benchmarks demonstrate that Flash-dLLM consistently outperforms existing state-of-the-art dLLM acceleration methods in both inference speed and memory efficiency. ### 3. [StableVQ: Practical Guidelines for Stable Vector-Quantized Tokenizer Training](https://arxiv.org/abs/2609.26774v1)

- 来源：arXiv
- 关键词：autoregressive, guidelines for stable vector-quantized, stable vector-quantized tokenizer training., vector-quantized tokenizer training. vector, learning objective, codebook utilization
- 链接：<https://arxiv.org/abs/2609.26774v1>

**原始摘要**

Vector Quantization (VQ) is fundamental to discrete visual tokenizers that power modern autoregressive and masked image generation models. While recent shared-projection codebook methods have substantially advanced codebook utilization, training stability remains a critical and underexplored challenge. We argue that the root cause lies in the entanglement of the Encoder--Decoder and Codebook training: because neither module can reliably fulfill its own responsibility in isolation, the system can only function when the two subsystems happen to cooperate---a fragile condition that breaks down precisely when training is most stressed. We propose StableVQ, which revisits the proper learning objective of each module and resolves the problems that arise when each is trained to fulfill its own role independently. Built on top of shared-projection codebooks, StableVQ is lightweight and introduces no learnable parameters. Experiments on ImageNet demonstrate consistent improvements in training stability, codebook utilization, and reconstruction quality across diverse codebook sizes and initialization settings.
