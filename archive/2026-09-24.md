1. [On the Diffusibility of High-Dimensional Latents](https://arxiv.org/abs/2609.28473v1)
   - 分类：Latent Diffusion / Flow Matching
   - 研究价值：值得精读
   - 关联：直接关系到 RAE 类潜空间扩散/流匹配的训练参数化选择，对做文生图与潜空间生成的团队属于可立即落地的工程性结论。
   - 痛点：RAE 范式让扩散与流匹配模型直接在预训练视觉编码器的高维特征空间中生成，但现成编码器重建保真度不足、会丢弃细粒度细节；而为了图像重建去微调编码器虽然找回细节，却会降低表征的有效维度并改变其几何结构。此时流匹配中的标准速度预测被迫去拟合低维信号流形之外的正交噪声方向，训练目标与数据几何错位，导致优化效率低下、生成质量受限，成为高维潜空间扩散中一个不易察觉的隐藏瓶颈。
   - 方法：作者系统分析高维潜空间中速度预测的优化困难，指出其需要拟合远离信号流形的正交噪声分量，因而把大量容量浪费在无意义的噪声方向上；由此提出改用干净数据参数化（x0-prediction）替代速度预测，使训练目标直接作用于底层信号流形，把学习集中在有意义的低维结构上。方法不改变编码器与骨干网络结构，只替换扩散/流匹配的训练参数化方式，并在多个强重建编码器与文本到图像任务上做对照实验，验证不同参数化对可扩散性与生成性能的影响。
   - 结果：在多个强重建编码器的文本到图像实验中，x0-prediction 一致优于标准速度预测，显著提升生成性能，说明高维潜空间中所谓的可扩散性问题主要来自参数化与数据几何的错配，而非表征本身不可用。该结论为 RAE 类扩散模型提供了一个几乎零成本、只在训练期生效的修复方案，也提示在评估编码器时应同时考虑重建保真度与表征有效维度对下游生成的影响。

2. [Beyond Future Prediction: Denoising as Generative Adaptation for Robot Control](https://arxiv.org/abs/2609.28339v1)
   - 分类：Robot Policy / Diffusion Transformer
   - 研究价值：值得精读
   - 关联：回答生成式 DiT 先验迁移到控制时到底贡献什么，对把视频/图像生成模型用于动作与决策的方向有直接方法论价值。
   - 痛点：机器人策略越来越多地复用大规模图像或视频生成预训练的 Diffusion Transformer 先验，但这一先验究竟为动作学习提供了什么、应当如何迁移到控制，仍不清晰。主流做法默认必须通过预测未来视觉帧来完成迁移，于是引入额外的未来目标、额外的生成分支与更长的视觉 token 序列，训练与推理开销显著增加，却未必带来对应的控制收益。论文指出未来预测可能只是一个非必要的中间任务，真正的接口应是生成模型自身的去噪过程，这一认识缺口使现有方法在效率与鲁棒性上同时存在隐性损失。
   - 方法：作者提出 NowWAM，一种无需未来目标的协同训练范式：模型在同一视觉流上对当前观测进行去噪，并直接从该表征预测机器人动作，从而把生成模型的原生去噪目标与面向动作的表征在整条去噪轨迹上显式耦合。为厘清先验的作用，作者在匹配的受控设置下比较过去帧、未来帧等不同视觉目标，并测试仅用干净端点训练的效果，发现过去与未来目标表现相当，而限制在干净端点会显著降低鲁棒性。方法保持骨干不变，仅改变目标构造与条件方式，因此可即插即用地适配文本到图像或图像编辑类 DiT。
   - 结果：在 LIBERO-Plus 上，NowWAM 配合 FLUX2-Klein 达到 87.7%，比未来目标协同训练基线提升 6.1 个百分点，同时把训练视觉 token 从 784 降到 392，单步时间从 2.85 秒降至 1.63 秒，约 1.8 倍加速；换用纯文本到图像的 Z-Image 骨干仍达 87.8%，说明强控制适配并不依赖视频生成或图像编辑先验。受控实验还表明过去与未来视觉目标效果相当，而仅在干净端点训练会显著削弱鲁棒性，暗示真正有效的接口是去噪轨迹本身。

3. [LiMA: Bridging Long-term Imagination to Real-time Dexterous Manipulation via Asynchronous Diffusion](https://arxiv.org/abs/2609.28431v1)
   - 分类：Diffusion Policy / Dexterous Manipulation
   - 研究价值：值得精读
   - 关联：把扩散式世界动作模型改造成异步双系统，对生成模型在实时控制中的延迟瓶颈与意图-执行对齐问题给出可复用设计。
   - 痛点：灵巧操作同时要求长时程前瞻与毫秒级反应，但现有方案存在结构性时间错配：VLA 模型擅长高层语义推理，却缺乏对物理动力学与空间关系的细粒度理解；世界动作模型（WAM）依赖迭代式生成，推理延迟高，导致模型意图无法跟上快速变化的物理接触。二者都难以在同一推理循环中同时满足慢思考与快执行，意图规划与反应式控制之间的节奏差异成为制约真实机器人部署的核心瓶颈。
   - 方法：LiMA 提出异步双系统生成框架，把意图规划与反应式执行系统性解耦，并按多尺度层级组织计算：慢系统以稀疏方式生成长时程时空意图，快系统则在高频上对动作轨迹做密集精修。为把稀疏意图预测与密集动作轨迹对齐，作者引入 Latent Schrödinger Bridge Coupling，将精修过程建模为熵正则化的概率传输问题，在潜空间中建立意图与动作之间的最优耦合；异步调度使两个系统以不同频率运行，从而在保留长时程想象能力的同时压低整体推理延迟。
   - 结果：在六项覆盖不同时程的双臂灵巧操作任务上，LiMA 取得 70.8% 的总成功率与 78.9% 的平均子任务成功率，并在未见场景中保持性能；相比 Cosmos-Policy，异步解耦使推理延迟降低 45.8%。结果说明分层异步生成能够同时保留长时程意图与高频反应能力，为扩散式世界动作模型在实时灵巧操作中的落地提供了可行路径。

**主要痛点**
- 高维潜空间扩散的可扩散性受参数化与数据几何错配制约，速度预测被迫拟合信号流形外的噪声方向。
- 生成式先验迁移到控制/操作时，未来帧预测并非必要中间任务，却带来额外 token 与延迟开销，并存在意图与快速物理反馈的时间错配。
- 长时程视频生成与潜世界模型在有界上下文下丢失关键历史与运动信息，且常用像素误差指标会奖励静止预测，掩盖失效。

**方法趋势**
- 用干净数据参数化（x0-prediction）替代速度预测，把学习集中在信号流形上。
- 去噪式生成适配：直接对当前观测去噪并预测动作；异步双系统 + Schrödinger Bridge 耦合，实现慢意图与快执行解耦。
- 记忆机制设计：递归指数滤波器记忆状态、解码路径监督（DART）、逐点身份轨迹监督的点集扩散世界模型，以及零样本注意力掩码 + 潜变量锚定的编辑流水线。

**结果信号**
- x0-prediction 在多个强重建编码器上一致提升文生图质量；NowWAM 在 LIBERO-Plus 达 87.7%（+6.1 点）并把训练视觉 token 减半、单步提速约 1.8x。
- LiMA 推理延迟较 Cosmos-Policy 降低 45.8%，双臂灵巧操作总成功率 70.8%；PointCast 在四个 regime 中三个最优，MPC 规划与所有基线相当或更优。
- 评测层面出现共性结论：仅像素误差会奖励冻结预测，提示需要同时衡量运动正确性；记忆机制综述给出可组合资源感知记忆、可信状态更新与标准化评测等开放方向。

1. [MicroQonv: Reshaping Convolution Tensors for Efficient Microscaling in Training and Inference](https://arxiv.org/abs/2609.28358v1)
   - 分类：Quantization / Efficient Training and Inference
   - 研究价值：值得精读
   - 关联：直接针对卷积网络的高效训练与推理，通过微缩放量化减少内存移动和计算开销，适用于边缘设备和持续学习。
   - 痛点：微缩放量化在卷积层中应用时效率低下：传统方法需要将全精度权重和激活张量传输到处理单元，并分别量化两次，导致远超预期的内存移动；此外，im2col变换使激活张量尺寸显著膨胀，进一步增加量化开销。这些额外开销严重限制了低精度量化在卷积网络训练和推理中的实际加速效果，尤其是在边缘设备和资源受限场景下。
   - 方法：提出MicroQonv，将微缩放量化与卷积层的前向和反向操作紧密结合，确保每个张量只被量化一次；并创新性地在应用修改版im2col（channel-batch-first im2col）之前对激活张量进行量化，避免激活张量膨胀。该方法同时优化权重、梯度和激活的量化流程，显著减少内存移动和存储需求。
   - 结果：MicroQonv将权重和梯度的量化成本降低2倍，激活量化成本最高降低9倍；内存移动和存储最多减少7.53倍。在YOLOv8nano和YOLOV26nano上，量化激活的内存移动分别减少3.5倍和2.2倍。此外，它支持边缘持续学习中的4-bit微缩放量化潜在回放，准确率提升5.7%到11%，且精度损失可忽略。

2. [Memory Attention](https://arxiv.org/abs/2609.28399v1)
   - 分类：Efficient Attention / Memory
   - 研究价值：值得精读
   - 关联：通过用token索引内存替代值投影，大幅降低推理计算和内存，支持CPU卸载，属于高效推理的核心方法。
   - 痛点：标准Transformer注意力中，值向量由当前上下文的隐藏状态动态计算，即使某些内容可跨上下文复用，每次仍需重复计算和存储，导致推理时GPU内存和计算开销随序列增长而增加。这限制了长上下文和资源受限设备上的高效部署，成为大模型推理效率的关键瓶颈之一。
   - 方法：提出Memory Attention (MA)，用层特定的token内存与上下文键组合形成值：内存提供token特定表示，键保持上下文依赖性。推理时，归一化可折叠进内存表，值构建简化为查表和加法；token索引检索还支持CPU卸载与预取，减少GPU参数存储。
   - 结果：在匹配训练token预算下，多种注意力配置上语言建模和下游平均性能均有提升。该方法减少了GPU参数存储，并通过查表加法实现高效值构建，为长上下文推理和资源受限部署提供了新思路。

3. [LiMA: Bridging Long-term Imagination to Real-time Dexterous Manipulation via Asynchronous Diffusion](https://arxiv.org/abs/2609.28431v1)
   - 分类：Efficient Inference / Robotics
   - 研究价值：值得精读
   - 关联：通过异步扩散架构将长期意图规划与实时动作执行解耦，显著降低推理延迟，实现实时灵巧操作，属于高效推理在机器人领域的前沿应用。
   - 痛点：灵巧操作需要同时具备长期预见和快速反应控制，但现有VLA模型缺乏细粒度物理动态理解，世界动作模型因迭代生成导致高推理延迟，造成意图无法适应快速物理接触变化，形成严重的时间错位。这一瓶颈限制了机器人在动态环境中的实时操作能力。
   - 方法：提出LiMA，一种异步双系统生成框架，将意图规划与反应执行解耦：慢系统处理稀疏长时程时空意图生成，快系统进行密集高频运动细化。为对齐稀疏意图与密集动作，引入Latent Schrödinger Bridge Coupling机制，将细化建模为熵正则化概率传输过程。
   - 结果：相比Cosmos-Policy，LiMA将推理延迟降低45.8%。在六个双臂灵巧操作任务上，总体成功率达到70.8%，子任务平均成功率78.9%，并在未见场景中保持性能。项目网站提供演示，验证了异步扩散在实时灵巧操作中的有效性。

**主要痛点**
- 高效训练与推理中，量化、注意力、扩散模型等面临内存移动、计算开销和延迟瓶颈。
- 微缩放量化在卷积层中因重复量化和im2col膨胀导致效率低下；注意力值计算重复且占用GPU内存。
- 机器人实时操作中，VLA和世界模型推理延迟高，难以适应动态物理交互；长上下文和资源受限部署困难。

**方法趋势**
- MicroQonv通过单次量化和channel-batch-first im2col降低卷积量化开销；Memory Attention用token内存表替代值投影，支持查表加法。
- LiMA采用异步双系统扩散解耦意图规划与反应执行，用Latent Schrödinger Bridge Coupling对齐稀疏意图与密集动作。
- 轻量级模型如LightMIS和Mizar通过架构压缩实现设备端高效推理；DART和x0-prediction等改进训练信号提升效率。

**结果信号**
- MicroQonv降低量化成本2-9倍，内存移动减少7.53倍；Memory Attention提升语言建模和下游性能；LiMA降低推理延迟45.8%，双臂任务成功率70.8%。
- LightMIS仅0.131M参数达到86.71% Dice；Mizar 159M参数在MMAU等基准超越同规模模型，单CPU延迟1.09秒。
- UECR-GRPO在数学推理上提升0.89-0.56个百分点；EWC微调保持通用能力但MT指令遵循仍受限；DART恢复运动时间结构。

2. [Watch, Recall, Act: Always-On Robots in Concurrent Embodied Streams](https://arxiv.org/abs/2609.28429v1)
   - 分类：Embodied Streaming Policy / Always-on Robotics
   - 研究价值：值得精读
   - 关联：对应具身智能中的常开机器人、长时程记忆与双臂并发控制，与团队关注的流式策略与世界模型记忆机制直接相关。
   - 痛点：现有动作模型假设固定指令、任务中途无干预、单步推理，而真实常开（always-on）机器人面对的是永不重置的无尽流：指令随时到达与失效，场景持续变化，机器人自身过去的动作又反过来改变当前需要推理的内容。这种开放世界设定要求策略同时具备远未来线索的观察、远过去自身动作的回忆以及双臂并发执行能力，而当前策略在长时程上下文管理上几乎缺位，导致记忆与并发成为性能瓶颈。
   - 方法：ARMS 刻意保持简单：以单个预训练 π0.5 为骨干，外挂三个轻量上下文提供模块，分别把实时感知、本体状态与机器人自身历史动作编码为骨干在动作前读取的上下文；这些模块异步更新上下文，使“观看”和“回忆”不阻塞“行动”，双腿双臂可并行执行。为避免额外标注，作者构建 ARMS Dataset，用分阶段构造脚本从真实双臂遥操作数据中自动为每个模块生成监督信号，并引入 agent-causal 自历史记录哪条手臂在何时做了什么。
   - 结果：在双臂并发任务上，ARMS 取得 45% 的综合成功率，而四个主要基线中最强者仅为 28%，提升显著。消融实验确认记忆模块、本体状态预测头与异步并发机制三者缺一不可，移除任一项都会造成明显性能下降。结果表明，把常开流式上下文管理做对，比引入更复杂的新机制更能提升持续任务表现，也为常开机器人的自监督数据构造提供了可复用流水线。
