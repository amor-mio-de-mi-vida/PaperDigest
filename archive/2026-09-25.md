1. [WanPE: Towards Cinematic Prompt Enhancement for Modern Text-to-Video Generation](https://arxiv.org/abs/2609.30221v1)
   - 分类：Text-to-Video Generation / Prompt Enhancement
   - 研究价值：值得精读
   - 关联：直接面向文本到视频生成，属于生成式AI中最核心的提示词增强与长视频叙事规划方向，与团队的视频生成/扩散工作高度相关。
   - 痛点：文本到视频生成正从几秒短片走向 30 秒以上的多镜头叙事，提示词需要同时规划动作、镜头轨迹、光照乃至声音，普通用户很难写出这种导演级脚本。现有提示词改写方法多为前向重写，在多镜头与长时间跨度上容易丢失或漂移用户原始意图，导致生成内容与需求不一致；同时业内也缺少针对长视频提示增强的系统化评测基准，改进方向难以量化。
   - 方法：作者构建了 1.05M 真实视频数据集，采用“视频反推”（video-grounded reverse construction）从成片还原出镜头级电影规划文本，训练 397B 参数的提示增强模型。为保持跨镜头、跨时间的语义一致性，提出 Semantic-Consistency GRPO（SC-GRPO），在强化学习目标中显式约束用户需求不漂移。同时构建 WanPEval 人类标注基准，覆盖 5–30 秒时长与不同意图粒度，含约 11K 次盲测成对评估。
   - 结果：在驱动 Wan3.0 视频生成器时，WanPE-397B 相比原始用户提示在 5–15 秒区间将人类偏好提升 10.66–18.84 分，在 30 秒区间提升高达 50.86 分。消融实验显示反向构建明显优于前向改写，SC-GRPO 在不同模型规模下都能稳健保持语义保真。最终模型在 5–15 秒上超过所有被评测的商业方案，并在 30 秒上与 Seedance 2.5 保持竞争。

2. [Accelerating Video Diffusion via Training-Free Trajectory Routing](https://arxiv.org/abs/2609.30096v1)
   - 分类：Video Diffusion / Inference Acceleration
   - 研究价值：值得精读
   - 关联：视频扩散推理加速是生成式AI落地的关键工程方向，该方法免训练、即插即用，可直接套用到现有视频扩散骨干上。
   - 痛点：视频扩散模型需要在数十个去噪步上反复执行大模型，即便使用步数蒸馏，每个蒸馏步仍要付出一次昂贵的前向计算，推理延迟居高不下。已有加速手段（再蒸馏、缓存、量化）通常需要重训练、修改架构或调度器，或依赖在线双模型评估，难以即插即用地部署到已有大模型上，并且容易牺牲生成质量与输出多样性。
   - 方法：TRACK 先用大模型跑一条参考轨迹，并在每个去噪步同时采集小模型对相同 latent、时间步、条件与引导输入的预测，计算两者的相对分歧分数。在校准集上聚合该信号，得到跨去噪步的分歧分数图，据此制定切换策略：质量敏感的步继续用大模型，分歧低的步路由到小模型。推理时每步只执行被选中的单个模型，无需重训练、不改架构与调度器，也不做在线双模型评估。
   - 结果：在 Wan 2.1、Cosmos 3、TurboDiffusion 与 FastVideo 四个视频扩散系统上，TRACK 分别取得 1.95×、2.04–2.73×、2.69× 与 2.17× 的推理加速。加速后总体生成质量与基线相当，且多样性保持较高。结果说明自动化的免训练模型切换可以成为一种通用的视频扩散加速范式。

3. [Rolling-WAM: World Action Models with Rolling Imagination](https://arxiv.org/abs/2609.30247v1)
   - 分类：World Action Models / Video-Action Joint Diffusion
   - 研究价值：值得精读
   - 关联：把视频-动作联合去噪分摊到多次重规划周期，直接服务扩散式机器人与闭环实时控制，属于生成式模型在具身场景的前沿交叉。
   - 痛点：世界动作模型把动作生成与未来视觉预测耦合在一起，但每个重规划周期都要完整跑一遍视频-动作联合去噪，计算延迟很大，导致动作更新滞后、闭环响应变慢。未来视频帧的生成开销与机器人所需的控制频率严重不匹配，使这类扩散式模型难以在实际机器人上以高频控制回路运行。
   - 方法：Rolling-WAM 把联合去噪分散到连续的重规划周期中：维护一个滑动窗口的视频-动作块，各块处于错开的噪声水平，并采用滚动噪声调度。每个控制步只把即将执行的动作块完全去噪，对更远的未来块仅做部分去噪；随着新相机观测到来，窗口向前推进，被保留的未来块延续其去噪过程，从而把计算成本在时间上摊销，并在块边界之间携带不断演化的视觉-动作上下文。
   - 结果：在 LIBERO、RoboTwin 以及真实 Unitree G1 人形机器人上，Rolling-WAM 取得与标准联合 WAM 相当的操作性能。由于不再需要每个周期从头去噪整个预测时域，它实现了 4.5× 的稳态重规划加速，显著提升了闭环响应能力。

**主要痛点**
- 长视频文生视频缺乏可靠的导演级提示规划，现有前向改写易丢失用户意图
- 视频扩散推理在数十个去噪步上反复执行大模型，即便蒸馏后每步仍昂贵，且多数加速方案需重训练或改架构
- 世界动作模型每个重规划周期完整跑联合去噪，延迟大，无法匹配机器人高频闭环控制
- 世界模型规划以目标图像编码距离打分，忽略“先远离目标才能到达”的反事实结构
- 生成式三维资产缺乏全局一致、不含烘焙光照的纹理与可用的跨模态几何条件

**方法趋势**
- 用视频反推构建镜头级规划数据并配合语义一致性 GRPO 做提示增强
- 基于大/小模型逐步预测分歧的校准路由实现免训练视频扩散加速
- 用错开噪声水平的滑动窗口把视频-动作联合去噪摊销到连续重规划周期
- 在动作流形上做黎曼条件流匹配加流映射一致性目标实现单步动作生成
- 用锚点级因果分解与整数推理简化 3DGS 熵编码上下文

**结果信号**
- WanPE-397B 使 5–15 秒人类偏好提升 10.66–18.84 分、30 秒提升 50.86 分，领先商业方案
- TRACK 在 Wan 2.1/Cosmos 3/TurboDiffusion/FastVideo 上取得 1.95×–2.73× 加速且质量与多样性保持
- Rolling-WAM 在 LIBERO、RoboTwin 与真实 G1 上性能持平标准 WAM 并实现 4.5× 稳态重规划加速
- RMFP 在多个操作基准上以更低采样成本达到竞争性能，并支持单次函数评估
- AD-WM 将 OGBench-Cube hard-start 成功率从 3.7% 提升到 52.0%，Franka 零样本抓放从 42.2% 提升到 71.1%

1. [Accelerating Video Diffusion via Training-Free Trajectory Routing](https://arxiv.org/abs/2609.30096v1)
   - 分类：Video Diffusion Inference Acceleration
   - 研究价值：值得精读
   - 关联：直接针对视频扩散模型推理昂贵的问题，提出训练无关的轨迹路由加速方法，属于高效推理核心方向。
   - 痛点：视频扩散模型需要在多个去噪步上反复执行大模型，即使经过步蒸馏，每一步仍需昂贵模型评估，导致推理延迟和算力成本高，难以在实时或大规模场景部署。现有加速方法常需重训练、改架构或在线双模型评估，适用性受限。尤其视频扩散同时处理时空维度，计算量远高于图像扩散，因此需要一种不修改模型、不重训练且能保持生成质量与多样性的通用推理加速方案。
   - 方法：TRACK 采用异构去噪策略，在选定的去噪步之间切换兼容的大模型和小模型。它先用大模型跑参考轨迹，并在每个步收集小模型预测，与同潜变量、时间步、条件和引导输入下的大模型预测比较，得到相对分歧分数。再在校准集上聚合该信号，形成跨扩散步的分歧分数图，从而确定切换策略：质量敏感步保留大模型，低分歧步路由到小模型。推理时每步只执行被选中的模型，无需重训练、架构或调度器改动，也无需在线双模型评估。
   - 结果：在 Wan 2.1、Cosmos 3、TurboDiffusion 和 FastVideo 上，TRACK 分别取得 1.95 倍、2.04–2.73 倍、2.69 倍和 2.17 倍加速，同时保持可比的总体生成质量和较高的多样性保留率。实验覆盖多个主流视频扩散系统，说明方法具有跨模型泛化性。该方法证明自动、训练无关的模型切换可以作为视频扩散推理加速的实用范式，为在不重训练条件下降低扩散采样成本提供了新路径。

2. [Rolling-WAM: World Action Models with Rolling Imagination](https://arxiv.org/abs/2609.30247v1)
   - 分类：Robot World Models / Inference Acceleration
   - 研究价值：值得精读
   - 关联：通过滚动去噪把联合视频-动作去噪分摊到多个重规划周期，直接降低闭环推理延迟，属于高效推理方向。
   - 痛点：World Action Models 将动作生成与未来视觉预测耦合，但在每个重规划周期都要完整执行联合视频-动作去噪，造成显著推理延迟，推迟动作更新并限制闭环响应能力。机器人操作需要高频重规划，这种从零去噪整个预测范围的方式难以满足实时控制要求。因此需要一种能把去噪计算沿时间分摊、同时保留跨块视觉-动作上下文的推理方案。
   - 方法：Rolling-WAM 将联合去噪分散到连续的重规划周期中。它维护一个滑动窗口，窗口内视频-动作块处于交错噪声水平；每一步的滚动噪声调度会完全去噪即将执行的动作块，同时部分精炼更远未来的块。随着新相机观测推进窗口，保留的未来块继续其去噪过程，从而把计算成本摊到时间上，并在块边界间携带演化的视觉-动作上下文。
   - 结果：在 LIBERO、RoboTwin 和真实 Unitree G1 人形机器人上，Rolling-WAM 取得有竞争力的操作性能，并相比标准联合 WAM 实现 4.5 倍稳态重规划加速。实验表明，无需从零去噪整个预测范围也能保持操作质量，同时显著提升闭环响应速度。该工作为实时机器人操作提供了一种通过滚动想象降低推理延迟的高效方案。

3. [PoEM: Predicting RL Outcomes from Existing Policies](https://arxiv.org/abs/2609.30226v1)
   - 分类：RL Post-Training Efficiency
   - 研究价值：值得精读
   - 关联：通过预测新奖励下的 RL 结果，避免重复运行昂贵的 RL 后训练，属于高效训练方向。
   - 痛点：基础模型常用强化学习进行后训练，以最大化人类对齐、正确性或指令遵循等奖励，但该过程计算密集、有时不稳定，且每当奖励模型改变或需要组合多个奖励时都要从头运行 RL。如何在不实际执行 RL 的情况下预测新奖励函数的策略结果，是降低后训练成本的关键痛点。该问题在奖励频繁变化和多奖励组合场景中尤为突出。
   - 方法：PoEM 利用一组已在其他奖励上后训练好的模型来预测新奖励下的 RL 输出。作者首先证明，若新奖励是已有奖励的线性组合，则新策略在 log 空间可写为已有 log 策略的线性组合；即使奖励非线性相关，RL 训练得到的 log 策略也常跨奖励张成近似低秩子空间。基于此，算法仅用奖励或基策略在样本上的输出估计组合权重，从而近似目标 RL 策略，而无需任何额外 RL 训练。
   - 结果：在合成奖励和真实奖励、文本与图像模态上，PoEM 验证了该预测框架的有效性，能够在不运行额外 RL 的情况下近似目标策略。结果表明，利用已有后训练模型可以显著降低新奖励适配的计算开销。该工作为奖励变化和组合场景提供了一种高效的后训练替代方案，并揭示了 RL 策略在 log 空间中的近似低秩结构。

**主要痛点**
- 视频扩散、机器人世界模型和 GUI 代理等在多步推理中反复调用大模型，导致延迟和算力成本高。
- RL 后训练和策略学习计算密集、不稳定，奖励变化或硬件偏移时需重复训练或现场重标定。
- 长时程代理推理和稠密跟踪易受误差累积与内存瓶颈限制，缺少训练无关或表示层面的高效方案。

**方法趋势**
- 训练无关的模型切换与滚动去噪，把大模型容量集中到质量敏感步骤并沿时间分摊计算。
- 利用已有策略预测 RL 结果、检索与闭式校正替代端到端策略训练，以及通过编译技能减少重复推理。
- 潜在表示训练干预、3D 去重与特征采样、量化感知整数推理等降低推理内存与计算开销。

**结果信号**
- TRACK 在多个视频扩散系统上取得 1.95 到 2.73 倍加速，Rolling-WAM 获得 4.5 倍重规划加速。
- Jev-Mobile 降低端到端执行时间 32.7%、API 成本 73.4%；Training-free BC 将策略拟合从小时降到秒级并支持 75 Hz 控制。
- PoEM 无需额外 RL 即可近似新奖励策略；潜在代理干预将长展开误差降低约 40% 并节省两个数量级 FLOPs。

1. [Instrumental Monitor Evasion Emerges Under Ordinary Task Pressure](https://arxiv.org/abs/2609.30217v1)

   - 关联：直接对应本团队对智能体运行时监控与安全评测的关注：EvasionBench 提供了可复用的任务-策略对与量化指标，若我们在 agent 产品中部署监控器，必须按此设定评估抗反复尝试的能力，而不能只看单次拦截率。

**原始摘要**

Latent world models are typically trained to predict factual transitions, whereas model predictive control (MPC) must compare alternative actions from the same state. ### 2. [Rolling-WAM: World Action Models with Rolling Imagination](https://arxiv.org/abs/2609.30247v1)

**原始摘要**
