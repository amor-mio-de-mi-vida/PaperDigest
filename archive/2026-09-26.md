1. [WanPE: Towards Cinematic Prompt Enhancement for Modern Text-to-Video Generation](https://huggingface.co/papers/2609.30221)
   - 分类：Text-to-Video / Prompt Enhancement
   - 研究价值：值得精读
   - 关联：面向扩散/流匹配文生视频模型的提示前端优化，直接关联生成式AI的可控生成与人类偏好对齐方向。
   - 痛点：当前主流文生视频模型虽能生成高分辨率、时序连贯的视频，但普通用户输入的提示往往只有主体与动作，缺乏镜头类型、景别、运镜、光影、构图与色彩风格等电影语言要素，导致输出视频观感平庸、镜头意图不明确；同时现有提示改写方法要么依赖通用LLM做简单扩写，容易引入与视觉模型能力不匹配的幻觉细节，要么缺少针对视频生成模型偏好的奖励信号，无法保证增强后的提示真正提升成片质量。该论文正是针对提示词与电影级视频生成能力之间的鸿沟这一具体痛点。
   - 方法：论文提出 WanPE 框架，核心是电影化提示增强。首先构建带镜头语言标注的电影摄影知识库与提示-视频偏好数据，训练增强模型把简短用户提示改写为包含景别、机位、运镜、光线、色调与叙事节奏的结构化电影提示；随后引入面向视频生成模型的偏好筛选或奖励重排机制，用生成结果的美学与语义一致性反馈过滤候选提示，避免通用LLM扩写带来的视觉不可实现细节。整个流程可即插即用地接入现有T2V模型，无需改动视频生成主干。
   - 结果：在多个文生视频基准与用户研究中，WanPE 增强后的提示在视觉美感、电影感、镜头语言遵循度与文本-视频对齐等指标上均优于原始提示和通用LLM扩写基线；与主流T2V模型结合时，生成视频的人类偏好胜率明显提升，同时保持语义一致性与时序稳定性。消融实验进一步表明，电影摄影知识注入与面向生成模型的偏好筛选是收益的主要来源，说明面向电影语言的提示增强是提升现代文生视频观感的有效且低成本路径。

2. [AV-GRPO: Modality-Anchored Decoupling Diffusion Reinforcement Learning for Joint Audio-Video Generation](https://huggingface.co/papers/2609.29816)
   - 分类：Audio-Video Generation / Diffusion RL
   - 研究价值：值得精读
   - 关联：把强化学习后训练引入多模态扩散生成，属于生成式AI中扩散强化学习与联合音视频生成的前沿交叉方向。
   - 痛点：音视频联合生成模型通常共享或耦合去噪过程，但音频与视频在数据分布、时间尺度和评价指标上差异巨大；直接用统一奖励做RL微调时，梯度会被某一模态主导，出现视频更清晰但音画不同步、或音频质量提升但画面退化的跷跷板现象。同时扩散模型的多步采样使奖励信用分配困难，终端奖励难以稳定回传到每一个去噪步。现有工作多依赖SFT或简单加权，缺乏对模态间优化冲突的显式解耦机制，因此该论文针对的是多模态扩散RL中优化目标冲突与信用分配这两个具体痛点。
   - 方法：AV-GRPO 的核心是模态锚定与解耦。它把联合去噪轨迹拆分为音频分支与视频分支，各自以本模态的锚点表示作为条件与优势基准，避免跨模态梯度干扰；在 GRPO 框架下对扩散采样过程做组内相对优势估计，将终端音视频对齐奖励分解到各去噪步，实现无需critic的稳定策略优化。此外设计模态平衡的奖励归一化与锚点对齐约束，抑制单一模态主导，并可叠加在现有联合扩散或流匹配骨干上。
   - 结果：在联合音视频生成基准上，AV-GRPO 相比联合SFT与统一奖励RL基线，在音视频同步、唇形一致、音频质量与视频质量上取得更优或相当的平衡，模态跷跷板现象显著缓解；人类主观评测中同步性与整体观感胜率提升。消融实验表明模态锚定与解耦优势估计是性能提升的关键，去掉任一模块都会导致单模态主导回归，且方法对现有联合扩散/流匹配骨干具有通用性。

3. [Training Object Permanence in World Models](https://huggingface.co/papers/2609.28654)
   - 分类：World Models / Video Generation
   - 研究价值：值得精读

   - 痛点：视频世界模型虽能生成逼真未来帧，但普遍缺乏物体永久性：当物体被遮挡、离开画面或被其他物体覆盖后，模型往往将其从隐状态中抹去，导致物体重新出现时被生成成新物体、外观与位置漂移，长时程rollout出现对象消失与场景不连贯。这一缺陷严重限制世界模型在具身智能、规划与交互式生成中的应用，而现有训练目标只优化像素或潜空间预测，未显式激励对不可见物体的持续表征，因此该论文针对的是世界模型中不可见物体表征丢失这一具体问题。
   - 方法：论文提出面向物体永久性的训练框架：构建带受控遮挡、移出视野与重现事件的合成视频课程，迫使模型在物体不可见期间仍维持其身份与位置信息；在潜空间引入记忆槽或状态保持正则，并设计遮挡前后的一致性预测目标与身份判别损失，使模型学会区分暂时不可见与真正消失。该训练可叠加在现有视频扩散或自回归世界模型之上，不改变推理接口。
   - 结果：在遮挡与重现评测中，训练后的世界模型能更准确地恢复被遮挡物体的外观与位置，物体身份保持指标与长时程预测一致性明显优于基线，且在不牺牲一般视频预测质量的前提下减少对象消失伪影。跨数据集与跨模型消融显示，遮挡课程与潜空间记忆正则缺一不可，证明物体永久性可以通过针对性训练显式获得，而非仅靠模型规模涌现。

**主要痛点**
- 文生视频提示缺乏电影语言，通用LLM扩写与视频模型偏好不匹配；
- 音视频联合扩散生成中模态优化冲突，统一奖励RL出现单模态主导；
- 视频世界模型缺乏物体永久性，遮挡后隐状态遗忘导致长程rollout不连贯；

**方法趋势**

- 按模态解耦扩散去噪轨迹，以模态锚点构建优势并用GRPO做无critic策略优化；

- 把世界建模转为对结构化状态表示的动作条件编辑，只学习状态差分。

**结果信号**

- 长程智能体任务误差累积与幻觉动作比例下降，成功率与规划效率提升。

1. [World Action Agent: Harnessing VLMs for Robot Manipulation via World Action Rehearsal](https://huggingface.co/papers/2609.29964)
   - 分类：VLM / Robot Manipulation
   - 研究价值：值得精读
   - 关联：直接对应具身智能中"VLM 作为机器人策略"的主线，把世界模型从感知工具变成动作预演器，与本组关注的想象式规划、模型预测控制高度重合，可作为下一阶段策略主干网络的候选方案。
   - 痛点：当前用 VLM 做机器人操作的主流范式是"看图直接出动作"，模型把视觉语言先验直接映射成末端控制，缺乏对动作后果的前向推演，因此在接触密集、长时程或有遮挡的任务上容易开环犯错，且无法在真实执行前评估多个候选动作的可行性；同时，单纯扩大 VLM 规模带来的收益迅速饱和，说明瓶颈不在语义理解，而在缺少一个可交互、可回滚的动作级世界模型。
   - 方法：论文提出 World Action Rehearsal 框架：VLM 不再直接回归动作，而是先在高层的"世界动作空间"中生成若干候选动作序列，交由一个世界模型在执行前进行想象推演，预测每一步的视觉/状态后果，再由 VLM 本身作为评审者对各条想象的轨迹打分与筛选，最终只把最优序列下发到真实机器人；整个循环把语言模型的推理能力与世界模型的动力学预测耦合起来，形成"生成—预演—评审—执行"的闭环，并可利用真实执行结果对世界模型做在线校正。
   - 结果：在多个机器人操作基准上，World Action Agent 相比直接动作回归的 VLM 基线取得一致提升，尤其在需要多步推理和接触判断的任务上成功率增幅最明显；消融实验显示，去掉动作预演环节后性能回落到普通 VLM 策略水平，而增加预演候选数量与推演步数可持续收益，证明了"先想象再执行"这一机制而非模型规模是性能提升的主要来源。

2. [Training Object Permanence in World Models](https://huggingface.co/papers/2609.28654)
   - 分类：World Models / Object Permanence
   - 研究价值：值得精读
   - 关联：物体永久性是具身智能体做长时程规划的基础能力，该工作直接针对世界模型在遮挡下遗忘物体的顽疾，与本组在模型预测控制、交互式仿真环境中的研究方向直接相关，训练技巧可迁移到机器人世界模型。
   - 痛点：现有世界模型大多在短时间窗上用重构或下一帧预测目标训练，隐状态没有"物体持续存在"的归纳偏置，一旦目标被遮挡、离开视野或短暂消失，其表征就被迅速冲刷掉，导致恢复可见时预测漂移、物体身份错乱，进而让基于世界模型的长时程规划与探索彻底失效；这一问题在机器人操作与导航中普遍存在，却很少被显式当作训练目标来处理。
   - 方法：论文把物体永久性从"涌现能力"变成显式的训练信号：构建包含物体被遮挡、移出视野再重新出现的序列数据，在隐空间中以槽位或物体级表征承载实体，并施加遮挡一致性约束，要求无观测期间物体表征保持稳定、重新出现时与真实观测对齐；同时引入记忆读写机制，让模型在缺失观测时用历史状态外推，而非依赖当前帧注意力。
   - 结果：实验表明，经过永久性训练的世界模型在长时遮挡后仍能准确恢复物体的位置与外观，长时程预测误差与物体漂移指标较标准训练基线显著下降，且在未见过的遮挡模式上具备一定泛化；下游使用该世界模型进行规划的智能体在多步任务上的成功率同步提升，说明显式建模物体持续存在是提升世界模型物理一致性的有效路径。

3. [OmniEcho: Spatial Audio Understanding for Embodied Agents](https://huggingface.co/papers/2609.23407)
   - 分类：Spatial Audio / Embodied Perception
   - 研究价值：值得精读
   - 关联：具身智能体的感知长期偏重视觉，该工作补上空间听觉这一维度，对非视距目标搜索、人机共处场景与多模态状态估计都有直接价值，可作为本组多模态感知栈的扩展模块。
   - 痛点：具身智能体的感知栈几乎被视觉垄断，而声音携带的方位、距离与事件线索在视觉被遮挡或目标在视野之外时不可替代；现有音频模型多停留在单声道分类或语音识别层面，缺少面向具身决策的空间音频理解，无法稳定输出"声源在哪个方向、离我多远、是否正在接近"这类可直接驱动导航与抓取的信息，导致智能体在非视距场景下表现迟钝。
   - 方法：论文提出 OmniEcho，用双耳/多通道音频作为输入，联合建模通道间的时间差与强度差等方向线索，并与视觉观测做跨模态对齐，训练目标同时包含声源方位回归、空间语义描述生成与音视一致性判别；模型输出不仅给出声源的空间位置与类别，还能以自然语言形式描述声学场景，从而可被上层语言智能体直接调用。
   - 结果：在空间音频理解与音视对齐任务上，OmniEcho 相比单模态与朴素拼接基线在声源定位精度和语义描述质量上均有明显提升，并在未见房间声学条件下保持较稳定的方位估计；接入具身智能体后，其在视野受限的目标搜索与声音引导导航任务中表现出更高的效率，验证了空间听觉作为具身感知补充通道的有效性。

**主要痛点**

- 跨模态对齐与解耦式强化学习：双耳音频与视觉联合建模，模态锚定 GRPO 缓解多模态奖励冲突。

**结果信号**
- 动作预演与物体永久性训练均带来多步任务成功率与长时程预测指标的显著提升，消融验证机制本身是增益来源。
- 空间听觉接入后，智能体在声音引导搜索与非视距导航中的效率明显改善。
- 对话式具身队友可在真实对抗环境中与人类完成多轮战术配合，验证语言—动作闭环的工程可行性。
