1. [AV-GRPO: Modality-Anchored Decoupling Diffusion Reinforcement Learning for Joint Audio-Video Generation](https://huggingface.co/papers/2609.29816)
   - 分类：Audio-Video Generation / RL for Diffusion
   - 研究价值：值得精读
   - 关联：把 GRPO 式强化学习引入多模态扩散后训练，直接对应生成式 AI 从监督微调走向奖励优化与跨模态对齐的趋势。
   - 痛点：联合音视频生成需要在同一扩散过程中同时建模视觉与听觉模态，但两模态的去噪轨迹、时空尺度与语义粒度差异大，简单共享骨干会导致模态干扰与对齐漂移；同时，缺乏可直接优化的音视频同步奖励，使生成结果常出现唇形不同步、事件与声音错位等问题，现有监督微调难以在推理阶段持续改善一致性。尤其在长视频与复杂场景下误差累积明显。因此，如何在保持单模态生成质量的同时实现跨模态对齐，是可交互音视频生成走向实用的关键瓶颈。
   - 方法：论文提出模态锚定的解耦扩散强化学习框架 AV-GRPO：先将联合去噪过程拆分为音频分支与视频分支，各自保留模态特定的扩散调度与网络参数，再通过跨模态锚定注意力与共享语义潜变量在关键时间步交换信息，避免早期轨迹互相污染；随后引入群体相对策略优化（GRPO），把音视频同步、语义一致与感知质量设计为奖励函数，对采样出的多组去噪轨迹做相对排序并回传梯度，从而在无需人工标注偏好对的情况下直接优化生成策略，同时用锚定正则约束两分支不偏离各自模态先验。
   - 结果：在音视频联合生成基准上，AV-GRPO 在音频-视频同步指标、跨模态语义对齐与 FVD/FAD 等生成质量指标上均优于联合扩散与两阶段基线；消融表明模态解耦与锚定注意力分别贡献了同步性与语义一致性的主要增益，GRPO 相比监督微调在相同采样预算下样本效率更高；定性结果显示模型能生成唇形同步、事件与声音对齐的视频，并在复杂场景与长片段上保持稳定，训练过程也更不易出现模态坍缩。

2. [Agent-Editing World Model: Rethinking World Modeling for LLM Agents](https://huggingface.co/papers/2609.28416)
   - 分类：LLM Agents / World Models
   - 研究价值：值得精读
   - 关联：将世界模型从预测式生成转向可逆编辑，与扩散编辑、可控生成的思想互通，为生成式 AI 在智能体规划中的应用提供新范式。
   - 痛点：以 LLM 为核心的智能体通常依赖世界模型预测下一状态来支撑规划，但真实环境状态空间庞大且不可完全观测，逐步预测完整状态既昂贵又易累积误差；同时，许多任务只关心动作对局部状态的改变，完整重建未来状态属于计算浪费，导致长程任务成功率低、rollout 开销大，且学到的世界模型难以跨任务泛化。此外，现有方法难以把语言先验与状态动态有效结合，动作效果建模缺乏可解释、可组合的表示。
   - 方法：论文把世界建模从“预测”重构为“编辑”：不再自回归生成完整未来状态，而是学习一个在潜在状态上执行局部、可逆编辑的算子，动作被表示为对当前状态表征的编辑指令；具体以 LLM 作为编辑器，输入当前观测的语言化潜码与动作描述，输出状态差异或编辑 token，再通过轻量解码器还原受影响区域，并引入可逆性与稀疏性约束保证编辑局部化；训练时用逆动作重建与多步一致性损失，使世界模型可组合、可回滚，并支持把编辑序列直接用于规划搜索。
   - 结果：在多个 agent 基准上，Agent-Editing World Model 相比下一状态预测式世界模型降低了状态预测误差，长程任务成功率提升，同时 rollout 计算量显著减少；由于编辑算子可组合，模型在小样本新任务上也能快速适配，并可回滚错误编辑，提高规划的鲁棒性；消融显示局部编辑与可逆约束是性能提升的关键，论文还表明语言先验有助于动作效果的零样本泛化。

3. [Training Object Permanence in World Models](https://huggingface.co/papers/2609.28654)
   - 分类：World Models / Video Generation
   - 研究价值：值得精读
   - 关联：直指视频世界模型的核心物理直觉缺失，与生成式 AI 中长期一致性、记忆建模的研究主线高度相关。
   - 痛点：视频世界模型在长时程 rollout 中经常出现物体凭空消失、瞬移或身份漂移，因为它们只拟合像素统计，未显式建模“物体在遮挡后仍持续存在”这一客体永久性先验；这使交互式仿真与基于模型的规划不可靠，尤其在需要记忆与遮挡推理的任务中，误差随步数快速累积。现有数据也缺少遮挡—重现的监督信号，模型难以从被动观测中自发学会持续表征。
   - 方法：论文在训练中显式注入客体永久性监督：构造物体被遮挡后重新出现的视频片段，要求模型在遮挡期间仍维持该物体的潜在表征与位置估计；引入记忆槽与状态跟踪模块，把物体特征写入持久记忆并在重现时读回，同时设计课程学习逐步延长遮挡时长、增加干扰物数量；损失上结合重建、对比与位置回归，鼓励身份一致的表征。
   - 结果：在遮挡—重现基准上，该方法显著降低物体消失率与位置漂移误差，长时程生成的一致性明显优于基线，且在训练未见过的遮挡模式上有一定泛化；将该世界模型用于下游规划时任务成功率提升，说明客体永久性是长时程世界建模的关键能力；消融显示记忆槽与课程学习分别对持续性表征和长遮挡鲁棒性贡献最大。

**主要痛点**
- 视频世界模型缺乏客体永久性，长时程生成中物体易消失、漂移。
- LLM 智能体的世界模型逐步预测完整状态代价高、误差累积、泛化差。
- 联合音视频生成中两模态相互干扰，同步与语义对齐难优化。
- 文生视频提示词缺乏电影语言，通用改写提升有限。

**方法趋势**
- 用遮挡—重现监督与记忆槽显式训练世界模型的持续性表征。
- 把世界建模重构为潜状态上的局部可逆编辑算子，由 LLM 驱动。
- 解耦音视频扩散分支并以锚定注意力加 GRPO 做奖励优化。
- 用多模态大模型生成结构化电影语言提示并对齐视频模型偏好。

**结果信号**
- 客体永久性训练降低物体消失率与位置误差，提升下游规划成功率。
- 编辑式世界模型减少 rollout 计算量并提升长程 agent 任务成功率。
- AV-GRPO 在音视频同步与 FVD/FAD 上超过联合扩散基线且样本效率更高。
- WanPE 在多个 T2V 基座上提升美学与运动评分及人工偏好胜率。

1. [Agent-Editing World Model: Rethinking World Modeling for LLM Agents](https://huggingface.co/papers/2609.28416)
   - 分类：World Model / LLM Agent
   - 研究价值：值得精读

   - 痛点：现有 LLM 智能体的世界模型大多沿用「预测下一观测」的强化学习范式，把环境动力学当作不可干预的黑箱，智能体只能被动适应而无法在执行中修正错误假设。这种预测式建模还存在两个具体痛点：一是像素级或 token 级预测开销大，且与语言推理所处的语义空间不匹配；二是长程任务中预测误差逐步累积，单步预测准确并不保证全局规划正确。
   - 方法：论文把世界模型重新定义为智能体可读、可写的显式状态结构，智能体在每一步推理中直接插入、删除或改写世界状态条目，并以编辑后的状态作为后续规划的条件，从而让「修正假设」成为一等操作。训练上结合语言模型自回归生成与状态编辑监督信号，使模型学会判断何时应修改世界表征、何时只需继续预测，而非无差别地预测下一 token。
   - 结果：在长程规划与反事实推理基准上，该编辑式世界模型相比传统预测式世界模型获得更高的任务成功率，并明显缓解误差累积导致的性能衰减，说明「世界模型作为可干预记忆」比「世界模型作为预测器」更适配 LLM 智能体。消融实验显示可编辑状态机制是主要增益来源，为后续在真实工具环境中扩展该范式提供了依据。

2. [AgentKernel: The Trust-Native Agentic Operating System](https://huggingface.co/papers/2609.29647)
   - 分类：Agent OS / Trust & Security
   - 研究价值：值得精读
   - 关联：与我们 Agent 基础设施与安全方向高度相关，涉及智能体权限隔离、工具调用审计与多智能体身份边界，可作为我们运行时层设计的参考架构。
   - 痛点：智能体运行时需要直接调用工具、读写文件与访问网络，但现有框架普遍把权限与信任当作事后补丁，缺少操作系统级的隔离、审计与能力约束机制。多智能体协作时身份与授权边界模糊，一次提示注入或越权工具调用就可能造成不可逆的副作用，而问题发生后往往缺乏可回溯的执行凭证来定位责任环节。
   - 方法：论文提出以「信任」为原生抽象的智能体操作系统 AgentKernel，将每个智能体抽象为受能力令牌约束的进程，由内核态调度器统一管理工具调用、资源访问与跨智能体消息。系统通过能力（capability）机制、可验证执行轨迹与集中式策略引擎，在系统层强制最小权限，并支持审计、限流与回滚等运行时治理操作，把安全语义下沉到调度路径而非留给应用层自行处理。
   - 结果：在典型智能体工作负载下，AgentKernel 能在维持任务完成率的同时拦截越权工具调用与提示注入攻击，并为每次动作生成可追溯的执行凭证；系统引入的额外开销相对轻量，未对正常任务吞吐造成实质影响。结果支持「把信任与权限下沉到操作系统层」是构建可靠智能体基础设施的可行路径。

**主要痛点**
- LLM 智能体的世界模型多为被动预测式建模，与语言推理空间不匹配且长程误差累积严重。
- 智能体运行时缺少系统级信任与权限抽象，工具调用越权与提示注入风险难以拦截和审计。

**方法趋势**
