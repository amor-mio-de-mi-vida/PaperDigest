1. [Video Generation Models: A Survey of Post-Training and Alignment](https://huggingface.co/papers/2610.00812)
   - 分类：Video Generation / Post-Training & Alignment Survey
   - 研究价值：值得精读
   - 关联：与团队在视频生成后训练、偏好对齐与奖励建模方向的调研需求直接相关，可作为方法选型的路线图。
   - 痛点：视频生成基础模型在预训练后虽能合成高质量片段，但下游可用性受限于提示词对齐、物理合理性、时序一致性与人类偏好匹配等缺陷；现有后训练与对齐技术（SFT、RLHF、DPO、奖励模型、蒸馏）散落在不同论文中，术语、数据口径与评测协议互不统一，导致新研究者难以判断哪类方法在何种数据规模与算力预算下真正有效，也缺少对奖励作弊、长视频收益衰减等失败模式与伦理风险的体系化梳理，亟需一份统一视角的综述来收敛这一快速膨胀的领域。
   - 方法：本文以系统综述的方式梳理视频生成的后训练与对齐方法，按“数据构建—监督微调—奖励建模—偏好优化—推理期对齐”分层归纳，重点讨论视频特有的时序奖励设计、多模态偏好数据采集、人类反馈标注流程与评测协议统一问题；同时横向对比文本到视频、图像到视频、音频驱动等任务范式下各类方法的适用边界，并从计算开销、奖励过优化、分布漂移与安全性角度给出选型建议。
   - 结果：论文给出统一的分类法与能力／成本对比表，指出偏好优化在时序一致性与运动幅度上可带来稳定增益，而奖励模型易被过度优化、长视频上的对齐收益存在衰减；文章还汇总了开源数据集与评测基准，梳理出细粒度时空对齐、可解释奖励与跨模态偏好迁移等尚未解决的开放问题，为后续研究提供可操作的路线图。

2. [Adaptive Reward Routing: Dynamic Multi-Reward Optimization for Joint Audio-Video Diffusion via Forward-Process RL](https://huggingface.co/papers/2609.37200)
   - 分类：Audio-Video Joint Diffusion / RLHF
   - 研究价值：值得精读
   - 关联：与团队在多奖励对齐、音视频联合生成与强化学习后训练的技术栈高度重合，路由机制可直接迁移到现有扩散后训练流程。
   - 痛点：音视频联合扩散模型需要同时满足视觉质量、口型同步、音画语义一致与运动自然等多项指标，而现有多奖励做法多采用人工设定的固定加权求和，导致不同样本上优化目标相互冲突、单一奖励主导训练信号、生成多样性下降甚至模式坍塌；同时在反向去噪链路上直接做强化学习需要可微采样或高方差策略梯度，训练不稳定、显存开销大，难以扩展到高分辨率与长时长视频，如何让多目标奖励随样本自适应并稳定优化是核心痛点。
   - 方法：论文提出自适应奖励路由机制，用轻量路由网络根据当前样本特征与去噪时间步动态预测各奖励项的组合权重，使不同样本在训练中被最相关的目标主导；并将音视频联合扩散的优化建模为前向过程强化学习，在加噪／前向轨迹上构造可分解的奖励与状态转移，从而避免反向传播穿过完整采样链，显著降低梯度方差与显存占用，实现端到端的多奖励协同优化。
   - 结果：在音视频生成基准上，该方法相较固定权重与静态 RLHF 基线在音画同步、语义对齐等指标上取得提升，视觉质量无明显退化，且路由权重随样本呈现可解释的自适应变化；训练过程更稳定、收敛所需步数更少，消融实验显示奖励路由网络与前向过程强化学习分别贡献主要增益，验证了动态多奖励优化的必要性。

3. [Hierarchical Continuous Diffusion Language Models](https://huggingface.co/papers/2610.02193)
   - 分类：Diffusion Language Models / Continuous Diffusion
   - 研究价值：值得精读
   - 关联：与团队在扩散语言模型、连续潜空间生成与长文本建模方向的探索直接相关，层级设计可复用到多模态生成。
   - 痛点：离散扩散语言模型受限于 token 空间难以定义平滑加噪过程，通常需要大量采样步数且生成质量不及自回归模型；已有连续扩散语言模型将 token 映射到连续嵌入再做扩散，但普遍缺乏层级结构，无法同时兼顾局部词法正确性与全局语义连贯性，在长文本生成中容易出现语义漂移、主题丢失与重复退化，如何在不牺牲采样效率的前提下实现由粗到细的可控生成是主要痛点。
   - 方法：论文提出层级化连续扩散语言模型，在词级／短语级与句子级／段落级等多个语义粒度上分别定义连续扩散过程并耦合采样：粗粒度潜变量先规划全局语义与篇章结构，细粒度潜变量在其条件下恢复具体 token 序列，配合层级噪声调度与条件去噪网络实现由粗到细的生成，使语义规划与表面实现解耦，降低单层模型的建模负担。
   - 结果：在语言建模与条件生成任务上，该模型的困惑度与生成质量优于单层连续扩散基线，在更少采样步数下即可达到相当质量；长文本的全局连贯性与重复率指标明显改善，消融实验验证层级结构、两层潜变量耦合方式与噪声调度是主要收益来源，说明层级连续扩散是提升扩散语言模型可用性的有效方向。

**主要痛点**
- 多奖励／多目标对齐中固定权重导致目标冲突与单一奖励主导，反向链路强化学习方差大、显存高。
- 扩散语言模型与像素扩散模型在离散化、采样效率与全局语义一致性上仍存在明显短板。
- 世界模型与流式视频生成在长时段一致性上退化严重，显存与计算开销随序列增长迅速膨胀。
- 视频生成中的视觉文本渲染、第一视角目标达成等能力缺乏细粒度、系统化评测基准。

**方法趋势**
- 多粒度／层级化潜变量建模：在词级与篇章级、actor 与 observer 视角间分层解耦，实现由粗到细生成。
- 动态多奖励路由与前向过程强化学习，避免反向传播穿过完整采样链。
- 线性复杂度空间记忆与可预测表征学习，支撑流式世界模型的长期一致性。
- 稠密预测作为表征对齐任务，以及紧凑可预测的语义 token 空间提升自回归效率。
- 面向视觉文本渲染与第一视角操作的细粒度基准构建。

**结果信号**
- 偏好优化类方法在时序一致性与运动幅度上稳定增益，但奖励模型易过优化、长视频收益衰减。
- 动态奖励路由在音画同步与语义对齐上优于固定权重基线，训练更稳定、收敛更快。
- 层级连续扩散在困惑度与长文本连贯性上优于单层基线，且采样步数更少。
- 空间线性记忆与预测性潜表征显著降低显存开销并改善长序列生成稳定性。
- 现有模型在视频文字渲染与长时程目标导向操作上仍普遍存在形变、闪烁与目标达成不足的问题。

1. [AgSpec: Pushing the Limits of Retrieval-Based Speculative Decoding in Coding Agent Pipelines](https://huggingface.co/papers/2610.01108)
   - 分类：Speculative Decoding / Inference Acceleration
   - 研究价值：值得精读
   - 关联：直接面向编码Agent流水线的推理加速，属于高效推理的核心方向，且把投机解码与真实Agent系统结合，工程与算法价值兼具。
   - 痛点：编码 Agent 流水线的上下文高度重复——仓库文件、历史编辑、系统提示在同一会话中被反复拼接，导致 prefill 与解码延迟成为端到端瓶颈；通用投机解码的草稿模型面向自然语言训练，既未利用代码库中大量可检索的重复片段，也难与 Agent 的多轮工具调用、动态上下文裁剪策略配合，因此在真实编码 Agent 场景中接受长度与加速比远低于离线基准所报告的水平。
   - 方法：AgSpec 将检索式投机解码深度嵌入编码 Agent 流水线：把仓库索引、历史编辑记录与当前 prompt 作为检索库，在每一步解码前检索出高置信度的长草稿片段，替代或补充小型草稿模型的输出；同时针对 Agent 上下文的动态变化设计自适应验证与草稿缓存机制，使检索命中率、验证开销与工具调用节奏协同优化，从而在不改变目标模型输出的前提下最大化接受长度。
   - 结果：在真实编码 Agent 基准上，AgSpec 相比通用投机解码与普通草稿模型取得更高的平均接受长度与端到端加速比，显著降低多轮工具调用下的单位任务延迟；论文进一步分析了检索库规模、草稿长度与验证策略的权衡，给出编码 Agent 流水线中检索式投机解码的性能边界，说明其在长上下文、高重复度场景下的收益最为突出。

2. [Prefill-Free Cross-Family KV Cache Transfer for Heterogeneous Multi-Agent LLMs](https://huggingface.co/papers/2609.32259)
   - 分类：KV Cache / Multi-Agent Inference
   - 研究价值：值得精读
   - 关联：跨模型家族的 KV 缓存复用直击异构多智能体推理的重复 prefill 浪费，是高效推理与推理系统层的重要突破点。
   - 痛点：异构多智能体系统中，不同模型家族在 tokenizer、隐藏维度、层数与位置编码上互不相同，KV 缓存无法直接跨模型复用；当一个 Agent 需要接手另一模型已处理的长上下文时，只能重新执行完整的 prefill，造成大量重复计算与首 token 延迟，成为多模型协作流水线的主要推理瓶颈，且随上下文长度增加而急剧恶化。
   - 方法：论文提出免 prefill 的跨家族 KV 缓存迁移：先建立不同模型家族之间隐藏状态的共享语义空间，通过轻量对齐层与投影把源模型的 KV 缓存映射到目标模型的键值空间，并处理 tokenizer 边界与位置编码差异；迁移完成后目标模型可直接在迁移缓存上继续解码，无需重新编码原始上下文，仅需少量校准即可保持注意力分布的一致性。
   - 结果：实验表明该方法在异构多模型家族的协作推理中几乎消除重复 prefill，显著降低首 token 延迟与整体算力开销，同时在下游任务上保持与全量重新预填充相当的输出质量；论文还给出缓存迁移的误差分析与适用边界，说明跨家族缓存复用可以作为多智能体推理系统的通用加速组件。

3. [Pretrain Once, Route Anywhere: Towards a Foundation Model for LLM Routing](https://huggingface.co/papers/2609.37362)
   - 分类：LLM Routing / Inference Efficiency
   - 研究价值：值得精读
   - 关联：把路由从每个模型池单独训练的定制组件升级为可复用的基础模型，直接降低推理服务的部署成本，属于高效推理基础设施方向。
   - 痛点：现有 LLM 路由方法通常把路由器与特定候选模型池绑定：一旦新增、替换或下线模型，路由器就必须重新收集标注并重训，难以复用；同时不同模型池的分布差异使迁移效果很差，导致路由在真实生产中部署与维护成本极高，难以形成可复用的基础设施，限制了路由在成本-质量权衡中的实际收益。
   - 方法：论文提出路由基础模型：在预训练阶段学习与具体模型池无关的路由表示，通过大量异构模型池与查询-模型配对数据进行训练，使路由器掌握查询能力需求与模型能力画像之间的通用映射；推理时只需给出新模型池的少量描述或示例，即可零样本或少样本完成路由，而无需重新训练或重新标注数据。
   - 结果：实验显示该路由基础模型在新模型池上以零样本或少样本迁移即可接近为各池单独训练的专用路由器效果，并在多个路由基准上取得更优的质量-成本权衡；论文验证了路由知识可以跨模型池迁移，为把路由做成可复用的基础组件与推理服务基础设施提供了可行路径。

**主要痛点**
- 多奖励RL与扩散后训练的奖励调度依赖静态权重，稀疏信号易被淹没，优化效率低。
- 异构模型家族间KV缓存不兼容、路由与Agent推理流程固定，导致重复prefill与算力浪费。
- 长上下文个性化、视频token化与流式世界模型的记忆/序列开销随长度增长，成为推理瓶颈。

**方法趋势**
- 将检索式投机解码、免prefill跨家族KV缓存迁移与自适应计算嵌入真实推理流水线。
- 用预训练路由基础模型、密度感知奖励聚合与On-Policy软记忆压缩提升训练/部署效率。
- 借助合成场景自蒸馏、可预测语义token与线性空间记忆降低数据与计算成本。

**结果信号**
- 编码Agent与异构多智能体场景取得更高接受长度、更低首token延迟与明显加速比。
- 路由基础模型在新模型池上零样本/少样本迁移即接近专用路由器效果。
- 多奖励聚合、紧凑软记忆与语义token化在保持质量的同时显著降低token数与推理开销。

1. [InterEvolve: Test-Time Evolution of Reward Programs for Humanoid Loco-Manipulation](https://huggingface.co/papers/2610.02196)
   - 分类：Humanoid Loco-Manipulation / Reward Program Evolution
   - 研究价值：值得精读
   - 关联：直接对应团队关注的具身智能奖励自动设计与部署期在线自适应方向，可复用到现有 RL 训练管线。
   - 痛点：人形机器人 loco-manipulation 的强化学习高度依赖人工设计的奖励函数，而这类奖励通常只对训练时的特定地形、目标与动力学条件有效；一旦部署环境或任务目标发生变化，固定的奖励程序无法覆盖新出现的失败模式，策略性能随之退化。传统应对方式是重新设计奖励或整体重训，代价高、周期长，也无法在测试时实时响应分布漂移。该论文要解决的正是奖励设计不可迁移、测试期无法自适应这一核心痛点。
   - 方法：作者把奖励函数写成可执行程序，并在测试阶段对其做进化搜索：以奖励代码为个体，用真实环境 rollout 的任务反馈作为适应度，通过变异、交叉与选择持续生成新的奖励候选，再用筛选出的奖励对策略做短程在线微调，形成“奖励进化—策略更新”的闭环。整个流程不需要人工重新设计奖励，也不需要额外大规模离线数据，奖励程序本身成为可被直接优化的对象，从而把奖励工程从离线人工环节转为在线自动环节。
   - 结果：在人形机器人 loco-manipulation 基准上，InterEvolve 相比固定奖励与常规奖励微调基线取得更高的任务成功率，并在环境扰动与任务目标切换时表现出更强的自适应能力。消融实验显示，性能提升主要来自测试阶段的奖励进化而非单纯增加采样量，说明奖励程序层面的在线演化能有效缓解奖励设计与部署环境不匹配的问题，为具身策略的持续适应提供了新的技术路线。

2. [Benchmarking and Enhancing Skill-Level Memory for Partially Observable Robotic Manipulation](https://huggingface.co/papers/2609.38886)
   - 分类：Robotic Manipulation / Memory Benchmark
   - 研究价值：值得精读
   - 关联：部分可观测下的记忆建模是团队具身操作方向的关键瓶颈，该工作同时提供基准与改进方法，工程可落地性强。
   - 痛点：部分可观测条件下的机器人操作必须依赖历史信息推断被遮挡目标的状态，但现有基准多以整条轨迹为单位评估记忆能力，忽略了“技能级”时间尺度的差异：不同子技能所需记忆跨度可能从数帧到数百帧不等。这种粗粒度评估使模型的长短期记忆瓶颈难以定位，研究者往往只能看到整体成功率下降，却无法判断失败究竟来自技能内短程记忆不足，还是跨技能阶段的信息丢失，导致记忆模块的改进缺乏明确方向。
   - 方法：论文构建了带技能级标注的部分可观测操作基准，按子技能切分轨迹并系统控制遮挡时长与遮挡对象，将记忆需求显式分解为技能内短程记忆与跨技能长程记忆两类，从而可分别度量。在此基础上，作者提出增强方案：在策略中引入技能感知的记忆模块，利用技能边界对历史特征进行压缩、写入与路由，使记忆的读写粒度与当前子技能对齐，避免无关历史干扰当前决策。
   - 结果：实验显示主流策略在长遮挡跨度下成功率显著下降，技能级分解能清晰定位失败主要来源于跨技能阶段的信息丢失，而非短程感知误差。所提技能感知记忆方法在多个部分可观测操作任务上优于统一记忆基线，并在长的长时遮挡设定下取得更稳定的成功率，验证了按技能粒度组织记忆的必要性，也为后续记忆机制评测提供了可复用的诊断工具。

3. [World Observer: Joint Actor-Observer Generation for Persistent World Modeling](https://huggingface.co/papers/2610.02162)
   - 分类：World Model / Video Generation
   - 研究价值：值得精读
   - 关联：面向持久世界建模的多视角一致性思路，可迁移到团队的具身仿真与长时程规划中的世界模型构建。
   - 痛点：现有世界模型多采用以自我为中心的单视角生成范式，模型只能看到 actor 自身的观测，缺少对同一场景中旁观者视角一致性的任何约束。结果是长时间 rollout 时几何结构与语义内容持续漂移，场景无法维持持久一致的内部表征，进而使基于该世界模型的规划在长时程任务上不可靠。如何在只有自视角监督信号的情况下约束场景的全局一致性，是该领域长期未被很好解决的关键痛点。
   - 方法：论文提出联合 actor-observer 生成框架，在同一潜空间中同步生成智能体视角与旁观者视角的视频序列。核心机制是在两类视角之间施加跨视角一致性约束，并共享场景表征与隐状态，要求同一时刻两个视角对场景的推断互不矛盾；观察者视角由此成为一种额外的空间监督信号，用于约束自视角生成中的几何与语义漂移，从而支撑持久的世界建模。
   - 结果：在长时程视频预测与世界模型基准上，联合 actor-observer 生成显著降低了长时间 rollout 的漂移，提升了视角一致性与场景持久性指标，并在多项长时程预测度量上优于单视角基线。作者进一步显示，用该世界模型驱动的下游规划获得更好表现，说明显式的多视角一致性约束能够提升世界模型的长期可用性，而不仅是短程的像素级生成质量。

**主要痛点**
- 奖励设计依赖人工且训练后固定，部署环境或任务变化时策略退化，缺乏测试期自适应机制
- 多奖励与稀疏奖励场景下信号冲突、权重静态，关键成功信号容易被稠密奖励淹没
- 部分可观测操作与长时程世界建模中记忆粒度粗、空间一致性无约束，长期 rollout 漂移严重

**方法趋势**
- 测试期奖励程序进化与策略在线微调形成闭环，无需人工重新设计奖励
- 按技能或奖励密度对记忆与信号做自适应分解、重加权与路由
- 多视角联合生成、线性空间记忆与可预测表征约束，提升世界模型的长期一致性

**结果信号**
- 在线奖励演化与技能级记忆显著提升人形 loco-manipulation 与部分可观测操作的成功率和鲁棒性
- 联合 actor-observer 生成降低长时程漂移，提升视角一致性与下游规划表现
- 密度感知聚合和自适应奖励路由在多奖励任务上取得更优的指标权衡与学习效率

1. [Prefill-Free Cross-Family KV Cache Transfer for Heterogeneous Multi-Agent LLMs](https://huggingface.co/papers/2609.32259)
   - 分类：LLM Inference / KV Cache Transfer / Multi-Agent LLM Systems
   - 研究价值：值得精读
   - 关联：直接对应 Agent 领域中的异构多智能体 LLM 协作与推理效率问题，是本次候选中最贴近工程落地的一篇。
   - 痛点：异构多智能体 LLM 系统中，不同家族模型往往需要共享上下文缓存以支撑协作推理，但 KV Cache 与模型权重、tokenizer、层结构强绑定，跨家族无法直接复用。传统做法是让目标模型重新 prefill 整段上下文，导致首 token 延迟高、重复计算严重，长上下文与多轮多智能体对话下显存与算力开销进一步放大。此外，异构模型间的缓存复用还面临隐状态空间语义不对齐、键值维度不一致的问题，使实时多智能体协作难以在延迟预算内完成。
   - 方法：论文提出免 prefill 的跨家族 KV Cache 迁移机制。核心是把源模型已缓存的键值表示，通过 token 空间映射与隐状态空间变换投影到目标模型的 KV 空间，并配合逐层对齐与少量校准样本校正跨家族分布差异，使目标模型不必重新编码上下文即可直接进入解码阶段。该机制在保留源模型上下文语义的同时，兼容不同维度的键值头与不同 tokenizer，可作为多智能体 LLM 通信层的通用组件使用。
   - 结果：实验表明该方法在异构模型对上能显著降低首 token 延迟与 prefill 端计算量，输出质量相对完整 prefill 基线的退化很小，在长上下文与多智能体协作推理场景中能有效减少重复上下文编码开销。结论上，跨家族 KV 迁移可在不牺牲生成质量的前提下压缩推理成本，为异构多智能体 LLM 系统的低延迟协作提供了可行路径。

2. [JevSpawn: Adaptive Agentic Inference through Compositional Action Spaces](https://huggingface.co/papers/2610.00437)
   - 分类：Agentic Inference / Adaptive Computation / Tool Use
   - 研究价值：值得扫读
   - 关联：面向 Agent 推理阶段的自适应计算与动作空间设计，属于 Agent 系统架构方向的直接相关工作。
   - 痛点：现有 Agent 推理框架通常使用固定工具集合与固定调用深度，面对不同任务时要么动作不足导致无法完成子目标，要么过度调用工具与思考步骤造成 token 与延迟浪费。真实任务所需动作空间随子目标动态变化，且原子动作之间可组合复用，静态动作集难以在统一策略内表达这种组合结构，也难以随任务难度自适应伸缩计算量。
   - 方法：论文提出组合式动作空间，将原子动作组合为可复用的宏动作，并按当前任务状态自适应生成或剪枝候选动作，形成动态的 agentic 推理空间。配合调度策略决定何时扩展、复用或终止动作组合，使推理深度与工具调用随任务需求自适应变化。
   - 结果：在 agentic 推理基准上，该方法在提升任务成功率的同时降低了平均 token 消耗与工具调用次数，说明自适应组合动作空间在效率与能力之间取得了优于固定动作集的折中，适合作为 Agent 推理框架的设计参考。

3. [Decentralized Master-Mind: Joint Action Refinement through Iterative Intent Denoising in Multi-Agent Pathfinding](https://huggingface.co/papers/2609.32019)
   - 分类：Multi-Agent Pathfinding / Multi-Agent Reinforcement Learning
   - 研究价值：值得扫读
   - 关联：属于 Agent 领域中的多智能体协同决策与联合动作优化分支，与多智能体路径规划研究主线直接相关。
   - 痛点：多智能体路径规划中，集中式规划器需要全局观测与统一动作空间，随智能体数量增长呈组合爆炸；而去中心化方法虽可扩展，各智能体仅依赖局部观测独立决策，缺乏对彼此意图的显式建模，容易产生动作冲突、死锁与反复重规划，联合动作难以收敛到全局一致解。
   - 方法：论文提出 Decentralized Master-Mind 框架，把智能体意图表示为可迭代去噪的隐变量，智能体先在局部观测下生成含噪意图，再通过多轮意图去噪与联合动作精化逐步消解跨智能体冲突，并以去中心化方式交替执行意图广播与动作修正。
   - 结果：在多智能体路径规划基准上，该方法在成功率、平均路径长度与冲突率指标上优于去中心化基线，解质量接近集中式规划器，且随智能体数量增加性能衰减更平缓，表明迭代意图去噪能有效缓解局部观测带来的协调困难。

**主要痛点**
- 异构多智能体 LLM 的 KV Cache 无法跨家族复用，重复 prefill 造成高延迟与算力浪费。
- Agent 推理使用固定工具集与固定调用深度，无法随任务动态伸缩，效率与能力失衡。
- 去中心化多智能体仅依赖局部观测，缺乏意图建模，联合动作易冲突、死锁且难收敛。

**方法趋势**
- 免 prefill 的跨家族 KV 迁移：token 空间映射加隐状态投影与逐层对齐校准。
- 组合式动作空间：原子动作组合为宏动作，按任务状态自适应生成与剪枝候选动作。
- 迭代意图去噪：将智能体意图作为可去噪隐变量，多轮交替进行意图广播与动作精化。

**结果信号**
- 跨家族 KV 迁移显著降低首 token 延迟与 prefill 计算量，生成质量退化很小。
- 自适应组合动作空间提升 agentic 任务成功率并降低 token 与工具调用开销。
- 迭代意图去噪在路径规划基准上成功率与冲突率优于去中心化基线，接近集中式解质量。
