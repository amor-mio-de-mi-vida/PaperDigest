1. [Hierarchical Continuous Diffusion Language Models](https://huggingface.co/papers/2610.02193)
   - 分类：Diffusion Language Models / Continuous Diffusion
   - 研究价值：值得精读
   - 关联：直接落在扩散/生成式AI主线上：把图像领域成熟的层级扩散思想迁移到文本，是连续扩散语言模型在结构层面的关键改造，对做扩散+语言/多模态的团队都有参考价值。
   - 痛点：现有连续扩散语言模型多把整段文本压进单一连续隐空间，用同一条噪声调度从纯噪声一次性恢复全序列，缺少词、短语、句子等层级结构，导致长文本的全局连贯性与局部语法细节难以兼顾；同时离散token与连续扩散目标之间的不匹配使采样步数偏多、解码误差逐层累积，训练与推理开销偏高，长度泛化能力受限，长文生成容易出现重复与漂移。
   - 方法：提出分层连续扩散语言模型：把生成过程拆成多个粒度层级（token级、短语/句级隐变量），高层隐变量先在连续空间完成全局语义规划，再以粗到细的条件方式指导低层去噪，形成层级化去噪链；各层通过共享/耦合去噪网络与层级间条件机制端到端训练，并设计连续去噪目标与离散token解码之间的对齐机制，使层级隐变量可解释、采样步数可灵活调整。
   - 结果：在标准语言建模与条件生成基准上，该模型在同等或更少采样步数下取得更低困惑度与更高生成质量，长文本的连贯性明显改善，重复与语义漂移问题得到缓解；层级设计带来可控的生成粒度与更好的长度泛化，推理效率相比单层连续扩散基线有提升，论文还给出层级数、噪声调度与去噪步数的消融分析，验证高层规划对长文质量的关键作用。

2. [World Observer: Joint Actor-Observer Generation for Persistent World Modeling](https://huggingface.co/papers/2610.02162)
   - 分类：World Models / Video Generation
   - 研究价值：值得精读
   - 关联：世界模型是扩散/生成式AI当前最热的方向之一，该工作用联合生成方式正面攻击长时程一致性与物体持久性这两个核心痛点，对做视频生成、交互式世界模拟与具身智能的团队都高度相关。
   - 痛点：现有视频世界模型大多只以单一第一视角（actor视角）自回归预测未来帧，缺少对同一场景中观察者/全局视角一致性的建模，长时程rollout时会出现几何与外观漂移、物体持久性丢失（物体一旦离开视野就消失），遮挡与视角变化下预测容易崩塌，难以支撑需要稳定3D记忆的交互式世界模拟以及下游规划、导航等任务。
   - 方法：提出联合actor-observer生成框架：在生成动作执行者视角视频的同时预测观察者/全局视角表示，两个视角共享隐空间并受几何一致性约束；通过跨视角注意力把观察者信息回注给actor分支，并用显式的持久性记忆（对场景实体做token化跟踪与检索）维持长期一致，配合多视角联合训练目标提升对遮挡和视角变化的鲁棒性。
   - 结果：在长时程世界建模基准上，联合生成显著提升视角一致性与物体持久性指标，长时间rollout的场景漂移明显下降，生成视频在FVD等质量指标与一致性评测上优于单视角基线；模型还能在实体离开视野后依然保持其状态，支持更稳定的记忆检索与后续交互式规划，消融证明观察者分支与持久性记忆是主要增益来源。

3. [LOCI: Spatial Linear Memory for Streaming World Models](https://huggingface.co/papers/2609.40222)
   - 分类：Streaming World Models / Long-context Memory
   - 研究价值：值得精读
   - 关联：面向流式世界模型的记忆机制，与视频扩散、长上下文建模和实时生成强相关；恒定显存的线性记忆设计对工程落地价值高，属于值得精读的系统+架构型工作。
   - 痛点：流式世界模型需要在近乎无限长的视频流中保持空间记忆，但Transformer式注意力随上下文长度增长，显存与延迟迅速膨胀、无法实时；而压缩式循环状态又容易遗忘远处空间细节，导致重访同一场景时几何与纹理不一致、长时程一致性差，无法在恒定资源预算下持续生成与记忆。
   - 方法：提出空间线性记忆（Spatial Linear Memory）：用线性复杂度的状态更新替代全注意力，把历史帧按空间位置组织成可读写的记忆槽（借鉴线性注意力/状态空间模型的写法），支持按空间查询检索历史观测；结合流式分块训练与增量状态更新，使模型在恒定显存、近恒定延迟下持续生成与重建，并对远处区域保持可寻址记忆。
   - 结果：在流式视频生成与世界模型基准上，LOCI在恒定显存与近恒定延迟下达到与全注意力基线相当甚至更好的重建与预测质量，长时程一致性与重访场景的准确性提升，支持更长的流式生成而不出现明显漂移；论文通过显存、吞吐与记忆检索精度对比说明其在实时应用中的优势。

**主要痛点**
- 扩散模型正从图像/视频扩展到语言与音频，核心痛点集中在结构层级缺失、跨模态奖励冲突以及长时程一致性难以维持。
- 世界模型与流式视频生成受限于注意力随上下文膨胀与循环状态遗忘，重访场景几何纹理不一致、物体持久性丢失。
- 视频生成在视觉文本渲染、第一视角可执行性等方面缺乏系统评测，生成结果与真实可用性存在明显鸿沟。
- 连续/像素/自回归等不同生成范式的效率与表征对齐问题仍未解决，采样步数、token冗余与语义表征质量互相牵制。

**方法趋势**
- 层级化扩散与多粒度隐变量：粗到细条件去噪，用全局规划指导局部细节生成。
- 联合视角/多模态生成：actor-observer共享隐空间、跨视角注意力与实体级持久性记忆。
- 线性复杂度空间记忆：可读写记忆槽替代全注意力，在恒定显存下支持流式长上下文。
- 强化学习驱动的多奖励自适应路由，以及预测性tokenizer、密集预测表征对齐等训练目标改造。

**结果信号**
- 层级连续扩散语言模型在更少采样步数下取得更低困惑度与更好长文连贯性。
- 联合actor-observer世界模型与空间线性记忆显著降低长时程漂移，提升视角一致性与物体持久性。
- 视频生成在文字渲染、第一视角操作等方向上被新基准暴露出明显短板，为后续改进提供诊断。

### 高效训练与推理

1. [AgSpec: Pushing the Limits of Retrieval-Based Speculative Decoding in Coding Agent Pipelines](https://huggingface.co/papers/2610.01108)
   - 分类：Speculative Decoding / Efficient Inference
   - 研究价值：值得精读
   - 关联：直接面向编码智能体的高效推理，属于投机解码与推理加速的核心方向。
   - 痛点：编码智能体流水线中，LLM需要反复生成代码、执行工具调用并读取反馈，自回归解码的逐token延迟成为端到端瓶颈。现有基于检索的投机解码在通用文本上有效，但在代码场景中由于上下文长、API签名与变量名高度结构化，草稿检索命中率低、验证开销大，导致加速比远低于理论值，难以满足编码智能体对低延迟和高吞吐的严苛要求。
   - 方法：论文提出AgSpec，针对编码智能体流水线重新设计检索式投机解码。核心机制包括：从代码仓库、历史编辑和工具返回中构建动态可检索的草稿库；利用代码结构（如函数签名、变量作用域）生成高置信度草稿token；设计轻量验证与回退策略，在草稿与目标模型分布不一致时快速截断重采样；并将投机解码与智能体的多轮工具调用调度协同优化，减少无效预填充和重复计算。
   - 结果：在多个编码智能体基准（如代码修复、仓库级问答与工具调用任务）上，AgSpec相比标准自回归解码取得显著加速，端到端延迟大幅降低，吞吐提升明显；与通用投机解码基线相比，检索命中率和接受长度更高，且不损失生成代码的正确性。论文进一步消融验证了动态草稿库和结构感知草稿生成对加速的贡献，表明该方法能切实推进编码智能体流水线的低延迟部署。

2. [Prefill-Free Cross-Family KV Cache Transfer for Heterogeneous Multi-Agent LLMs](https://huggingface.co/papers/2609.32259)
   - 分类：KV Cache / Efficient Multi-Agent Inference
   - 研究价值：值得精读
   - 关联：针对多智能体推理中的KV缓存复用，是推理效率的重要优化方向。
   - 痛点：异构多智能体LLM协作中，不同模型家族（如Llama、Qwen、Mistral）的KV缓存格式和表示空间不兼容，新智能体加入或切换时往往需要对其完整上下文重新执行预填充。这一重复预填充在长上下文、多轮协作场景下带来巨大的计算冗余和首token延迟，严重制约多智能体系统的推理效率与可扩展性。
   - 方法：论文提出免预填充的跨家族KV缓存传输机制。核心思路是学习一个轻量对齐模块，将源模型家族的KV缓存映射到目标模型家族的表示空间，使目标模型无需重新编码上下文即可直接复用缓存；同时设计缓存兼容性校验与部分重计算回退策略，保证传输后生成质量。该方法支持异构模型间的即插即用协作，并与现有推理引擎集成。
   - 结果：在多种异构LLM组合（如Llama→Qwen、Mistral→Llama）和长上下文多智能体任务上，该方法消除了重复预填充，端到端延迟相比朴素重预填充大幅下降，吞吐显著提升，同时生成质量与全量预填充基线几乎持平。消融实验表明对齐模块和回退策略对保持质量至关重要，验证了跨家族缓存复用的可行性。

3. [SemanTok: Predictable Semantic Tokens for Efficient Autoregressive Video Generation](https://huggingface.co/papers/2610.00686)
   - 分类：Video Generation / Efficient Autoregressive Generation
   - 研究价值：值得精读
   - 关联：面向视频生成的高效自回归推理，属于生成效率优化。
   - 痛点：自回归视频生成通常将视频离散为大量细粒度视觉token，序列极长，逐token预测导致推理速度慢、计算开销大；同时视觉token冗余度高，相邻帧间大量信息重复，模型难以在有限步数内生成时序连贯的视频。如何在保持生成质量的同时显著缩短自回归序列，是视频生成效率的核心痛点。
   - 方法：论文提出SemanTok，用可预测的语义token替代细粒度视觉token进行自回归视频生成。方法首先通过语义tokenizer将视频压缩为高层语义单元，使token更具可预测性和时序一致性；然后训练自回归模型在语义token空间预测，减少序列长度和采样步数；最后通过语义解码器重建高质量视频。该设计将建模难度从像素级转移到语义级。
   - 结果：在标准视频生成基准上，SemanTok在FVD、IS等指标上与细粒度token自回归基线相当或更优，同时推理速度显著提升，自回归步数明显减少，验证了语义token化在效率与质量之间的良好权衡。消融实验表明语义tokenizer的压缩率和预测性对最终性能影响显著。

**主要痛点**
- LLM推理延迟与吞吐成为编码智能体、多智能体协作等场景的瓶颈，投机解码与KV缓存复用是重点方向。
- 长上下文与流式视频理解中，记忆和缓存的线性增长导致推理开销高，需要紧凑记忆与线性复杂度结构。
- 多奖励强化学习训练中稀疏奖励和奖励冲突降低样本效率，动态奖励聚合与路由可提升训练效率。
- 视频生成自回归序列过长，细粒度视觉token冗余高，语义token化有望兼顾质量与效率。

**方法趋势**
- 检索式投机解码、跨家族KV缓存对齐传输、免预填充缓存复用。
- 语义tokenizer与可预测语义token自回归、空间线性记忆、紧凑软记忆与在线策略优化。
- 密度感知奖励聚合、自适应奖励路由、前向过程强化学习。
- 路由基础模型、偏好蒸馏缩放、轻量决策模型替代LLM。

**结果信号**
- AgSpec在编码智能体流水线取得显著加速；跨家族KV传输消除重复预填充，大幅降低多智能体延迟。
- SemanTok在视频生成基准上保持质量同时提升推理速度；LOCI以线性记忆实现高效流式世界模型。
- 密度感知奖励聚合与自适应奖励路由提升多奖励RL样本效率和最终回报。
- 偏好蒸馏缩放发现小模型可生成更优拒绝样本，路由基础模型降低推理成本。

1. [InterEvolve: Test-Time Evolution of Reward Programs for Humanoid Loco-Manipulation](https://huggingface.co/papers/2610.02196)
   - 分类：Embodied RL / Reward Design / Humanoid Loco-Manipulation
   - 研究价值：值得精读
   - 关联：直接对应我们关注的具身强化学习与奖励工程设计，尤其是人形机器人在长尾场景下的部署自适应，可作为奖励自动演化方向的核心参考。
   - 痛点：人形机器人 loco-manipulation 的奖励函数高度依赖专家手工迭代，而不同地形、物体与步态阶段对奖励项的偏好差异极大；一旦部署到分布外场景，固定奖励程序无法自适应，常出现仿真表现良好、真机因奖励错配而退化的问题。现有 RL 微调或提示搜索方案又需要额外奖励标注或大量在线交互，代价高昂。因此，如何在不重写奖励的前提下让奖励随场景在线自适应，是长尾部署的关键瓶颈。
   - 方法：该工作把奖励函数表示为可执行程序，并在测试时闭环演化：先用少量真机轨迹构造自监督评价信号（任务进度、能量代价、接触一致性等），再由 LLM 对候选奖励程序做变异与交叉，配合短程 RL 快速验证与筛选，形成“评估—演化—微调”循环。整个过程不需要人工改写奖励，也不需要额外奖励标注，奖励程序可随新场景持续迭代。
   - 结果：在 humanoid loco-manipulation 基准与真机实验中，测试时演化让奖励程序随场景自适应，任务成功率相对固定奖励基线明显提升，并在未见地形与物体上表现出泛化能力，同时显著减少人工调奖励的迭代次数。消融表明自监督评价信号与短程验证是主要增益来源，去掉任一项性能明显回落，说明该范式可让奖励像策略一样在部署阶段被持续优化。

2. [Benchmarking and Enhancing Skill-Level Memory for Partially Observable Robotic Manipulation](https://huggingface.co/papers/2609.38886)
   - 分类：Robot Manipulation / Memory / Benchmark
   - 研究价值：值得精读
   - 关联：契合我们关于部分可观测操作与长时程记忆的研究线，其技能级评测协议可直接用于诊断现有 VLA 策略的记忆失效点。
   - 痛点：部分可观测下的机器人操作必须依赖记忆，但现有基准与策略大多把历史当作一个整体隐状态处理，无法区分“哪个技能阶段需要记住什么”，导致长程多阶段任务中关键状态（物体是否被移动、容器是否已打开）被稀释，策略在重访与回溯场景中频繁失败。更关键的是，缺少细粒度评测协议来判断记忆失败究竟发生在技能级还是全局级，使改进缺乏明确靶点。
   - 方法：作者提出技能级记忆基准：把长程任务分解为若干技能，在每个技能边界人为设置可观测性遮蔽，并注入需要跨技能回溯的查询来精确探测记忆能力。在此基础上提出技能级记忆增强方法，用技能分段读写记忆槽（技能摘要加关键帧检索），并在策略训练中加入记忆一致性辅助目标，使读写与技能边界对齐。
   - 结果：实验显示，现有最强 VLA 与记忆策略在跨技能回溯子集上大幅掉点，暴露了全局隐状态记忆的结构性缺陷；而技能级记忆增强方法显著提升长程成功率与记忆召回率，同时内存开销更低。消融分析表明技能分段读写与一致性损失是主要增益来源，基准与指标对记忆机制的诊断具有可复现性。

   - 研究价值：值得精读

   - 痛点：视频世界模型通常只以自我中心视角建模，一旦相机移开，被遮挡或移出视野的物体状态便随之丢失，导致长时程生成出现物体凭空消失、形变与场景结构漂移，无法支撑具身智能体所需的持久场景记忆与再观察能力。缺少一个在 actor 视角之外持续维持场景状态的机制，是长时程世界建模的核心痛点。
   - 方法：作者提出 Actor-Observer 联合生成框架：在同一场景下同时生成 actor（第一人称动作视角）与 observer（第三人称环绕观察视角）两条互相一致的视频流，通过跨视角一致性约束与共享三维潜表示对齐两支生成。observer 分支持续维持场景状态，actor 分支在需要时查询该状态即可恢复当前不可见区域，实现持久世界建模。
   - 结果：在长时程世界建模基准上，联合生成显著降低长程漂移与物体消失率，视角切换回原位置时的重建一致性明显提升，生成的整体场景结构在长时间跨度内保持稳定。结果表明 observer 监督是维持持久世界状态的有效机制，生成出的持久场景表示可为下游规划与导航提供更可靠的输入。

**主要痛点**
- 奖励工程仍高度依赖人工：人形 loco-manipulation 等任务在分布外场景下固定奖励失效，缺乏部署阶段在线自适应机制
- 部分可观测长程操作的记忆结构粗糙：全局隐状态稀释关键状态，且缺少技能级诊断协议定位失效环节
- 世界模型难以维持持久场景状态：自我中心视角在相机移开后丢失物体，长时程生成漂移与物体消失严重
- 多奖励/稀疏奖励场景下固定加权导致优化被稠密项主导，权重调参敏感且不可逐样本自适应

**方法趋势**

1. [Decentralized Master-Mind: Joint Action Refinement through Iterative Intent Denoising in Multi-Agent Pathfinding](https://huggingface.co/papers/2609.32019)
   - 分类：Multi-Agent Pathfinding
   - 研究价值：值得精读
   - 关联：直接对应 Agent 方向中的多智能体协同决策与去中心化规划，是该领域方法层面的核心创新，建议作为本日首篇精读。
   - 痛点：多智能体路径规划长期在集中式与去中心化之间两难：集中式联合求解能逼近全局最优，但计算量随智能体数量指数增长，难以扩展到大规模场景；纯去中心化方法虽可扩展，却因每个智能体只能观测局部信息，无法推断同伴的真实意图，导致联合动作彼此冲突，频繁出现死锁与拥堵，成功率在密集环境中急剧下降。如何在无中心控制器的前提下实现有效的联合动作协调，是该领域的核心痛点。
   - 方法：论文提出「去中心化主脑」框架，将每个智能体的未来意图建模为带噪隐变量，并通过迭代式的意图去噪在邻居之间反复交换与精炼这些意图表示；每一轮去噪都相当于一次隐空间中的协商，智能体据此增量修正自身的候选动作，逐步收敛到彼此一致的联合动作方案。整个过程不依赖中心控制器，也不需要显式的通信协议与全局状态，仅在局部交互下即可实现接近集中式求解的协调效果。
   - 结果：在多组标准 MAPF 基准（含密集随机地图与走廊场景）上，该方法在成功率、总路径长度与冲突次数上全面优于去中心化基线，并在中大规模智能体数量下逼近集中式求解器的解质量，同时保持线性级别的计算开销；消融实验显示迭代意图去噪的轮数与邻居信息交换是性能提升的关键因素，去除任一环节都会带来明显的成功率下降。

2. [Prefill-Free Cross-Family KV Cache Transfer for Heterogeneous Multi-Agent LLMs](https://huggingface.co/papers/2609.32259)
   - 分类：LLM Inference / KV Cache
   - 研究价值：值得精读
   - 关联：面向异构多智能体 LLM 系统的推理效率问题，横跨 Agent 编排与 LLM 系统优化，对多智能体框架的工程落地有直接价值。
   - 痛点：异构多智能体 LLM 系统中，不同智能体常由不同模型族（不同架构、头数、隐藏维度）驱动，彼此共享上下文时需重复执行 prefill 计算，导致首 token 延迟与算力开销随智能体数量与上下文长度迅速膨胀；而现有 KV Cache 复用技术大多局限于同族同架构模型，跨族缓存因注意力头语义与维度不匹配而无法直接迁移，严重制约了异构多智能体系统的推理效率。
   - 方法：论文提出免 prefill 的跨模型族 KV Cache 迁移机制：先通过少量校准样本学习源模型与目标模型之间注意力头级别的对齐映射，再用轻量投影矩阵将源 KV 缓存变换到目标模型的表示空间，并对位置编码与层间缩放差异做归一化补偿，从而使目标模型无需重新编码历史上下文即可直接续写，实现跨族缓存的即插即用复用。
   - 结果：在多种跨族模型组合（不同参数规模与注意力变体）上的实验表明，该方法可将多智能体场景下的 prefill 计算量降低大半，首 token 延迟显著下降，生成质量在通用基准与多智能体协作任务上与原模型自算缓存的差距保持在很小范围；同时对头数与隐藏维度不一致、层数不匹配等情形仍具鲁棒性。

**主要痛点**
- 多智能体协同中集中式求解不可扩展、去中心化方法又缺乏意图层面的协调机制，易陷入死锁与拥堵。
- 异构多智能体 LLM 系统共享上下文时重复执行 prefill，造成首 token 延迟与算力开销随规模迅速膨胀。
- 跨模型族的 KV 缓存因注意力头语义与维度不匹配而无法直接复用，现有技术多局限同族同架构模型。

**方法趋势**
- 将智能体意图建模为带噪隐变量，通过迭代式意图去噪在邻居间协商并精炼联合动作。
- 以去中心化、无中心控制器的局部交互替代集中式联合求解，兼顾可扩展性与解质量。
- 学习跨族注意力头对齐映射，用投影与归一化补偿实现免 prefill 的跨模型族 KV 缓存迁移。

**结果信号**
- 迭代意图去噪在密集 MAPF 场景下显著提升成功率、缩短路径并减少冲突，可扩展到更大规模智能体。
- 跨族 KV 缓存迁移大幅降低 prefill 计算量与首 token 延迟，生成质量损失很小且对架构差异鲁棒。
- 两项工作分别从决策协同层与推理系统层推进了多智能体系统的可扩展性。
