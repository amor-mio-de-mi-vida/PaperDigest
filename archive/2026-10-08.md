1. [Real-Time Joint Audio-Video Generation by Parallel Adapter Composition](https://arxiv.org/abs/2610.10343v1)
   - 分类：Audio-Video Diffusion / Real-Time Streaming Generation
   - 研究价值：值得精读
   - 关联：直接对应视频/音视频扩散的实时化与少步采样方向，其适配器并行组合思路可迁移到团队现有流式视频与少步蒸馏管线。
   - 痛点：联合音视频扩散Transformer落地实时交互生成，通常需要两项改造：块自回归注意力让帧在整段视频完成前即可输出，以及少步采样让每个块足够便宜。现有流式视频工作采用链式流水线，先蒸馏出因果学生再蒸馏成少步模型，或反序进行；每一阶段都在上一阶段权重上继续微调，后一个目标容易抹掉前一个能力，造成图像质量与时序一致性难以兼得。这一问题在块自回归与少步双重约束下更加突出，长期稳定生成因此受限。
   - 方法：作者借鉴模型合并思想，在打包的音视频骨干上并行获取两种能力：一个因果适配器针对冻结骨干训练以获得流式能力，一个现成的少步适配器提供少步能力。由于二者编辑的是不同功能轴，作者预测并验证其权重更新方向近似正交，且训练时无需任何显式正交约束，因此可以直接相加组合而互不干扰。推理时只把两个适配器相加，无需联合训练，即可得到兼具少步与流式能力的联合音视频生成模型。
   - 结果：实验显示组合模型的图像质量接近双向教师，在图像质量等多数指标上匹配或超过链式蒸馏基线，且训练上两个适配器可独立获得，避免了顺序微调带来的能力遗忘。最终流式系统在480×832分辨率、不使用量化的条件下实现约26 fps的实时联合音视频生成，并可连续生成30秒而图像质量保持稳定，说明并行适配器组合是实时交互式音视频生成的可落地方案。

2. [GRACE: Generation-aware latent compression for efficient video generation](https://arxiv.org/abs/2610.10524v1)
   - 分类：Video Diffusion Acceleration / Latent Compression
   - 研究价值：值得精读
   - 关联：视频扩散加速与latent压缩是团队核心关注点，其生成感知压缩+DiT对齐思路可与缓存加速方法互补。
   - 痛点：高压缩率视频自编码器可通过大幅减少token数来加速视频扩散Transformer，但这类自编码器很难训练：压缩比越高重建质量越差，恢复质量需要增加通道数，而这又会拖慢DiT收敛；同时压缩后的latent与DiT预训练时所见分布不一致，预训练DiT不得不从头重训或付出高昂适配成本。直接在DiT原本的自编码器上压缩虽能保持兼容，但仅以重建为目标优化仍会使latent偏离DiT已学习的分布。
   - 方法：GRACE是一个两阶段框架。第一阶段在保持与预训练DiT兼容的前提下压缩冻结的视频自编码器：保留预训练编码器给出的基础latent，额外学习一个残差latent承载强压缩下丢失的信息，并在冻结DiT的特征空间中把压缩latent与预训练latent对齐，使自编码器面向生成而非仅面向重建优化。第二阶段对DiT做轻量微调并采用非对称去噪，让基础latent先于残差latent被去噪，从而以更小的适配成本恢复生成质量。
   - 结果：在Wan2.1-I2V-14B上，GRACE将token数减少8倍，在480×832×81分辨率下把推理延迟降低11.1倍，同时在VBench上的生成质量与压缩前的预训练流水线持平。这表明，只要把压缩目标与DiT的特征空间、去噪顺序对齐，就能在不牺牲生成质量的前提下获得显著的视频扩散加速，为高压缩视频自编码器的实际可用性提供了可行路径。

3. [SGF+: Decoupling Gradient Flows for Autoregressive Video Generation](https://arxiv.org/abs/2610.10429v1)
   - 分类：Autoregressive Video Generation / Long-Horizon Generation
   - 研究价值：值得精读
   - 关联：面向自回归视频生成的长时稳定性与梯度冲突问题，与团队长视频/流式生成方向高度相关，设计原则简单且可直接复用。
   - 痛点：自回归视频生成要求当前帧既被去噪、又要把自身写成供未来预测使用的KV上下文，这两个角色通常由同一组参数承担。作者发现，这两种角色产生的梯度模式不同，且存在系统性的负对齐，使视觉质量与时序一致性难以被联合优化；结果是在长时与分块生成中容易出现质量退化与误差累积，模型难以在训练窗口之外稳定外推。该问题随rollout长度增加而加剧，成为长视频自回归生成的瓶颈。
   - 方法：SGF+把上下文写入与去噪两个角色拆成各自独立的参数，同时通过因果注意力保留二者的交互，使写入的信息仍能影响未来帧的去噪。训练上不引入任何辅助损失，两个角色仍用原始生成目标联合优化，其中上下文写入参数通过其对未来预测的贡献被监督；这种角色特定参数化使梯度冲突自然消解，也无需额外的长视频训练数据或更长的训练时长。
   - 结果：在逐帧与分块两种生成设定下，SGF+相对所评估基线同时提升了视觉质量与长时一致性，且没有使用额外视频训练数据或更长训练周期。仅用5秒长度的rollout训练，模型即可支持最长24小时的连续生成而无需长视频微调。这些结果表明，为上下文写入与去噪分别参数化，是高质量自回归视频生成与原生长时外推的有效设计原则。

**主要痛点**
- 视频扩散推理成本高：缓存复用、latent压缩、少步采样等加速手段在生成质量与可控加速比之间权衡困难。
- 自回归/长时生成中上下文写入与去噪角色冲突、误差递归累积，限制长期与实时生成稳定性。
- 流匹配/扩散策略的迭代积分与少步执行存在离散化间隙，真机部署延迟高。
- 3D、交错多模态与文本渲染等任务缺乏显式结构与位置条件，也缺乏统一评测基准。

**方法趋势**
- 角色解耦与适配器并行组合：SGF+分离上下文写入/去噪参数，音视频工作并行组合因果与少步适配器。
- 生成感知latent压缩与残差对齐：GRACE在冻结DiT特征空间对齐压缩latent。
- RL/DPO/观测校正驱动的调度与优化：MORCA缓存调度、RFPO反射流策略优化、Koopman观测校正、物理接地扩散DPO。
- 条件流匹配与self-rollout训练：Seq-Flow与城市微气候CFM生成。

**结果信号**
- GRACE在Wan2.1-I2V-14B上token降8倍、延迟降11.1倍且VBench质量持平。
- 并行适配器组合实现480×832下约26 fps实时联合音视频生成，可连续生成30秒。
- SGF+仅用5秒rollout训练即支持24小时连续生成无需长视频微调。
- RFPO单步执行保留98.5%回报，机载延迟从4.39ms降至0.08ms（54.9倍加速）。

1. [Training Parallel Speculative Draft Models by Directly Minimizing Expected Decoding Rounds](https://arxiv.org/abs/2610.10411v1)
   - 分类：Speculative Decoding / LLM Inference
   - 研究价值：值得精读
   - 关联：直接优化推测解码的全局解码轮数，是大模型推理加速与训练目标设计的重要交叉。
   - 痛点：推测解码通过低成本草稿模型并行提议多个token来加速大模型推理，但并行或半自回归草稿模型的训练存在跨轮耦合：某位置的草稿分布取决于本轮从何处开始，而轮起点又由前几轮接受的token数决定。现有训练目标多依赖块内代理，忽略这种跨轮依赖，因此不能直接优化全局解码效率，导致接受长度和端到端加速比次优。如何为并行草稿模型设计直接优化解码轮数的训练目标，是推理加速中的关键痛点。
   - 方法：论文将推测解码建模为马尔可夫奖励过程，提出期望解码轮数（EDR）目标，用状态占用度对局部拒绝代价加权，使目标精确等于期望解码轮数且无需额外超参数。作者进一步推导精确的时序差分梯度，支持从目标模型rollout中进行无偏随机优化，并给出精确离线评估器，可在共享目标rollout上成对比较草稿模型而无需实际运行推测解码。
   - 结果：在数学推理、代码生成和聊天等九个基准上，用EDR微调DSpark和DFly两种最优草稿模型，均一致提升平均接受长度并超过现有训练目标。该方法还能提供精确离线轮数评估，便于公平比较不同草稿模型。结果表明直接优化全局解码轮数优于块内代理目标，为并行推测解码训练提供了理论框架和实用算法。

2. [MORCA: Offline-to-Online Reinforcement Learning for Adaptive Cache Reuse in Video Diffusion Acceleration](https://arxiv.org/abs/2610.10457v1)
   - 分类：Video Diffusion Acceleration / Cache Reuse
   - 研究价值：值得精读
   - 关联：面向视频扩散推理加速，用强化学习调度缓存复用，直接关系高效推理与缓存决策优化。
   - 痛点：扩散Transformer视频生成因迭代去噪而推理延迟很高，缓存复用虽可利用步间冗余加速，但现有动态缓存方法通常只估计当前步复用缓存带来的步误差，忽略了该复用对最终生成视频质量的终端误差影响。步误差与终端误差并不直接对应，导致缓存决策可能明显损害最终画质；同时现有阈值方法难以按用户指定的加速目标精确控制速度，难以满足实际部署需求。
   - 方法：MORCA将缓存复用与重算调度建模为序列决策问题，用离线到在线强化学习训练策略，在给定用户加速目标下做出潜在感知的复用或重算决策。方法利用潜变量信息捕捉步误差与终端误差之间的关系，以终端误差为导向进行缓存调度，并通过离线到在线训练提升策略在真实去噪过程中的适应性与稳定性。
   - 结果：在多种视频生成模型和多个目标加速比下，MORCA在相近计算预算下取得优于现有缓存方法的生成保真度。实验表明其能按用户指定加速目标调度缓存复用，同时更好维持最终视频质量。该工作说明面向终端误差的强化学习缓存调度比步误差阈值策略更有效，为视频扩散推理加速提供了新范式。

3. [RFPO: Rectified Flow Policy Optimization for Embodied Control](https://arxiv.org/abs/2610.10453v1)
   - 分类：Embodied Control / Few-step Flow Policy
   - 研究价值：值得精读
   - 关联：面向流策略少步推理加速，直接解决具身控制中流匹配策略部署延迟高的问题。
   - 痛点：基于流匹配的机器人策略表达力强，但推理需迭代求解ODE，计算开销大；直接减少积分步数会严重降低控制性能，因为策略在全步执行下优化，并未显式约束其在粗粒度数值积分下仍可靠。这种少步离散化鸿沟使流策略难以在真实机器人上低延迟部署，尤其在高频控制与资源受限平台上，成为具身控制推理加速的核心障碍。
   - 方法：RFPO提出面向可靠少步执行的流策略优化框架：在在线学习中使用奖励感知的Reflow校正学生策略诱导的传输路径，使策略对粗粒度积分更鲁棒；同时用冻结的高斯PPO控制器在全步和中间积分预算下提供动作空间监督。部署时仍为单个流学生，仅用一步Euler积分执行，从而兼顾表达力与推理效率。
   - 结果：在Unitree Go2、Boston Dynamics Spot、Unitree H1和Unitree G1上，RFPO在一步执行下保持全步控制性能，一步回报与64步回报差距在2.4%以内。在Unitree Go2上，一步执行保留98.5%的64步奖励，板上平均推理延迟从4.39ms降至0.08ms，实现54.9倍加速，真机实验验证稳定的一步运动。

**主要痛点**
- 大模型与视频/机器人模型推理延迟高，需在缓存、少步积分和推测解码中降低计算量。
- 后训练与RL数据昂贵，探索、蒸馏和harness选择常缺乏高效目标与可靠筛选。
- 长上下文、多阶段智能体和世界模型存在历史利用效率低与上下文丢失问题。

**方法趋势**
- 面向推理加速的缓存调度、潜变量压缩、少步流策略优化与EDR训练目标。
- 面向训练效率的探索-优化解耦、同策略蒸馏、多教师偏移迁移和harness感知数据配方。
- 面向具身与科学仿真的世界模型缩放、可微仿真器和跨域预训练。

**结果信号**
- 多篇工作在视频扩散、LLM解码和机器人控制上取得数倍到数十倍延迟下降或显著成功率提升。
- 训练效率类工作在同预算下超越DAPO等基线，并改善pass@k、样本效率和迁移可靠性。
- 世界模型与代理模型研究给出可预测缩放规律、物理一致性和跨任务零样本泛化证据。

1. [Long-WAM: Scaling the Context of World-Action Models](https://arxiv.org/abs/2610.10528v1)
   - 分类：Robot World-Action Models
   - 研究价值：值得精读
   - 关联：具身智能与机器人世界模型方向的重要系统工作，直接解决长上下文实时控制的矛盾。
   - 痛点：实时机器人控制需要足够的视觉历史来推断运动与任务进度，但直接处理长历史会带来显著延迟，现有世界-动作模型往往在上下文长度与推理速度之间被迫取舍；更关键的是，单纯给模型更长的历史并不等于模型会有效利用历史，双向预训练的视频基础模型在增加上下文时甚至没有净收益。该工作系统研究了这一矛盾，并指出历史利用效率取决于视频基础模型是否以自回归方式预训练。
   - 方法：Long-WAM 先在大规模机器人视频与第一视角视频上以无动作标签方式学习因果预测，再在世界-动作适配阶段保留“历史到未来”的因果结构；系统层面采用流式观测编码、异步执行和硬件特定加速，使长上下文模型能在 RTX 5090、DGX Spark 与 Jetson AGX Thor 上部署。核心机制是把视频基础模型的自回归预训练与因果世界-动作建模对齐，让历史信息真正参与未来预测和动作生成，而不是仅作为被忽略的输入。
   - 结果：在 RoboCasa GR-1 上，上下文从0.0秒增至19.2秒使成功率从63.3%提升到78.7%，而双向预训练初始化没有净收益；机器域自回归预训练进一步提升 GR-1 与 LIBERO-Long 的峰值成功率。Long-WAM 在 LIBERO-Long、RoboTwin 2.0 与 DOMINO 上取得对比方法中最佳结果，RTX 5090 上每个动作块含未来视频隐变量预测仅需107.4 ms。真机 Unitree G1 与 YAM 上支持动态长时程操作，动态叠杯任务达到95%成功率，而 Pi0.5 与 Fast-WAM 在20次试验中均未成功。

2. [RoboJEPA: Scaling Robotic Latent World Models](https://arxiv.org/abs/2610.10515v1)
   - 分类：Robot World Models / Scaling Laws
   - 研究价值：值得精读
   - 关联：首次建立多形态机器人世界模型的扩展律，对具身基础模型规模化具有直接指导意义。
   - 痛点：潜空间世界模型能够预测未来状态并用于真实世界规划，但领域内缺乏原则性方法来估计其能力如何随模型规模、数据与计算量扩展，这导致研究进展缓慢且难以判断投入是否值得；同时，多形态机器人真实数据训练的世界模型是否具有可预测的扩展行为尚不清楚，机器人策略评估也依赖昂贵且不稳定的真机试验，缺少可替代的可靠代理指标。
   - 方法：RoboJEPA 基于联合嵌入预测架构（JEPA）构建世界模型，在覆盖12种机器人形态的大规模真实机器人数据集上训练，并通过拟合想象误差随计算量的变化来刻画扩展规律；作者进一步分析想象误差与下游规划性能的相关性，将其作为真机评估的代理指标。模型还以单张目标图像为条件进行零样本规划，直接部署到真实硬件执行长时程任务，并开源全部检查点、训练与机器人部署代码。
   - 结果：实验发现 RoboJEPA 的想象误差随计算量遵循二阶幂律，可外推预测远大于拟合尺度的模型质量，下游机器人规划性能也随计算量可预测地提升，且想象误差与其强相关。RoboJEPA 以80亿参数成为迄今最大的 JEPA 预测器模型，也是首个在真实机器人数据上建立多形态世界模型扩展律的工作。潜空间世界模型能够以零样本方式作为机器人智能体，通过单张目标图像规划解决真实硬件上的长时程任务。

3. [EmbodiedRSI: Active Continual Robot Learning Through Hypothesis-Guided Co-Evolution](https://arxiv.org/abs/2610.10498v1)
   - 分类：Embodied Continual Learning / Self-Evolving Agents

### 2. [GRACE: Generation-aware latent compression for efficient video generation](https://arxiv.org/abs/2610.10524v1)
