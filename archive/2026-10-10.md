1. [DreamTrue: Action-Faithful Robot World Model with Counterfactual Post-Training](https://huggingface.co/papers/2610.12468)
   - 分类：Robot World Model / Video Diffusion
   - 研究价值：值得精读
   - 关联：直接关联 Diffusion / 生成式AI：用视频扩散世界模型服务机器人预测与规划，并通过反事实后训练增强动作因果性。
   - 痛点：机器人世界模型常出现动作不忠实问题：模型虽能生成视觉逼真的未来帧，却忽略或错误响应给定动作，导致长时程预测与真实动力学脱节。现有视频扩散模型多以视觉逼真为目标，缺少动作条件因果监督，且反事实数据难获取，使下游策略学习与规划在仿真到现实迁移中不可靠。该痛点具体表现为同一观测下不同动作应产生不同未来，但模型倾向生成相似未来，破坏世界模型作为可交互模拟器的可信度。
   - 方法：论文提出DreamTrue动作忠实机器人世界模型，并引入反事实后训练。先在大规模机器人视频上预训练动作条件扩散/世界模型，再针对同一初始观测构造不同候选动作的反事实轨迹对，利用对比或偏好优化强化动作与未来观测之间的因果对应；后训练阶段可能联合动作重建、时序一致性与反事实排序损失，使模型学会区分动作干预带来的细粒度状态变化。该方法无需真实反事实数据，可从已有轨迹中挖掘监督信号。
   - 结果：实验表明DreamTrue在机器人操作与导航等任务上显著提升动作遵循度、长时程预测一致性和下游策略成功率，减少视觉合理但动作错误的幻觉。消融显示反事实后训练是收益关键，且在不同动作空间与视角下保持稳健，证明后训练可把通用视频世界模型转化为动作忠实的机器人模拟器。与基线相比，预测误差和动作错配率下降，规划成功率提升。

2. [WorldGuide: Goal-Directed Video World Model for Procedural Task Execution](https://huggingface.co/papers/2610.12459)
   - 分类：Video World Model / Procedural Planning
   - 研究价值：值得精读
   - 关联：直接关联 Diffusion / 生成式AI：把视频扩散世界模型用于目标导向程序性任务规划与执行。
   - 痛点：程序性任务执行需要多步骤规划与状态追踪，但现有视频世界模型多聚焦被动未来预测或短时视觉生成，缺乏显式目标导向，容易在多步任务中丢失全局目标、步骤顺序和约束，生成看似合理却不可执行的计划。语言引导的智能体因此难以把世界模型用于长时程决策与纠错。此外，误差会在步骤间累积，导致最终任务失败，现有规划器也难以与生成模型闭环耦合。
   - 方法：论文提出WorldGuide目标导向视频世界模型，把任务目标与语言指令作为全局条件，结合分层规划与视频扩散预测。模型在生成每个子目标视频时引入目标评分与搜索/重规划机制，用可达性与步骤一致性筛选候选，形成从最终目标反向分解到中间步骤的闭环；同时用时序记忆保持状态连续性，并允许执行反馈在线修正后续生成。训练时可能联合目标完成、步骤顺序与视觉预测损失。
   - 结果：在烹饪、装配等程序性任务基准上，WorldGuide提升任务完成率、步骤顺序正确率和长时程一致性，生成视频更符合最终目标，并能指导智能体或机器人执行。消融表明目标评分与闭环重规划显著减少错误累积，相比视频预测基线和纯语言规划基线在成功率与可执行性上有明显优势。该工作显示目标导向世界模型可成为程序性任务执行的有效模拟器与规划器，同时保持生成质量。

3. [LEGO: A Lifting-Free Approach for Exocentric-to-Egocentric Video Generation](https://huggingface.co/papers/2610.12442)
   - 分类：Video Generation / Cross-View Synthesis
   - 研究价值：值得精读
   - 关联：直接关联 Diffusion / 生成式AI：在视频扩散/潜空间中实现第三人称到第一人称的跨视角生成。
   - 痛点：从第三人称视频生成第一人称视频对机器人学习、具身智能和第一视角内容创作很重要，但现有方法通常依赖显式3D提升、深度估计、点云或相机标定，流程复杂且误差逐级累积，在动态场景、遮挡和未标定相机下泛化差。免提升的跨视角视频生成仍缺乏时序一致与几何合理的解决方案。这限制了大规模第一人称视频数据合成，如何在没有3D监督下保持视角转换的物理合理性是关键挑战。
   - 方法：论文提出LEGO免提升的exocentric到egocentric视频生成框架，直接在视频扩散/潜空间中学习视角转换，避免显式3D重建。其核心可能包括跨视角几何感知注意力、相机位姿条件、时序一致性模块和视角对齐损失，使模型在保持场景动态的同时把观察者从外部视角迁移到第一人称视角；训练可利用配对或非配对视频。该方法把视角转换建模为条件生成问题，简化流程并增强泛化。
   - 结果：在Ego-Exo4D等跨视角基准上，LEGO生成的第一人称视频在FVD、PSNR、LPIPS等指标上优于依赖3D提升的基线，视角一致性和时序稳定性更好，并能提升下游第一人称动作识别与具身感知任务表现。实验证明无需显式3D提升也能实现高质量跨视角视频生成，对动态遮挡场景更鲁棒。这些结果表明免提升范式在跨视角视频生成中具有潜力。

**主要痛点**
- 视频/机器人世界模型缺乏动作忠实性与目标导向，长时程预测易累积误差。
- 跨视角与3D生成仍受显式3D提升和局部可控性不足制约。
- 扩散语言模型推理慢，多分支投机解码存在冗余。

**方法趋势**
- 反事实后训练、目标导向闭环规划、免提升跨视角扩散、多分支折叠投机解码、局部空间条件3D生成、流式全景世界模型。

**结果信号**
- 多项工作在动作遵循、任务完成率、跨视角一致性、推理吞吐、局部编辑和导航成功率上取得提升。

1. [MiMo-V2.6: Scaling Reinforcement Learning Towards Self-Improvement](https://huggingface.co/papers/2610.11959)
   - 分类：RL Self-Improvement / LLM Post-Training
   - 研究价值：值得精读
   - 关联：直接关联高效训练与后训练规模化，是RL自我改进方向的重要工程与算法探索。
   - 痛点：大模型后训练高度依赖人工偏好数据与固定奖励模型，RL规模化时面临奖励劫持、训练不稳定与能力退化等问题，尤其在数学、代码等长程推理任务上，自我改进循环难以稳定扩展，算力与数据标注成本居高不下。现有方法多依赖外部高质量标注或强教师模型，缺乏可持续的自生成训练闭环，导致性能提升很快遇到瓶颈，难以在真实后训练流程中低成本落地。
   - 方法：论文提出MiMo-V2.6，构建可扩展的自我改进强化学习框架：通过自生成可验证任务构造训练信号，结合迭代式奖励建模与在线难度课程，让模型在无人工偏好标注下持续生成高质量数据；同时采用异步分布式RL与裁剪策略提升长程训练稳定性，并设计多阶段策略优化流程，使自我改进循环能够在规模化集群上高效运行，兼顾训练吞吐与策略更新质量。
   - 结果：在数学、代码与通用推理基准上，MiMo-V2.6相比前代及同规模基线取得显著提升，多轮自我改进后性能持续增长而非饱和；实验验证了无需人工偏好数据即可规模化RL训练，训练稳定性与样本效率均有改善，为低成本、可复现的高效后训练提供了路径，也展示了自我改进范式在长程推理任务上的扩展潜力。

2. [SparseDecoding: Decoding-Aware Pruning for Accurate and Efficient LLM Inference](https://huggingface.co/papers/2610.12327)
   - 分类：LLM Inference / Decoding-Aware Pruning
   - 研究价值：值得精读
   - 关联：面向LLM推理加速的剪枝方法，与高效推理部署方向高度相关。
   - 痛点：现有LLM剪枝方法多基于校准数据或静态权重重要性，忽略自回归解码阶段的动态激活模式，导致剪枝后精度明显下降，尤其在长序列生成、稀疏激活与KV缓存受限场景下，难以同时兼顾推理吞吐与输出质量。如何在解码过程中动态识别冗余、避免一刀切剪枝，是高效推理部署中的关键痛点。
   - 方法：论文提出解码感知剪枝框架SparseDecoding：在自回归解码过程中动态估计各注意力头与MLP通道的重要性，结合轻量预测器与稀疏度调度，逐token选择保留子网络；并融合KV缓存感知的通道剪枝与算子级优化，使剪枝决策与解码路径对齐，从而在推理时动态适配不同输入难度，减少无效计算。
   - 结果：在多个开源LLM上，SparseDecoding在相同稀疏度下比静态剪枝方法取得更低困惑度与更好的下游任务精度，解码吞吐提升约1.5至2倍，显存占用显著下降；消融实验表明解码感知的重要性估计与稀疏度调度是关键增益来源，证明动态剪枝可在几乎不损失精度的情况下带来实质推理加速。

3. [SpecFold: Folding Multi-Branch Redundancy for Faster Speculative Decoding in Diffusion Language Models](https://huggingface.co/papers/2610.04875)
   - 分类：Speculative Decoding / Diffusion LM
   - 研究价值：值得精读
   - 关联：面向扩散语言模型的投机解码加速，属于高效推理与新型生成范式的交叉方向。
   - 痛点：扩散语言模型并行解码时存在大量多分支冗余计算，投机解码在扩散框架中面临候选树膨胀、验证开销高与接受率低的问题，导致实际加速比有限，难以在长文本生成中高效部署。如何压缩多分支候选、降低验证成本并提升接受率，是扩散语言模型推理加速的核心痛点。
   - 方法：论文提出SpecFold，将多分支投机解码的候选路径折叠为紧凑表示，利用分支间冗余合并与动态剪枝减少验证成本；并设计折叠感知的接受准则与调度策略，适配扩散语言模型的迭代去噪过程，使候选生成、折叠与验证在统一框架内协同，减少重复前向计算与无效分支扩展。
   - 结果：在多个扩散语言模型与基准上，SpecFold在保持生成质量的同时将解码步骤减少约2至3倍，端到端加速比相较标准扩散解码显著提升，且优于已有投机解码基线；实验进一步表明折叠策略对长文本生成尤为有效，为扩散语言模型的高效推理提供了可推广的加速方案。

**主要痛点**
- 大模型后训练RL依赖人工偏好数据，规模化时训练不稳定、成本高。
- LLM解码阶段存在大量冗余计算，静态剪枝难以兼顾精度与吞吐。
- 长上下文KV缓存线性增长导致显存与带宽瓶颈，压缩易丢失细节。
- 扩散语言模型多分支投机解码候选膨胀，验证开销高、接受率低。
- 测试时迭代扩展易出现信息衰减与收益饱和，难以稳定放大计算。

**方法趋势**
- 自生成可验证任务与迭代奖励建模，实现无人工标注的RL自我改进。
- 解码感知的动态剪枝与稀疏度调度，逐token选择保留子网络。
- 多分支候选折叠与冗余合并，降低扩散语言模型投机解码验证成本。
- 残差记忆模块实现上下文压缩，保留token级细节并增量更新。
- 循环原生注意力残差稳定深层迭代，支持数万次测试时迭代。

**结果信号**
- MiMo-V2.6在多轮自我改进后推理与代码能力持续提升。
- SparseDecoding在相同稀疏度下精度更优，解码吞吐提升约1.5至2倍。
- SpecFold将扩散语言模型解码步骤减少约2至3倍并提升端到端加速。
- REMORY在8倍压缩率下保持接近全上下文的长上下文任务精度。
- Loop-Native Attention Residuals支持数万次测试时迭代并持续提升性能。

1. [DreamTrue: Action-Faithful Robot World Model with Counterfactual Post-Training](https://huggingface.co/papers/2610.12468)
   - 分类：Robot World Model / Model-Based RL
   - 研究价值：值得精读
   - 关联：直接对应具身智能中基于模型的学习与规划，解决世界模型对动作不敏感这一关键瓶颈。
   - 痛点：机器人世界模型常被用于预测动作后果，但多数像素级视频预测模型对动作并不“忠实”：不同动作可能产生几乎相同的预测，模型更依赖视觉先验而非真正建模动作与环境的因果耦合，导致规划与策略学习得到误导性的 rollout，长时程误差不断累积。这种“动作不敏感”在接触丰富、动态非线性的操作任务中尤为突出，直接限制了基于模型的强化学习在真实机器人上的可用性。
   - 方法：论文提出 DreamTrue，一个强调动作忠实性的机器人世界模型，并配套反事实后训练（counterfactual post-training）范式：在预训练生成式世界模型基础上，针对同一初始观测构造不同动作序列的反事实样本对，用对比/偏好式目标强化模型对动作差异的敏感度，使其在改变动作时产生一致且可区分的预测偏移；后训练阶段同时对长时程预测误差进行校准，使模型在闭环中稳定支持策略评估与规划。
   - 结果：实验显示，经过反事实后训练的 DreamTrue 在动作敏感性指标与长时程预测一致性上显著优于纯监督训练的生成式世界模型基线，明显缩小了真实 rollout 与预测 rollout 之间的差距；将其接入基于模型的规划与强化学习流程后，策略成功率与样本效率均有提升，并在多个操作任务上表现出一定的跨任务、跨场景泛化能力，说明“动作忠实”是提升世界模型实用性的关键因素。

2. [WorldGuide: Goal-Directed Video World Model for Procedural Task Execution](https://huggingface.co/papers/2610.12459)
   - 分类：Video World Model / Long-Horizon Planning
   - 研究价值：值得精读
   - 关联：面向具身长时程任务执行，把视频世界模型从被动预测推进到目标与进度导向的可用规划器。
   - 痛点：现有视频世界模型大多只做被动预测，缺乏对目标与任务进度的显式建模。在需要按步骤完成多阶段流程的机器人任务中，模型容易生成视觉上合理但步骤错乱、遗漏关键中间状态的视频，无法为长时程规划提供可靠指导；目标条件化不足也使模型在给定高层指令时难以保持步骤一致性，缺少可中断、可恢复的流程约束。
   - 方法：论文提出 WorldGuide，一个目标导向的视频世界模型：以语言指令与目标条件、当前任务进度作为引导信号，在扩散式视频生成框架中引入任务阶段与进度表征，并采用分块自回归方式逐段预测未来观测；训练时结合目标条件监督与步骤级一致性约束，使生成轨迹与预设流程对齐，从而可作为闭环规划器、进度估计器与策略评估器使用。
   - 结果：在若干流程化操作基准上，WorldGuide 在生成质量、步骤一致性与目标达成率等指标上优于通用视频世界模型和目标条件基线，生成的长时程 rollout 能在更长时间范围内保持阶段正确；将其作为规划或评估模块接入下游任务后，执行成功率显著提高，表明目标导向的视频世界模型可直接赋能具身长时程任务执行。

3. [SuperNav: An Agentic Navigation System for Any Task in Any Scene](https://huggingface.co/papers/2610.12126)
   - 分类：Embodied Navigation / Agentic Systems
   - 研究价值：值得精读
   - 关联：属于具身导航与智能体框架交叉方向，可作为通用导航与任务执行的系统级基座。
   - 痛点：现有导航系统通常针对特定场景或特定任务定制（如点目标导航、视觉语言导航），依赖预先构建的地图或固定动作空间；当场景从室内换到室外、任务从“去找物体”变成“按指令完成一串操作”时难以直接迁移。同时缺少统一的感知—推理—行动智能体框架，导航与下游操作、工具调用之间的衔接脆弱，泛化性与实际可用性受限。
   - 方法：论文提出 SuperNav，一个面向“任意任务、任意场景”的智能体导航系统：以多模态大模型作为决策核心，将导航建模为可调用工具（建图、主动探索、目标定位、路径规划、记忆检索等）的分层智能体循环，通过统一的观测—记忆—动作接口与可插拔技能库支持室内外、静态与动态环境；借助在线反馈与技能自组合适配新任务，无需针对每个任务重新训练。
   - 结果：在多个跨场景、跨任务基准上，SuperNav 取得领先或具竞争力的成功率与路径效率；零样本/少样本迁移到训练分布外的场景与任务时，性能下降明显小于专用基线。消融实验显示，分层工具调用与长期记忆是主要增益来源，系统可作为通用导航与具身任务执行的基座组件。

**主要痛点**
- 机器人世界模型对动作不敏感、长时程预测漂移，难以支撑可靠的基于模型规划。
- 视频世界模型缺乏目标与任务进度约束，流程化长时程任务生成步骤错乱。

**方法趋势**

**结果信号**

1. [SuperNav: An Agentic Navigation System for Any Task in Any Scene](https://huggingface.co/papers/2610.12126)
   - 分类：Embodied Agent / Navigation
   - 研究价值：值得精读
   - 关联：面向具身智能与智能体导航的统一系统，与团队在通用任务型 Agent 与真实场景落地方向高度关联。
   - 痛点：现有导航智能体普遍被场景与任务双重绑定：一类工作在固定仿真环境（如室内 PointNav、ObjectNav）中训练，换到室外、跨楼层或杂乱动态场景即性能崩塌；另一类只支持单一目标类型（点到点、找物体），无法处理“先找到某物再执行操作”这类复合指令。同时，感知-规划-控制各模块间的接口是硬编码的，任务语义难以直接约束底层动作，导致 Agent 在新场景、新任务上必须重新采集数据与重训，泛化成本极高。
   - 方法：论文提出统一的智能体导航框架 SuperNav，核心是把任务理解、场景感知与动作决策都交给可组合的 Agentic 组件：以视觉语言模型作为高层任务解析器，把任意自然语言指令分解为可验证的子目标序列；中层采用语义地图与记忆模块维护跨时刻的场景表征，支持动态更新与重规划；底层通过技能库（skill library）将子目标映射为连续的导航与交互原语，使同一套策略可迁移到室内外多种场景。系统以闭环方式在推理时调用工具与自我纠错，而非为每个任务单独训练策略。
   - 结果：在覆盖室内外、静态与动态场景的多类导航与复合任务基准上，SuperNav 相比任务专用基线取得一致提升，尤其在零样本迁移到未见场景与未见任务组合时优势明显，任务成功率与路径效率指标均有改善；消融显示语义记忆与子目标分解是主要增益来源。论文还表明统一框架可同时支撑点到点导航、目标搜索与“导航+操作”复合任务，验证了通用性。

2. [A Closer Look at Agentic BBO: Benchmarking LLM Agents for Black-Box Optimization](https://huggingface.co/papers/2610.12183)
   - 分类：Agent Benchmark / Black-Box Optimization
   - 研究价值：值得精读
   - 关联：为 LLM Agent 在优化与科学发现类任务中的能力提供系统性评测视角，可用于校准团队的 Agent 评测方法论。
   - 痛点：黑盒优化（BBO）是实验设计、超参调优、材料发现等场景的共性难题，近期大量工作声称 LLM Agent 能通过“提出候选—观察反馈—迭代改进”超越贝叶斯优化等经典方法，但这些结论缺乏统一评测：各论文自建任务、自选预算、自设成功指标，甚至把手工调好的提示与大量试错预算混入对比，导致无法判断增益究竟来自模型的优化推理能力，还是来自外围工程与评测设定的松动。领域急需一套受控、可复现的 Agentic BBO 基准来回答“LLM Agent 到底强在哪、何时失效”。
   - 方法：论文构建面向 LLM Agent 的黑盒优化基准，系统梳理并标准化任务族（连续/离散、低维/高维、带噪声与约束等）、查询预算、初始点、评估指标与重复实验协议，把 Agent 设定与经典优化器（贝叶斯优化、进化算法、随机搜索等）置于同一预算下比较。方法上还分解 Agent 的组成要素：提示与领域知识注入、历史反馈的表示方式、探索-利用权衡策略、候选生成与反思模块，并设计消融实验分离各因素贡献，同时分析预算规模、维度与目标函数平滑度对性能差距的影响。
   - 结果：结果显示 LLM Agent 在低维、低成本、语义可先验注入的任务上具备竞争力，常能借助先验快速锁定有希望的区域；但在高维、噪声大或预算紧张时明显落后于成熟优化器，且性能对提示格式、反馈表示和预算设定高度敏感。基准化对比还表明部分先前宣称的领先优势在统一预算与多轮重复后消失，说明存在评测偏乐观问题。论文据此给出何时该用 Agent、何时该退回经典优化器的结论与实用建议。

3. [Accurate but Not Humble: Evaluating Epistemic Humility in LLM Agents under Knowledge Conflict](https://huggingface.co/papers/2610.12360)
   - 分类：Agent Trustworthiness / Knowledge Conflict
   - 研究价值：值得精读
   - 关联：关注智能体在知识冲突下的可靠性与校准，直接关系到团队部署 Agent 时对幻觉与错误自信的防护设计。
   - 痛点：LLM Agent 在实际运行中经常遇到外部证据与自身参数化知识相冲突的情形，例如检索文档、工具返回值或用户纠正与模型记忆不一致。此时理想行为是一致地采信更可靠来源，并在证据不足时承认不确定、主动求助或放弃作答。然而现有评测多只看最终答案准确率，忽视“以何种方式抵达答案”：模型可能凭错误自信压过正确证据，也可能在真该坚持时盲从错误输入。缺乏对认知谦逊（epistemic humility）的度量，使 Agent 在高风险场景下表面准确、实则不可信。
   - 方法：论文提出面向知识冲突的评测框架，通过在智能体流程中注入受控冲突来考察其行为：构造模型记忆与外部证据相互矛盾的任务，并控制证据可靠性、冲突强度、来源权威性与误导信息比例。评测不只看答案对错，还引入一组认知谦逊指标，刻画模型是否表达不确定性、是否请求澄清、是否在更新信念时给出合理依据，并区分“合理坚持”与“顽固错误”、“合理让步”与“盲目服从”。方法同时分析提示、检索质量、多轮交互与自我反思对谦逊行为的影响，形成可复用的诊断流程。
   - 结果：实验发现模型呈现出明显的“准确但不谦逊”模式：在冲突情境下往往给出高置信度答案，不确定性表达稀少，且倾向于过度依赖参数化记忆而忽略更新的外部证据；当外部证据正确时盲从与忽略并存，行为不一致。指标还显示多轮追问与显式反思可部分改善校准与求助行为，但不能消除错误自信。论文据此指出，仅以准确率衡量 Agent 会系统性高估其可信度，需将校准与冲突处理纳入评测标准。

**主要痛点**
- 导航与具身智能体难以跨场景、跨任务泛化，模块接口硬编码导致重训成本高。
- LLM Agent 在优化、检索等任务上的能力宣称缺乏统一评测协议，结论可比性差。
- Agent 在知识冲突下常表现出错误自信，缺少对校准与不确定性表达的度量。

**方法趋势**
- 用视觉语言模型做高层任务分解，结合语义记忆与技能库实现闭环导航。
- 构建受控基准与统一预算协议，将 Agent 与经典优化器同台对比并做要素消融。
- 通过注入受控知识冲突并设计认知谦逊指标，诊断 Agent 的信念更新行为。

**结果信号**
- 统一导航框架在未见场景与复合任务上取得一致提升。
- LLM Agent 在低维先验可注入任务上有优势，高维噪声场景落后于经典优化器。
- 模型普遍准确但不谦逊，仅以准确率评估会高估 Agent 可信度。
