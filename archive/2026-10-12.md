1. [Continually Post-training Small Models via Synthetic Self-distillation](https://huggingface.co/papers/2610.13113)
   - 分类：Continual Learning / Self-Distillation / Small Model Post-training
   - 研究价值：值得精读
   - 关联：直接命中'高效训练'主线：在无人工标注、无外部教师推理的条件下让小模型持续吸收新知识，是边缘侧与长周期迭代场景中训练成本最低化的关键路径，可作为团队小模型持续后训练流程的核心参考。
   - 痛点：小模型在持续后训练中面临灾难性遗忘与高质量标注数据稀缺的双重困境：真实任务数据昂贵且分布不断漂移，直接微调容易过拟合新任务并破坏已有能力；而依赖大模型蒸馏又需要持续调用教师模型、承担高昂推理成本，难以在边缘侧或长周期场景中反复迭代。如何在无人工标注、无额外教师推理开销的前提下，让小模型稳定地持续吸收新知识，是高效训练领域亟待解决的具体痛点。
   - 方法：论文提出合成自蒸馏的持续后训练框架：模型先用自身对未标注或合成输入生成候选回答，再通过自洽性过滤、可验证性检验或奖励打分筛出高质量样本，构造合成训练集；随后在参数高效微调（如 LoRA）与正则化、经验回放机制的约束下，把筛选后的伪标签数据回灌到自身参数中，形成“自生成—自筛选—自更新”的闭环。为抑制自我强化偏差，框架混入少量历史数据做回放并冻结部分层以稳定优化。
   - 结果：实验显示该闭环在多个持续学习任务上让小型模型在保持原有能力的同时获得稳定提升，相比直接监督微调显著降低遗忘率，且无需任何外部教师模型推理或人工标注，训练与推理成本均大幅下降；合成数据的质量筛选是收益关键，去掉筛选环节后性能退化明显。论文还给出模型规模、合成数据量与回放比例的消融结论，说明方法在算力受限场景下具备可复现的高效性。

2. [SoftwareGym: Scaling Computer-Use Agent Training with Diverse Synthesized Software Environments](https://huggingface.co/papers/2610.12611)
   - 分类：Agent Training / Environment Synthesis / Data Scaling
   - 研究价值：值得精读
   - 关联：面向智能体训练的数据与环境扩展：用程序化合成替代昂贵人工环境搭建，直接降低训练数据获取成本，是'高效训练'在 agent 方向上的规模化基础设施，对团队构建可复现训练管线有直接借鉴价值。
   - 痛点：计算机使用智能体的训练长期受限于真实软件环境稀缺、配置昂贵且不可复现：搭建一套可交互的桌面或网页应用需要大量人工，状态空间难以覆盖长尾操作路径，导致轨迹数据规模小、多样性差，智能体在真实软件上的泛化与鲁棒性提升缓慢。如何低成本、大规模地合成多样化且可执行的软件环境，并把它们高效转化为训练信号，是智能体训练扩展性的核心瓶颈。
   - 方法：论文构建 SoftwareGym，以程序化方式批量合成多样化软件环境：通过模板化与随机化组合界面组件、功能逻辑与任务目标，自动生成可交互应用及配套的指令—操作—反馈轨迹，并提供统一接口把环境并行化，使智能体能在成千上万个合成环境中进行大规模试错式训练。环境可自动校验任务完成状态，从而给出稠密奖励，并可与现有智能体训练管线直接对接。
   - 结果：在合成环境上大规模训练的计算机使用智能体，迁移到真实软件基准后成功率明显优于仅在少量真实环境或静态数据集上训练的策略，且环境多样性与并行度提升同任务成功率呈正相关；合成的稠密奖励有效缓解了稀疏反馈导致的训练低效问题，验证了“环境合成即数据扩展”这一路径的可行性与可扩展性，为后续按需扩张训练规模提供了工程范式。

3. [SWE-Duel: Towards a Self-Scaling Arena for Coding Agents](https://huggingface.co/papers/2610.12569)
   - 分类：Coding Agents / Self-Scaling Evaluation / Arena
   - 研究价值：值得精读
   - 关联：把评测与训练数据生成合成一个自扩展闭环，用对抗式信号替代昂贵人工标注，既降低评测成本又反哺训练，属于'高效训练与推理'中数据效率与迭代效率的结合点。
   - 痛点：编码智能体的评测与迭代面临成本与污染双重困境：真实仓库任务需要人工构造、执行代价高，静态基准很快被训练数据污染，排行榜分数与实际能力脱节；同时缺乏可持续、自扩展的对抗式评估信号，使改进方向难以快速验证，训练数据生成效率低下。如何用自动化、可自扩展的竞技机制同时解决评测失真与数据稀缺，是该方向的具体痛点。
   - 方法：论文提出 SWE-Duel，一个自扩展的编码智能体竞技场：让不同智能体在同一批由仓库演化或合成流程动态生成的代码任务上两两对抗，比较补丁正确性与测试通过率，用对战结果自动更新评分与任务难度分布，并持续扩充任务池。系统以自动验证（单元测试与执行反馈）充当裁判以减少人工标注，同时对多智能体并行执行做调度优化以控制单轮评测开销。
   - 结果：实验表明该竞技场能提供比静态基准更稳定、区分度更高的排名，随对战轮次增加，任务池规模与难度自动增长，顶尖智能体的胜率逐步收敛；对抗式信号还能反哺训练，提升智能体在真实仓库修复任务上的通过率，验证了自扩展评估闭环在降低评测成本与缓解数据污染方面的有效性。

**主要痛点**
- 高质量标注与真实环境/仓库数据获取成本高，持续迭代易灾难性遗忘或遭数据污染
- 外部教师模型蒸馏与人工构题的推理和评测开销过大，难以在算力受限场景反复迭代

**方法趋势**
- 自生成—自筛选—自更新的合成自蒸馏闭环，配合参数高效微调与经验回放
- 程序化合成多样可交互环境并自动校验，提供稠密奖励与并行训练接口
- 自扩展对抗式竞技场，用自动测试裁判动态更新评分、难度与任务池

**结果信号**
- 小模型持续后训练遗忘率显著下降且无需教师推理，成本大幅降低
- 合成环境大规模训练后真实软件迁移成功率提升，与环境多样性正相关
- 自扩展竞技场排名区分度更高，对抗信号反哺训练提升真实仓库修复通过率

2. [Reflex: Visually Grounded Reactive Humanoid Control](https://huggingface.co/papers/2610.12772)

   - 研究价值：值得精读
   - 关联：与具身智能/人形机器人控制强相关，关注视觉闭环、反应式控制和 sim-to-real。
   - 痛点：人形机器人在非结构化环境中的全身控制需要同时处理视觉感知、动态平衡与实时反应，但现有方法常把感知、规划与控制分层，导致反应延迟大、视觉-动作耦合弱，难以应对移动目标、突发遮挡和外部扰动；sim-to-real 中的视觉域差异与高维动作空间也进一步放大了策略学习难度，因此如何让 humanoid 基于视觉输入实现低延迟、可泛化的反应式全身控制是核心痛点。
   - 方法：Reflex 提出视觉 grounded 的反应式人形控制框架：以第一人称/外部视觉观测为条件，直接输出全身关节动作或运动指令，并通过强化学习在仿真中训练教师策略，再利用蒸馏/域随机化迁移到真实机器人；其关键设计是让视觉表征与本体感受在闭环控制中紧密耦合，使策略能根据场景变化实时调整步态、平衡与肢体动作，而不是依赖慢速高层规划。
   - 结果：论文展示了 Reflex 能在真实人形平台上完成视觉引导的反应式运动与操作任务，对外部扰动、目标变化和部分遮挡表现出更强鲁棒性与更低响应延迟；相比传统分层控制，端到端 visuomotor 策略在动态场景中提升任务成功率并减少跌倒，说明视觉 grounded 的闭环控制可有效增强 humanoid 的实环境适应能力。若能在多任务与多地形上验证，则表明该方法具备较强泛化潜力。具体指标需参考原文。

   - 结果：论文的核心结论是：训练环境的多样性可以随合成规模扩展，并据此扩大 computer-use agent 的训练规模，缓解环境稀缺带来的泛化瓶颈；即在合成软件环境集合上训练，比局限于少量环境更有利于策略迁移。需要说明的是，本次抓取的元数据中未包含摘要与具体数值，因此论文给出的基准设置、成功率提升幅度与消融实验结论尚未核实，建议进一步阅读原文确认实验指标。

**主要痛点**
- computer-use agent 训练所需的真实软件环境依赖人工搭建，成本高、复现难，环境多样性不足导致策略跨软件泛化能力受限。

**方法趋势**
- 用自动合成方式批量生成多样化的可交互软件环境，把环境构建转化为可扩展流程，扩展智能体的训练环境分布。

**结果信号**
