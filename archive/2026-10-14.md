1. [PixelMoE: Scaling Pixel-Space Diffusion with LLM-Style Mixture-of-Experts](https://arxiv.org/abs/2610.18857v1)
   - 分类：Pixel-Space Diffusion / MoE
   - 研究价值：值得精读
   - 关联：直接推进像素空间扩散的可扩展性，MoE稀疏扩展与层次化流匹配对生成式模型Scaling具普遍参考价值。
   - 痛点：像素空间扩散模型无需VAE分词器，可直接建模原始图像、避免潜空间压缩的信息损失，但其扩展长期走稠密路线，模型容量与激活计算量强耦合，放大规模时训练与推理成本急剧上升；同时LLM中成熟的MoE稀疏架构能否迁移到像素空间扩散、是否必须引入扩散专用路由机制与辅助路由目标尚无系统验证，高分辨率下全局结构与细节的平衡也缺乏有效机制。
   - 方法：PixelMoE将标准LLM式Token-Choice路由与细粒度专家结合用于输入自适应稀疏计算，保留共享专家捕获公共表示，并用基于偏置的负载均衡策略稳定训练，稀疏专家与共享专家并行激活使容量随专家数扩展而计算量近似恒定；同时提出像素空间层次化流匹配，沿去噪轨迹从全局结构形成到局部细节精炼逐步改变空间分辨率，全程不依赖扩散专用路由或辅助路由目标。
   - 结果：在类别条件ImageNet-1K上，PixelMoE在256×256取得FID 1.47、512×512取得1.53，且未使用表示对齐或感知损失；同等激活参数量下各规模均稳定优于稠密基线，证明像素空间中稀疏容量扩展有效，结果与领先的像素空间及潜空间生成模型相比也具竞争力，作者承诺释放代码与模型以支持复现。

2. [GAD: Geometry Attention Distillation for Consistent Video Generation](https://arxiv.org/abs/2610.18779v1)
   - 分类：Video Generation / Attention Distillation
   - 研究价值：值得精读
   - 关联：针对视频扩散一致性这一核心难题，注意力蒸馏思路可迁移到其他生成backbone，实验增益显著。
   - 痛点：视频扩散模型能生成视觉上吸引人的短片，但难以在时间维度保持场景几何与物体结构一致，作者发现现有视频注意力无法识别可靠的跨帧对应，响应分散在多个区域，即使场景结构已可辨认，导致长程场景一致性与动态时间一致性不足，该问题在长视频生成与场景结构形成阶段尤为突出。
   - 方法：GAD把冻结几何模型注意力中的对应关系蒸馏到视频注意力，这些对应从干净视频提取并连接同一静态表面或运动物体；由于结构在较高噪声时形成于深层、较低噪声时形成于浅层，方法按噪声时间步选择学生层施加蒸馏，使视频注意力更一致地聚焦于对应位置，且不引入额外推理模块，可直接嵌入现有视频生成流程。
   - 结果：在三种视频backbone上均提升长程场景一致性与动态时间一致性，几何指标随生成长度增加而改善；在Wan2.2 5B上两个长程基准的跨帧匹配准确率较基线至少提升30%，且不增加额外推理模块，实验覆盖多种生成长度与backbone，显示一致性与动态质量同时改善，为视频世界模拟提供高效路径。

3. [Scaling Online Optimal Transport Minibatches for Flow Matching](https://arxiv.org/abs/2610.18838v1)
   - 分类：Flow Matching / Optimal Transport
   - 研究价值：值得精读
   - 关联：为flow matching训练稳定性提供理论刻画与可扩展算法，对扩散/流生成模型的训练实践影响广泛。
   - 痛点：流匹配的训练与积分稳定性高度依赖源样本与数据样本的配对方式，独立随机配对方差大，minibatch最优传输可构造在线耦合降低随机性；但面对更大、更高维数据集时小minibatch限制收益，而每次迭代把耦合扩展到显著更大的minibatch计算上不可行，且OT耦合如何影响完整随机梯度与积分缺乏理论刻画。
   - 方法：该工作提出可扩展的在线熵正则OT近似，使源-目标耦合规模显著增大而保持OT收益；理论上针对无正则与熵正则OT，证明相对独立配对可严格降低完整随机梯度方差与积分误差，并刻画这些改进如何随在线耦合minibatch增大而增强，在保持计算可行的前提下把在线耦合扩展到远大于以往minibatch的规模。
   - 结果：在单细胞基因插值流与图像流训练上，实验与理论预测一致：更大的在线耦合持续提升训练稳定性与最终生成性能，说明扩大在线OT minibatch兼具理论依据与实际收益；该结论对大规模流匹配训练中超参与耦合规模的选取具直接指导意义，也为后续研究提供了可扩展的实现路径。

**主要痛点**
- 像素空间扩散容量与激活计算强耦合，高分辨率视频/图像生成的注意力与跨帧一致性代价高
- 流匹配/扩散训练中源-目标配对与在线OT耦合规模受限，稳定性理论刻画不足
- Schrödinger bridge等模型的免训练条件采样缺失，视频扩散跨帧几何对应不可靠
- 机器人与世界模型评估缺乏真实执行配对基准，恢复与持续改进机制不成熟

**方法趋势**
- LLM式MoE稀疏路由+共享专家+层次化流匹配，几何注意力蒸馏迁移跨帧对应
- 可扩展在线熵正则OT近似，回火twist+序列蒙特卡洛实现SB免训练条件采样
- 生成式多视角网格重建与因果世界生成，MoE统一世界/世界-动作模型
- 扩散策略人类视频预训练+少量示范引导微调，能量景观内省式终身学习

**结果信号**
- PixelMoE在ImageNet-1K 256/512达FID 1.47/1.53；GAD在Wan2.2 5B上跨帧匹配提升至少30%
- 更大在线OT耦合持续提升训练稳定性；WorldRecon Chamfer降低14.9%/43.1%
- UniW(A)M真实操作平均成功88.3%，GreenWAM在WorldArena与RoboTwin领先
- Steertuning以5条示范约5分钟达71%成功率，LoopWAM成功率提升19.7个百分点

### 高效训练与推理

1. [Hybrid Reasoning Agents](https://arxiv.org/abs/2610.18861v1)
   - 分类：Latent Reasoning / Agent Inference Efficiency
   - 研究价值：值得精读
   - 关联：与团队“高效训练与推理”方向直接相关：给出可落地的潜空间/文本混合推理范式与配套后训练配方，直接压缩长程 Agent 的 token 消耗与推理延迟，并保持工具调用能力与推理可解释性。
   - 痛点：现代 LLM Agent 仍以自然语言作为推理与交互的唯一媒介，每一步思维链都要以 token 形式显式生成，导致 token 消耗、推理延迟与成本随交互轮次和任务长度急剧膨胀，长程任务尤为严重；隐空间潜推理虽然计算高效，却缺乏原生工具调用能力与可读的推理轨迹，无法直接在外部环境中行动与调试，实用性受限。如何在不牺牲 Agent 工具使用与透明性的前提下，把大量冗余的语言化推理替换为更经济的内部计算，是该领域亟待解决的核心痛点。
   - 方法：论文提出 Hybrid Reasoning Agents（HybridAgents），一种在统一生成过程中动态穿梭于潜空间推理与文本交互的混合架构：轻量模块 HybridLink 负责在文本模式与潜空间模式之间无缝切换，使潜思考可被直接检视，同时保留原生工具调用；连续工作记忆跨多轮维护无损的混合上下文。在此架构之上进一步设计配套后训练算法：HybridSFT 通过让主干学会与 HybridLink 协同，稳定带工具的混合生成；HybridRL 则以强化学习教会模型判断何时该在潜空间思考、何时该以文本行动。
   - 结果：在 3 个模型规模、覆盖数学、科学、医学、检索与 Agent 推理等 11 个基准的评测中，HybridAgent 相比前沿文本式 LLM Agent 以及文本/潜空间两类 Agent 框架平均性能提升 10.4%；同时带来 35.5%–54.7% 的 token 削减、1.8–2.6 倍的推理加速与 2.7–3.7 倍的成本节省，说明潜空间与文本混合推理能够在提升能力的同时显著改善推理效率。

2. [DoubtLess: Training-Free Contrastive Decoding for Efficient Reasoning](https://arxiv.org/abs/2610.18862v1)
   - 分类：Efficient Reasoning / Decoding-Time Intervention
   - 研究价值：值得精读
   - 关联：直接命中“高效推理”：免训练、即插即用的解码期方法，可与现有推理模型和训练式压缩叠加，适合作为团队推理加速的默认基线并快速迁移到 Agent 场景。
   - 痛点：推理模型依赖长链思维（CoT）获得强性能，但常常生成远超解题所需的 token，重复检查与“wait”式回溯讨论占据大量预算，推高延迟与成本。现有加速手段各有代价：为每个模型重新训练压缩会带来额外训练开销；在隐状态上加固定 steering 向量会粗暴改变表示；早停或禁用特定词等解码启发式则可能损害准确率。因此亟需一种无需训练、不损精度、且不依赖隐状态注入的通用推理压缩方法。
   - 方法：DoubtLess 是一种免训练的解码期对比方法，让一个小型推理模型在每一步引导大型模型的 logits：小模型读取大模型已有的 CoT 两次，一次以“简洁思考者”提示、一次以“冗长思考者”提示，两者 logits 之差经强度系数缩放后加到大模型的输出分布上，从而在多步解码中持续朝简洁方向偏移。整个过程无需改动模型权重、无需额外训练，也不需要访问隐状态或注意力矩阵。
   - 结果：在竞赛数学、研究生级科学与竞技编程共 7 个基准上，DoubtLess 将 Qwen3-32B 的 CoT 长度缩短 31% 且准确率不变，优于 5 个推理时基线；在自调试编码 Agent 中每轮思考 token 减少 20% 且任务表现不变，并可泛化到另外两个模型家族。与训练式压缩结合可进一步缩短 CoT；行为分析显示节省主要来自首次得到正确答案之后的重复检查。

3. [Visual Tokens on Demand: Visual Budgeting for Scalable and Efficient Multi-Image Reasoning in Multimodal LLMs](https://arxiv.org/abs/2610.18858v1)
   - 分类：Multimodal Efficiency / Visual Token Compression
   - 研究价值：值得精读
   - 关联：属于多模态推理效率的关键一环，与团队关注的推理期 token 压缩、prefill 开销与 KV/注意力成本优化直接相关，且即插即用、不重训基座、易复现验证。
   - 痛点：多模态大模型多针对单图输入优化，多图推理时每张图都会引入大量视觉 token，编码与注意力开销随之线性增长。现有多数 token 剪枝、合并、压缩与重采样方法面向单图设计，假设冗余主要是空间局部冗余；多图场景下冗余跨图存在、任务相关证据稀疏且分散，激进压缩会丢失比较、计数、时序推理与证据定位所需的细节。而依赖注意力矩阵的方法与 FlashAttention 等高效实现不兼容，训练型方案还需重训或适配基座模型。
   - 方法：论文提出 mmVB，一个轻量即插即用模块，在不重训基座模型、也不在推理时访问注意力矩阵的前提下，利用跨图上下文为每张图分配“查询条件化”的 token 预算，即按需保留视觉 token。模块仅新增 1.6M 可训练参数，可与现有内存高效注意力实现共存，因而能在不改变基座权重的情况下实现可控的视觉预算分配。
   - 结果：mmVB 将视觉输入 token 减少 9 倍，带来 5 倍的首 token 延迟加速与 7 倍的 prefill FLOPs 下降，同时在 8 个多图推理基准上仍保持 94.4% 的全分辨率精度，说明按需视觉预算能在几乎不损失性能的前提下大幅提升多图推理的可扩展性与效率。

**主要痛点**
- 大模型推理 token 与延迟开销随思维链长度、Agent 轮次与输入图像数量快速增长，长链思维与多图输入存在大量冗余计算
- Agent 任务每步都调用 LLM 导致成本随执行原语/迭代次数线性膨胀，长程任务奖励稀疏、数据难以策划与验证
- 训练侧大 batch 与学习率缩放规则缺乏理论指导，混合质量数据难以有效利用，示范采集与真机试错代价高昂
- 现有 token 压缩与加速方法常依赖注意力矩阵、需重训基座模型，或与 FlashAttention 等高效实现不兼容

**方法趋势**
- 免训练解码期干预（小模型简洁/冗长对比 logits 引导）与潜空间/文本混合推理架构，配套 HybridSFT/HybridRL 后训练
- 查询条件化的按需 token 预算（mmVB）、动作分块减少 LLM 调用、技能与经验的选择性注入与复用
- 架构与稀疏化改造：跨层记忆读写 LDM、像素空间 MoE 稀疏激活、按噪声时间步注意力蒸馏
- 训练数据与梯度优化：可扩展在线熵 OT 近似、质量感知条件化预训练、反向翻译、稠密进度奖励塑形
- 硬件感知实现与低资源流水线（4×3090 上分钟级训练、单步策略蒸馏）

**结果信号**
- DoubtLess 在 7 个推理基准上缩短 31% CoT 且准确率不变；HybridAgent 平均性能 +10.4%、token 减少 35.5%–54.7%、推理加速 1.8–2.6 倍
- mmVB 视觉 token 减少 9 倍、TTFT 加速 5 倍、prefill FLOPs 降低 7 倍并保留 94.4% 精度；ChunkAct 成功率 +5.0 点且 LLM 调用减少 2.9 倍
- 更大在线 OT 耦合持续改善流匹配训练稳定性与生成质量；LDM 在 400M/1.5B 取得比 PreLN/mHC/AttnRes 更低的困惑度
- Tev-27B 借稠密进度奖励在 ALE-CM 追平前沿模型并泛化到 Terminal-Bench；GreenWAM 蒸馏单步策略支持实时控制

1. [LoopWAM: Closed-Loop Generalist Policy Improvement from Deployment Rollouts](https://arxiv.org/abs/2610.18873v1)
   - 分类：Closed-Loop Robot Policy Learning / World-Action Models
   - 研究价值：值得精读
   - 关联：直接面向具身智能中从真实部署 rollout 闭环改进通用策略的问题，结合世界模型、动作生成与强化学习式自我改进。
   - 痛点：通用机器人策略常依赖专家示范进行行为克隆，但部署 rollout 中混合了成功、次优与失败经验；直接模仿所有动作会强化坏行为，过滤失败又丢失宝贵的物理交互后果，导致策略难以从真实部署中持续自我改进。该痛点的核心是缺乏一种能同时利用多质量数据、并把动作条件世界模型与策略改进耦合起来的训练机制，使机器人在多任务和单任务后训练中都能闭环提升。
   - 方法：论文提出闭环世界-动作模型 LoopWAM，用来自自身和其他已部署策略的 rollout 训练，并通过来源相关噪声采样统一行为学习与动作条件世界建模；质量引导与质量加权监督保留全质量视频监督，同时调节动作模仿；视频与动作 token 在并行去噪中交互，使学到的物理后果直接指导动作生成。
   - 结果：在 RoboChallenge Table30-V2 上，三轮部署-训练将成功率从 23.67% 提升到 43.33%，提升 19.7 个百分点，最终得分 56.80；RoboTwin 2.0 平均成功率 94.5%，RoboCasa365 总体成功率 49.5%；衬衫折叠任务经两轮部署驱动改进，成功率从 13.20% 升至 55.56%。

2. [ChunkAct: Action Chunking for Agentic Robotics](https://arxiv.org/abs/2610.18874v1)
   - 分类：Agentic Robotics / Action Chunking
   - 研究价值：值得精读
   - 关联：直接对应 LLM agent 控制机器人时的推理效率瓶颈，是 agentic robotics 与动作分块交叉的重要工作。
   - 痛点：Agentic robotics 将 LLM agent 放入机器人控制回路，每个 primitive 都要基于完整交互历史做一轮 LLM 推理，导致 episode 成本随 primitive 数量线性增长；这种逐步推理在子目标确定后往往高度冗余，严重制约长程任务效率与可扩展性。该痛点说明 agentic 机器人不能只关注任务成功率，还必须降低每步决策的 LLM 计算与上下文成本。
   - 方法：ChunkAct 将 action chunking 引入 agentic robotics：在线时一次 LLM 调用启动一串链式 primitive，chunk 自主执行，仅在失败时交回控制；离线时将记忆编译成这些 chunk，使测试时执行无需记忆，规划器只用于真正需要推理的决策。这样 LLM 计算量随决策数而非 primitive 数扩展。
   - 结果：在 LIBERO-Pro 上，ChunkAct 相比当时最优 agentic robotics 方法任务成功率提升 5.0 个百分点，同时 LLM 调用减少 2.9 倍、输入 token 减少 4.4 倍、输出 token 减少 2.3 倍，说明 LLM 计算量随决策数而非 primitive 数扩展。

3. [Interaction Latents as Actions for Contact-Rich Manipulation](https://arxiv.org/abs/2610.18855v1)
   - 分类：Contact-Rich Manipulation / Action Representation
   - 研究价值：值得精读

3. [ChunkAct: Action Chunking for Agentic Robotics](https://arxiv.org/abs/2610.18874v1)
   - 分类：Agentic Robotics / Inference Efficiency
   - 研究价值：值得精读
   - 关联：用 action chunking 消除 agent 冗余逐步推理，对任何长时程 LLM agent 的成本优化都有借鉴意义，尤其适合机器人工具链编排。
   - 痛点：把 LLM agent 放入机器人控制回路虽能零训练泛化到新任务，但效率代价很高：每个原子动作都要基于完整交互历史做一轮 LLM 推理，单个 episode 的成本随原语数量线性增长，长时程任务下推理调用与 token 消耗急剧膨胀。而这类逐步推理在很大程度上是冗余的——子目标一旦确定，后续原语往往按记忆中的既定流程执行，却仍要反复调用规划器，造成算力与延迟浪费。
