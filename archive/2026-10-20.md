1. [Text-to-Image Generative Modeling Without Language Pretraining](https://arxiv.org/abs/2610.26863v1)
   - 分类：Text-to-Image Generation / Multimodal Autoregressive Models
   - 研究价值：值得精读
   - 关联：直接挑战当前T2I默认依赖语言预训练的范式，对低成本多模态生成和端到端训练路线很有启发。
   - 痛点：现有文生图系统几乎都把互联网规模语言预训练视为默认前提，导致预训练算力高昂、流程复杂且强依赖文本语料；更关键的是，社区缺少控制实验回答语言预训练究竟是否为强T2I生成所必需，以及从零训练能否在质量与效率上同时竞争。该痛点限制了新架构探索、低成本复现和端到端多模态预训练路线的可行性，尤其在同规模比较中，语言预训练收益与算力开销的权衡并不清楚。
   - 方法：作者提出 Halcyon 系列早期融合多模态自回归模型，完全从零在 GPIC 的1亿图文对上预训练，不加载任何语言模型权重；通过统一 token 序列让文本与图像在早期交互，并以受控实验比较纯文本预训练加 T2I 与从零训练的差异。方法上还用 I2T 监督替代 caption dropout，使同一预训练预算下兼顾图像描述与文生图能力，核心是验证语言预训练并非强 T2I 的必要条件。
   - 结果：实验显示 Halcyon-0.52B 以 48.0 对 63.3 的 gFD 优于 LlamaGen-XL/8，且预训练算力少 18.2 倍；Halcyon-1.6B 以 35.3 对 41.0 优于 JiT-T2I-XXL/8++，算力少 275 倍。控制实验表明纯文本预训练并不能提升 T2I 生成，说明强 T2I 可从零训练；替换为 I2T 监督后仍保持有竞争力的生成质量并学会图像描述。

2. [SpecKCast: Spectral Kalman Forecasting for Diffusion Acceleration](https://arxiv.org/abs/2610.26837v1)
   - 分类：Diffusion Acceleration / Feature Forecasting
   - 研究价值：值得精读
   - 关联：与团队关注的 DiT 推理加速和特征缓存/预测方向高度契合，可直接用于现有生成管线。
   - 痛点：扩散 Transformer 需在数十个去噪步上反复前向，推理成本高；特征缓存虽能复用跨步特征，但现有预测式方法对所有空间频率分量采用统一外推，忽略了不同去噪阶段主导频率不同，以及去噪进程非均匀导致等步长对应变化量差异巨大。这两类失配会随跳步数增加放大预测误差，限制加速比与保真度的折中，尤其在高分辨率图像和视频生成中，误差累积会直接破坏细节与时间一致性。
   - 方法：SpecKCast 是一种免训练方法，先把模型输出做二维离散余弦变换，将特征分解到频域；随后为每个 DCT 系数配置轻量 Kalman 滤波器，并依据噪声调度构造频带特定的时间坐标，跟踪系数的取值与变化率。只有当滤波器预测不确定性超过阈值时才真正调用 Transformer，从而自适应决定哪些去噪步可以跳过，把频域分解、非均匀时间重参数化和不确定性门控结合起来。
   - 结果：在 FLUX.1-dev、Qwen-Image、Wan2.1-14B 与 HunyuanVideo 上，SpecKCast 在加速与保真度之间取得优于现有缓存和预测方法的折中，最高实现约 6 倍加速，额外显存不到 0.05 GiB。由于按频带和不确定性自适应跳步，它在高跳步比下仍能抑制误差累积，适合直接接入现有 DiT 推理管线，实验覆盖图像与视频两类主干。

3. [GenOlympiad: Benchmarking Frontier Image Models at Their Capability Boundaries](https://arxiv.org/abs/2610.26850v1)
   - 分类：Text-to-Image Benchmark / Capability Evaluation
   - 研究价值：值得精读
   - 关联：直接服务T2I模型选型与失败分析，能暴露计数、推理、物理一致性等硬能力短板。
   - 痛点：文生图模型视觉质量快速提升，但社区缺少能压力测试能力边界的基准；现有评测常依赖主观风格或粗粒度 VLM 打分，难以回答前沿模型在计数、深度推理、物理一致性、复杂规则遵循等硬能力上究竟差多少。评测饱和与不可验证会掩盖真实短板，阻碍模型选型与迭代，尤其缺少可视觉验证、可自动锚定证据的难提示集。
   - 方法：GenOlympiad 从九个能力轴构造高难度提示，强调提示对齐可视觉验证而非风格主观；评估框架把每个提示拆成易问题与难问题，并为多数难题自动绘制辅助线以锚定证据，再据此评分。基准覆盖20多个强模型，并分析模型演化、与 Elo 的一致性及 grounding 评估协议的有效性，还用自动化流程降低人工评分成本，从而对前沿 T2I 进行可复现的压力测试。
   - 结果：评测显示最佳模型 Nano Banana Pro 严格得分仅23.9/100，说明前沿 T2I 在硬能力上仍远未饱和；代码模型如 GPT-6 Astra 的提示对齐分数更高但视觉美感不足。作者还给出模型演化趋势、与 Elo 分数的对齐分析，并验证基于 grounding 的自动评估协议，为后续 T2I 能力诊断提供可复现基准，代码与提示已公开。

**主要痛点**

- DiT多步去噪推理成本高，现有特征预测忽略频域差异和去噪非均匀性。
- 视频与世界模型仍难兼顾长时序一致性、物理合理性和隐藏状态规则遵循。

**方法趋势**
- 从零训练早期融合多模态自回归模型，并用受控实验隔离语言预训练作用。
- 频域DCT加逐系数Kalman滤波，按噪声调度和不确定性门控跳过DiT去噪步。
- 多镜头3D布局控制、状态与渲染解耦、滑动窗口token和跨形态统一运动学表示。
- 可验证难提示集、对象级物理测量和自动grounding评估协议。

**结果信号**
- Halcyon以18.2倍和275倍更少预训练算力超过强T2I基线，纯文本预训练无增益。
- SpecKCast在多个图像/视频DiT上最高约6倍加速，额外显存低于0.05 GiB。

- 视频与世界模型工作普遍在跨块一致性、物理测量和组合泛化上暴露新失败模式。

### 高效训练与推理

1. [TokenGate: Adapting LLMs for Fast and Memory-Efficient Prefill with Learned Token Pruning](https://arxiv.org/abs/2610.26754v1)
   - 分类：Efficient Inference / Token Pruning
   - 研究价值：值得精读
   - 关联：直接优化长上下文 prefill 的 token 计算量，兼顾 TTFT、峰值显存与精度，是高效推理的核心工作。
   - 痛点：长上下文输入在每一层都要处理全部 token，prefill 的时延和显存开销随序列长度快速增长；现有 token 剪枝方法多依赖不可微的 top-K 或额外启发式，难以与预训练模型端到端适配，且在高压缩率下容易损失精度。同时，直接套用固定阈值或静态稀疏模式无法根据输入内容动态决定哪些 token 值得深入计算，导致“省算力”和“保效果”之间难以兼顾。
   - 方法：提出 TokenGate，一个可插拔的小组件，在现有 Transformer 与混合注意力模型上增加可学习的 token 重要性评分；为绕开 top-K 不可微问题，设计 token-gated attention，借鉴 MoE 用 token 重要性对 attention logits 重新加权，使剪枝决策可由下游任务损失端到端训练。训练时只更新少量新增参数，推理时按重要性丢弃低分 token，从而减少后续层计算和 KV 缓存占用。
   - 结果：在多种长上下文任务上，TokenGate 在精度不下降的前提下实现 1.4–11.3 倍更快的首 token 时延（TTFT）和 1.5–3.4 倍更低的峰值显存；相比此前最佳 token 剪枝方法，prefill 最高快 6.4 倍、峰值显存低 2 倍。它可原生扩展到 Qwen3 等标准 Transformer 以及 Qwen3.5 等混合注意力模型，适配成本接近常规参数高效微调。

2. [SpecKCast: Spectral Kalman Forecasting for Diffusion Acceleration](https://arxiv.org/abs/2610.26837v1)
   - 分类：Diffusion Acceleration / Feature Forecasting
   - 研究价值：值得精读
   - 关联：面向扩散模型多步去噪的免训练加速，直接减少 transformer 调用次数，属于生成模型推理加速。
   - 痛点：Diffusion Transformer 推理需在大量去噪步上反复执行 transformer，特征缓存与预测虽能跳过部分步，但现有方法对所有空间频率分量统一外推，忽略不同去噪阶段频率变化差异，也忽略去噪进程非均匀导致等步间隔对应变化量不同；跳过步数增多时预测误差被放大，限制加速比。因此，如何在频域按分量、按阶段自适应地决定外推与真实计算，成为扩散加速的关键问题。
   - 方法：SpecKCast 是一种免训练方法，对模型输出做二维 DCT，将特征转到频域；对每个 DCT 系数用轻量 Kalman 滤波沿由噪声调度推导的频带特定时间坐标跟踪其取值与变化率，仅在滤波预测不确定性超过阈值时调用 transformer。这样模型可自适应决定何时计算、何时外推，并把计算预算集中到频率变化剧烈或预测不可靠的系数上。
   - 结果：在 FLUX.1-dev、Qwen-Image、Wan2.1-14B、HunyuanVideo 上，SpecKCast 在加速与保真之间取得优于现有缓存/预测方法的折中，最高实现 6 倍加速，额外显存不到 0.05 GiB。在多个主干和视频生成任务上均保持较低质量损失，并随跳过步数增加仍能控制预测误差。结果说明频域 Kalman 跟踪能更稳健地跳过冗余去噪步，且无需重新训练模型。

3. [LatComm: Reusable Context Compression for Latent Communication between Large Language Models](https://arxiv.org/abs/2610.26840v1)
   - 分类：LLM Communication / Context Compression
   - 研究价值：值得精读
   - 关联：通过可复用潜空间上下文压缩降低跨 LLM 通信与重复 prefill 成本，属于推理效率与上下文压缩交叉方向。
   - 痛点：多 LLM 系统常把同一长上下文传给多个模型和多个问题，若以文本传递，接收模型每个问题都要重新处理全部 token，成本随上下文长度和问题数线性增长；现有压缩或潜空间通信方法难以同时满足上下文表示紧凑、可跨问题复用、可被另一 LLM 读取三个条件。这导致上下文复用与跨模型协作之间缺乏一个既省算力又不牺牲答题质量的接口，尤其当接收模型与编码模型不同、且问题不断到来时，重复 prefill 成为主要瓶颈。
   - 方法：LatComm 将编码与读取分离：冻结的上下文编码器 LLM 先在不看问题的情况下把上下文压缩成固定大小 packet，发送给另一个冻结的接收 LLM；接收端通过 cross-attention 读取 packet，门控由自身 prompt 计算，从而按问题选择需要读取的内容。该设计让同一 packet 可被多个问题复用，同时保持接收模型无需重新处理原始长上下文；训练只涉及轻量接口，不更新两个冻结 LLM。
   - 结果：在 12 个多项选择 QA 数据集上，LatComm 平均准确率比单向量基线最高提升 10.2 分；在 QuALITY 上把接收端输入减少 57 倍，并使回答一篇文章问题的时间快 3 倍。在多个数据集上均保持稳定增益，而非仅对单一任务有效，表明可复用潜空间上下文能在跨模型通信中同时降本增效，并为多 LLM 协作提供可扩展的上下文接口。

**主要痛点**
- 长上下文 prefill 与跨模型重复处理仍是推理成本主瓶颈，token 剪枝、上下文压缩和可复用潜空间表示是重点方向。
- 扩散/生成模型多步去噪带来重复 transformer 计算，现有缓存与预测方法在频域自适应和非均匀去噪上仍有误差放大问题。
- 高效适配与持续训练面临灾难性遗忘、全量微调成本高、适配器静态合并无法动态组合能力等问题。
- 上下文压缩与记忆内化缺少忠实性评估和存储/速度联合优化，压缩后证据保留与长历史存储仍是痛点。

**方法趋势**
- 可学习 token 重要性评分与 token-gated attention，实现端到端 token 剪枝和 KV 缓存削减。
- 频域 DCT + Kalman 滤波跟踪扩散输出系数，按预测不确定性自适应跳过 transformer 调用。
- 编码-读取分离的潜空间上下文 packet，配合 prompt 门控 cross-attention 实现跨问题复用。
- LoRA 动态切换、参数高效微调、多 LoRA 内核、递归权重共享和原生记忆架构降低训练/适配成本。
- 分阶段预训练、成本-性能 Pareto 搜索和合成环境训练提升训练/执行效率。

**结果信号**
- TokenGate 在精度不降下实现 1.4–11.3 倍 TTFT 加速和 1.5–3.4 倍峰值显存降低。
- SpecKCast 在多个扩散主干上最高 6 倍加速，额外显存低于 0.05 GiB。
- LatComm 在 12 个 QA 数据集上平均准确率最高提升 10.2 分，QuALITY 输入减少 57 倍、回答快 3 倍。
- MemT-1.0 在 128K 历史下约 1.86 倍推理加速和 66 倍持久存储压缩；WeAct 比全量微调高 6.2% 且计算更少。
- HarnessPro 相对 RHO 通过率提升 2.0 个百分点，每任务成本降低 26.1%。

1. [Ropedia W0: Scaling Loco-Manipulation World Models across Embodiments with Human Experience](https://arxiv.org/abs/2610.26855v1)

   - 研究价值：值得精读
   - 关联：直接对应具身世界模型、跨具身迁移与策略评估，建议团队精读并评估Xp-Data与Xp-Teleop的可复用性。
   - 痛点：现有世界模型多局限于单一具身或纯视频预测，无法统一建模人形与机器人之间的异构动作空间，移动与操作常被割裂处理。跨具身多模态数据稀缺、标注不统一，且缺少长时程移动操作基准，导致世界模型在真实具身间迁移、策略评估和基于模型的规划中缺乏可靠支撑，也难判断缩放人类数据是否真正提升机器人表现。现有工作还常把动作空间、相机运动与手部操作分开建模，使跨具身预训练难以共享表示；真实机器人数据规模远小于人类视频，如何利用人类经验补足机器人监督也是关键缺口。

   - 结果：在DreamDojo、Ψ0、ω-HOME、Xp-Teleop和AgiBot五个跨具身基准及留出人类第一人称视频上取得SOTA，从零样本到少样本和全量后训练均验证有效；缩放人类预训练数据可同时提升人类与机器人评测。蒸馏后支持实时分钟级rollout和VR交互，并展示策略评估、基于模型规划与世界-动作建模的应用潜力。这些结果表明大规模人类经验可迁移到机器人世界模型。

2. [Physical Words: A Vocabulary for Structuring Latent Reasoning in Robot Manipulation](https://arxiv.org/abs/2610.26854v1)
   - 分类：Robot Manipulation / Latent Reasoning
   - 研究价值：值得精读
   - 关联：对应机器人操作中的reasoning-before-acting与视觉触觉推理，核心机制可迁移到现有VLA和世界模型。
   - 痛点：语言推理能表达任务语义，却难以刻画接触、形变和位姿变化等细粒度物理动态；latent reasoning能预测未来状态，却缺少可复用的推理原语和时序结构。机器人操作需要同时利用语义与动力学，如何把连续物理动态组织成可解释、可迁移、可多模态扩展的推理单元，是reasoning-before-acting范式的核心痛点；现有VLA还常把语言推理与底层动作生成割裂。
   - 方法：提出PhysWord，用原子动作动词作为连续物理动态的共享语义锚点；模型预测未来原子动作词，并把其上下文隐状态与对应未来观测导出的latent目标对齐。进一步构建带视觉和可选触觉变体的时序PhysWord空间，自回归预测未来时间步的Physical Words以捕捉执行阶段转换，为动作生成提供结构化多模态上下文，并让推理原语可按时间组织。
   - 结果：在视觉触觉UniVTAC上取得90.3%成功率，在视觉LIBERO-Long上取得99.6%，并在双臂夹爪和灵巧手的真实任务上优于对比方法；进一步实验表明该结构化latent推理框架能泛化到未见场景，并支持长时程操作。结果说明原子动作词对齐能有效桥接语义推理与物理动力学，为机器人基础模型提供可复用的推理接口。

3. [GPT-6 Astra Is a Native Visuo-Tactile Policy for Contact-Rich Manipulation](https://arxiv.org/abs/2610.26846v1)

### 2. [VideoMaMa++: Temporally Consistent Video Matting via Preserve-and-Refine Token](https://arxiv.org/abs/2610.26857v1)

- 来源：arXiv
- 关键词：video matting, diffusion, attention, consistency across chunk boundaries, matting benchmarks and in-the-wild, matting via preserve-and-refine token.
- 链接：<https://arxiv.org/abs/2610.26857v1>

**原始摘要**

### 8. [SpecKCast: Spectral Kalman Forecasting for Diffusion Acceleration](https://arxiv.org/abs/2610.26837v1)

- 来源：arXiv
- 关键词：forecasting methods, video generation, transformer, diffusion, better trade-off between acceleration, acceleration and fidelity THAN
- 链接：<https://arxiv.org/abs/2610.26837v1>

**原始摘要**

Diffusion Transformers (DiTs) achieve high-fidelity image and video generation, but they suffer from substantial inference costs due to repeated transformer evaluations across many denoising steps. Feature caching reduces this cost by reusing features across denoising steps. Recent forecasting methods extend this idea by extrapolating features to skipped steps instead of reusing them. However, existing forecasting methods extrapolate the features they predict uniformly, even though the spatial-frequency components of these features change most at different stages of denoising. The filter tracks each coefficient's value and rate of change, and the transformer is evaluated only when the filter's forecast uncertainty exceeds a threshold. Experiments on FLUX.1-dev, Qwen-Image, Wan2.1-14B, and HunyuanVideo show that SpecKCast achieves a better trade-off between acceleration and fidelity than existing caching and forecasting methods, reaching up to 6x speedup with less than 0.05 GiB of additional memory.
