1. [AEON: Unifying Video and 3D World Models](https://arxiv.org/abs/2610.28631v1)
   - 分类：Video World Model / 4D Gaussian Splatting
   - 研究价值：值得精读
   - 关联：直接对应视频生成与3D/4D世界模型融合方向，建议团队精读其潜空间桥接与4DGS解码设计。
   - 痛点：当前显式世界模拟分成两条路线：视频生成模型外观逼真但难以保持3D一致性，3D生成模型几何一致却常输出静态、真实感不足的观测。如何在同一生成框架中同时获得视频级真实感、可渲染的4D一致性、相机轨迹控制与持久场景动态，并解决生成视频潜空间到重建4D表示之间的域差异，是视频/3D世界模型融合的核心痛点。
   - 方法：AEON在文本或图像条件视频潜空间中生成，并输出可渲染的4D Gaussian Splatting作为显式世界表示。它先用单目视频训练4D重建模型，联合预测4DGS与相机位姿作为初始化4D解码器；再设计域适配器，在视频VAE上蒸馏，把生成视频潜变量转换为重建4D潜变量。推理时按预测相机轨迹渲染4DGS，并构建带场景动态的持久4D环境。
   - 结果：在标准基准上取得SOTA，并统一支持视频式世界建模、持久4D环境构建和多种下游应用；生成结果既保持视频真实感，又具备3D/4D一致性，可按预测相机轨迹重渲染，并支持带动态的场景模拟。相较纯视频或纯3D路线，AEON把外观生成与几何一致性放在同一潜空间框架中，验证了视频生成与4D重建表征可互为解码接口，项目页展示了多样化应用。

2. [SolarRenderer: Few-Step Generative Reference Rendering](https://arxiv.org/abs/2610.28630v1)
   - 分类：Few-Step Diffusion / Controllable Video Rendering
   - 研究价值：值得精读
   - 关联：面向可控视频生成与少步扩散渲染，工程与算法价值都高，适合关注高效生成和结构控制的成员。
   - 痛点：游戏引擎和编码智能体已能给出场景布局、运动与相机，但把粗结构转成真实视频需要渲染器既严格跟随结构又补全外观。现有渲染器通常绑定单一引擎表示、依赖数十步去噪或昂贵自蒸馏，且训练条件与目标视频不对齐，导致跨结构表示泛化差、推理慢。尤其缺少一个统一控制接口，能用同一模型跟随姿态骨架、绘图、点云等异构结构并支持实时流式渲染。
   - 方法：SolarRenderer冻结MiniMax-H3 33B视频主干，只训练两个轻量LoRA：结构视频按所描述帧的位置进入主干原生reference通路，不设类型标识，仅用纯文本描述，使单一控制LoRA跟随任意结构表示。它从预训练四步LoRA出发，用结构引导分布匹配实现四步渲染，并设计块因果变体支持流式；训练语料为13.6万帧对齐片段，覆盖游戏引擎、模拟器和YouTube。
   - 结果：相比50步采样提速12.3倍，块因果变体可实时渲染768p视频；在分布内测试和16种结构表示泛化基准上均达SOTA。模型泛化到11种未见表示，包括姿态骨架、手绘和点云，说明统一reference通路与少步分布匹配能同时保持结构控制、生成质量和推理效率，并保留四步LoRA学到的控制能力，为引擎/智能体驱动的可控视频生成提供了可部署路径。

3. [Large Flow Language Models](https://arxiv.org/abs/2610.28559v1)
   - 分类：Flow Matching LM / Diffusion Language Model
   - 研究价值：值得精读
   - 关联：连续流语言模型规模化的重要进展，适合关注扩散/流式LLM、推理加速和训练效率的成员精读。
   - 痛点：自回归语言模型受顺序解码瓶颈限制，离散扩散虽可并行但语义连贯性和十亿参数级规模化仍不足；连续流语言模型具备并行生成、控制和加速潜力，但大规模构建方法、数据效率与推理加速方案尚不成熟。现有扩散式语言模型往往需要海量token训练，且少步生成与质量、吞吐之间的权衡未被充分解决。核心痛点是能否以低成本把连续流LM扩展到8B规模并同时匹配AR质量。
   - 方法：Lafa采用块式流语言模型：前缀用因果注意力，块内用双向异步流。它通过适配预训练自回归模型高效训练，并利用前缀缓存与块级并行解码加速推理；在0.5B、7B、8B规模上仅用不到300亿token训练，还可蒸馏为flow map支持一步/少步生成。作者利用流训练带来的多token预测效应，设计自推测解码，在同一模型内用自回归验证流式草稿。
   - 结果：在指令跟随、推理和编程任务上，8B规模Lafa的生成质量匹配或超过AR模型，且流训练能保留甚至提升预训练AR能力。自推测解码在可比质量下达到AR模型2.54倍吞吐，优于多token预测和离散扩散方法；少步蒸馏支持一步/少步生成。结果说明连续流可在较低数据成本下扩展到十亿参数，并作为可扩展语言建模基础。

**主要痛点**
- 视频/3D世界模型仍难兼顾真实感、几何一致性与持久动态。
- 扩散/流模型在少步生成、规模化训练和推理吞吐之间仍需权衡。
- 多模态与具身生成缺少统一表示、可靠评估和跨具身泛化。

**方法趋势**
- 视频潜空间与4DGS/几何特征桥接，统一生成与重建。
- 冻结大主干加轻量LoRA、分布匹配和块因果流式实现少步高效渲染。
- 块式流匹配、自推测解码与奖励引导去噪提升扩散/流语言模型质量与速度。

**结果信号**
- AEON、SolarRenderer、Lafa分别在4D世界模型、少步渲染和8B流语言模型上取得SOTA或显著加速。
- 点轨迹监督与视触觉一致性后训练提升多视角预测和机器人策略评估。
- 持续个性化、离散扩散候选集和检索式版权检测在各自基准上表现突出。

### 高效训练与推理

1. [Adaptive Multi-Token Prediction: How far should we go?](https://arxiv.org/abs/2610.28619v1)
   - 分类：LLM Inference Acceleration / Multi-Token Prediction
   - 研究价值：值得精读
   - 关联：直接对应高效解码与投机推理，是本次最贴近高效推理的论文之一。
   - 痛点：多 token 预测（MTP）能通过一次目标模型验证多个草稿 token 来加速解码，但最佳投机视野会随上下文变化：长草稿可靠时可摊薄验证成本，一旦被拒绝又会浪费后缀计算。与逐 token 停止的自回归草稿不同，MTP 的所有头在同一前向中触发，必须在起草前固定视野，现有方法缺少无需重训练、且不改变精确验证器的上下文自适应控制机制，导致固定窗口在吞吐与浪费之间难以权衡。
   - 方法：将视野选择建模为在线控制问题，用验证反馈学习当前上下文可信任的草稿长度；AMTP 以轻量控制器预测每个视野的接受生存概率，并选择期望每秒 token 数最高的视野。控制器从每次验证过程自由学习，无需重训练草稿模型或修改目标验证器，并用在线梯度下降获得亚线性 regret，理论上把预测误差转化为对最佳视野的吞吐 regret 与墙钟完成时间界。
   - 结果：在 Llama-3.1-8B-Instruct + Medusa、Meta MTP、Qwen3-4B-Inst-2507-MTP 等五个草稿-目标组合上，于 AIME 2025 和 GSM8K 评估，AMTP 解码最高比标准解码快 4.1 倍。它在 10 个设置中有 8 个匹配或超过固定窗口，吞吐提升最高 10%，且控制器即插即用、无需重训练。这些结果说明上下文自适应视野能在不牺牲验证正确性的前提下减少拒绝后的浪费。

2. [Large Flow Language Models](https://arxiv.org/abs/2610.28559v1)
   - 分类：Flow Language Models / Parallel Generation
   - 研究价值：值得精读
   - 关联：面向十亿参数连续流语言模型的高效训练与并行解码，直接关联高效训练与推理。
   - 痛点：连续流语言模型有望实现并行生成并继承扩散模型的控制与加速工具，但在十亿参数规模上，如何数据高效地训练、如何保持生成质量以及如何与预训练自回归模型衔接仍缺乏成熟方案；现有扩散语言模型往往训练成本高、并行解码质量不稳定，难以作为通用语言建模基座。
   - 方法：提出 Lafa，一个 8B 参数的分块流语言模型：前缀使用因果注意力，每个块内部使用双向异步流，从而可适配预训练 AR 模型、支持前缀缓存和块级并行解码。训练在 0.5B、7B、8B 规模上使用少于 300 亿 token，并利用多 token 预测效应将流训练自蒸馏为 one/few-step flow maps，再用自投机解码在单模型内以自回归方式验证流草稿。
   - 结果：在指令跟随、推理和编程任务上，Lafa 的生成质量匹配或超过 AR 基线，并保持预训练 AR 能力甚至因多 token 预测效应而提升。自投机解码达到同质量 AR 模型 2.54 倍吞吐，优于多 token 预测和离散扩散方法；flow maps 支持一步/少步生成，表明连续流可作为可扩展语言建模基座。

3. [Beyond 4 bits: Data-Centric Post-training Quantization and Recovery](https://arxiv.org/abs/2610.28537v1)
   - 分类：Post-Training Quantization / Low-Bit Compression
   - 研究价值：值得精读
   - 关联：直接研究 2-bit 后训练量化与恢复，是低比特高效推理的关键方向。
   - 痛点：后训练量化在 4 bit 附近近乎无损，但降到 2 bit 时标量 PTQ 配置会跌到随机水平，严重限制低比特部署；已有研究常把量化表示、校准数据和恢复微调数据当作实现细节，而它们在 4 bit 下影响不明显、在 2 bit 下却决定模型是否可用，缺少面向生成任务和 MoE 模型的系统性数据中心配方。
   - 方法：系统研究量化表示、校准数据与恢复微调数据三项选择，覆盖 6 个 3.8B–32B 稠密与 MoE 模型；发现向量码本是最关键因素，并指出短恢复预算下校准数据与恢复数据耦合、必须联合选择。最终配方采用向量码本表示、小型任务对齐校准混合，以及低成本的仅码本恢复阶段，不依赖昂贵 QAT。
   - 结果：该配方约使用 2.3 个有效比特/权重，在标量 PTQ 已随机水平的场景下保留 89%–97% 的全精度问答准确率；包含恢复阶段后，比最强 QAT 基线少用 1.4–30 倍计算。作者还强调剩余精度损失主要集中在生成任务且模型依赖明显，说明 2-bit PTQ 需要表示与数据协同设计。

**主要痛点**
- LLM 解码与服务受 KV cache、固定投机视野和自回归顺序限制。
- 低比特量化、长序列推荐与图生成仍面临显存、计算和精度折衷。
- 视频/世界模型与机器人策略需要少步生成、蒸馏和域适配来降本。

**方法趋势**
- 在线控制自适应 MTP 视野、块式连续流与自投机解码。
- 向量码本 PTQ、cache 操作与 AKV 服务引擎、级联蒸馏检索。
- 少步 LoRA 渲染、Duhamel-Picard 并行积分与硬件友好注意力。

**结果信号**
- AMTP 最高 4.1x 解码加速，Lafa 同质量 2.54x 吞吐，2-bit PTQ 保留 89–97% QA。
- 缓存策略降本 27.7%，ECHO 降约 160x FLOPs，SolarRenderer 四步快 12.3x。
- PaPi 加速约 100x，图生成显存降 65%。

1. [Learning Adaptable Dexterous Skills via Hybrid Dexterous Mimicking](https://arxiv.org/abs/2610.28628v1)
   - 分类：Dexterous RL / Motion Tracking
   - 研究价值：值得精读
   - 关联：直接对应具身智能中的多指灵巧操作与强化学习，兼顾人类先验和目标泛化。
   - 痛点：灵巧多指操作的学习长期存在两难：目标驱动强化学习可从任意物体位姿出发，却缺少人类先验，容易收敛到不自然、不可靠的手指策略；单段运动跟踪虽能复现类人动作，却难以偏离参考轨迹，面对新物体位姿、遮挡和动态交互时泛化不足。现有流程很难仅凭少量人类示范同时获得可泛化、类人且可真实部署的灵巧技能，这成为从视频或动捕规模化学习灵巧操作的核心瓶颈。
   - 方法：AdaDex把一段数秒的手-物轨迹转化为目标条件技能，核心是Hybrid Dexterous Mimicking：共享策略同时在两类大规模并行环境中训练，一类用稠密运动跟踪目标注入人类先验，另一类对初始状态和目标加噪并仅给稀疏物体成功奖励，迫使策略在远离参考时仍能完成任务；两类环境共享参数，使跟踪先验与目标泛化相互校正。参考轨迹可来自动捕或野外RGB(D)视频的HOI重建。
   - 结果：实验覆盖功能抓取、物体重摆、手指步态的在手重定向以及抛接等动态任务，结果显示AdaDex在泛化性和功能性上优于基线，并能完成跨仿真器迁移与真实世界部署；每项技能仅需数秒人类运动，显著降低数据门槛。该结果说明跟踪先验与稀疏成功奖励的混合训练能同时保留类人性和目标适应性，为从少量示范扩展灵巧技能库提供了可操作路径。

2. [UniWALM: Unified World Action Language Model for Embodied Robot Control](https://arxiv.org/abs/2610.28626v1)
   - 分类：World-Action-Language Model
   - 研究价值：值得精读
   - 关联：直接对应具身智能中的统一世界模型、VLA与语言记忆闭环，属于长程操作核心方向。
   - 痛点：现有具身VLA或世界模型多把推理、视觉语言模型与视频-动作主干分成独立阶段，导致语言推理无法在动作生成中闭环，记忆依赖行为需要外部规划器或记忆库，且各模态表征割裂。同时，视频-动作联合生成中的动作流易受扰动，缺少无需推理开销的纠错机制。如何在同一表征中联合建模语言、视频和动作并支持记忆，是提升长程操作与真实部署可靠性的关键。
   - 方法：UniWALM用单一Mixture-of-Transformers主干统一视频、动作和语言，每个模态既是条件也是监督目标，各模态扩散头同步去噪，在同一次前向中解码子任务、文本记忆和动作，无需单独规划阶段；生成的语言在下一步被重新消费，形成语言即记忆的闭环。为稳定动作流，作者提出Flow Matching with Correction，在训练中学习从受扰动作轨迹恢复，而不增加推理成本。
   - 结果：在MolmoSpaces组合式拾放和RMBench记忆依赖子集上，UniWALM稳定优于同主干FastWAM等基线；RMBench达到34.5%，无需预训练语言或推理模型，仅用单锚帧就超过Mem-0的28.5%关键帧设置。真实Find-the-Item任务中，生成文本记忆把成功率从11.1%提升到61.1%，而先进VLA仍不超过33.3%，说明联合生成语言能反哺操作并支撑记忆行为。

3. [SuperMimic: Scaling Humanoid Whole-Body Control with One Differentiable World Model](https://arxiv.org/abs/2610.28480v1)
   - 分类：Humanoid Whole-Body Control / Differentiable World Model
   - 研究价值：值得精读
   - 关联：直接对应人形全身控制与基于模型的强化学习，用可微世界模型摊销跨动作策略学习。
   - 痛点：人形全身控制依赖大规模人类动作跟踪，但现有流程要么用逐动作专家再蒸馏，造成信息损失，要么用集群级算力暴力训练单一策略，成本极高；动作数据集扩大时，GPU小时几乎不可承受，难以系统研究动作跟踪的缩放规律。如何用一个可复用的动态模型摊销跨动作学习，是人形全身控制规模化的核心瓶颈，也限制了通用、富表现力人形行为的扩展。
   - 方法：SuperMimic从标准刚体仿真器日志中拟合一个可微世界模型，刻画所有动作共享的动力学，并让世界模型与跟踪策略在同一闭环中联合训练；策略通过在短时想象rollout上反向传播获得解析梯度，快速想象与解析梯度共同提升学习效率。该方法不依赖逐动作专家或大规模蒸馏，而是把共享动力学作为跨动作摊销器，并保持与标准仿真器的兼容。
   - 结果：单GPU 3小时即超过在128 GPU上训练7天的SOTA跟踪器回报，GPU小时减少超过1000倍；在129,514个基准动作上仅失败25个，而基线失败179个，训练9.8小时/2 GPU后达到零失败。世界模型预测误差从1到264小时动作保持稳定，策略可迁移到Unitree G1并完成多样甚至杂技动作，说明移除算力瓶颈后系统研究运动跟踪缩放规律变得可行。

**主要痛点**
- 灵巧操作、人形控制和长程操作仍受数据、泛化与接触动力学建模瓶颈。
- 世界模型需兼顾视频真实感、3D或触觉一致性以及策略评估可靠性。
- 智能体化机器人与VLA需更高效的规划器后训练、推理加速和记忆闭环。

**方法趋势**
- 混合运动跟踪与目标RL、可微世界模型BPTT、多模态扩散统一建模。
- 视觉-触觉或4D世界模型、奖励模型一致性后训练、主动证据获取。
- 智能体后训练、测试时自适应、缓存与推测解码等效率技术。

**原始摘要**
