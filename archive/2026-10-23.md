1. [WorldForge V2: Eliciting Camera-Trajectory Alignment in Video Diffusion Models](https://arxiv.org/abs/2610.31640v1)
   - 分类：Video Diffusion / Camera Control
   - 研究价值：值得精读
   - 关联：直接对应视频扩散模型的可控生成与相机轨迹对齐，是视频生成走向空间一致世界模型的关键方向。
   - 痛点：视频扩散模型虽具备丰富3D/4D先验，但用于空间任务时相机控制不精确，生成序列存在时空不一致，相机运动与场景动态相互纠缠；现有任务特定微调或后处理变形方案容易引入视觉伪影、泛化能力差且计算成本高，难以在保持预训练生成能力的同时实现可靠轨迹控制。用户既要求视角沿指定轨迹变化，又要求外观与物体运动稳定一致，这在场景生成、视频重渲染和交互式内容创作中尤为突出。
   - 方法：提出WorldForge V2，先构建免训练引导框架，用变形参考沿目标相机路径迭代修正生成；通过光流分析定位与运动相关的潜通道进行选择性引导，以分离运动控制与外观；再用双路径比较引导与无引导预测，纠正不完美参考造成的伪影，并用v-cache复用前一步去噪预测降低开销；进一步把运动定位扩展到网络块，训练Trajectory LoRA，并以两阶段策略让适配器学习引导生成中遇到的状态。
   - 结果：在多个数据集的定量与定性评测中，该方法在相机控制视频生成上取得最先进的生成质量和轨迹精度；Trajectory LoRA仅需很少训练数据，单个训练场景即可泛化到未见场景；v-cache在减少精修成本的同时保持控制效果；消融进一步验证光流通道选择、双路径纠偏和分块适配对轨迹对齐与外观保持的贡献，整体优于任务微调和后处理变形等基线。

2. [Squaring-the-Sphere: Distortion-Free and Seamless Panorama Generation via CubeAtlas](https://arxiv.org/abs/2610.31565v1)
   - 分类：Panorama Generation / Diffusion Transformers
   - 研究价值：值得精读
   - 关联：面向360度全景扩散生成，提出新表示与稀疏注意力，对高分辨率、跨视角一致的生成建模有直接参考价值。
   - 痛点：360度全景图像生成要求局部透视保真与全球球面连续统一，但现有表示存在两难：等距柱状投影可实现无缝全景建模，却有严重畸变和与预训练图像生成器的域差距；立方体贴图保留透视几何，却常出现面间不一致和可见接缝；同时高分辨率全景的密集注意力计算成本高，如何在单次生成中兼顾跨面关系、几何保真和效率是核心痛点。现有方法很难同时满足这些约束。
   - 方法：提出CubeAtlas表示，将全部立方体面展开到单个紧凑画布，并把方向对齐、旋转后的极区与赤道面并排组织，在保留立方体透视几何的同时显式编码无缝拼装所需的跨面关系；使预训练扩散Transformer无需改骨干或位置编码即可一次建模完整全景；针对结构化布局引入布局感知稀疏注意力掩码，仅保留全景连续性所需交互并剔除几何无关token对；还加入免训练超分与融合方案提升透视空间细节。
   - 结果：在多个基准上，CubeAtlas相较ERP建模取得更好的全景质量，同时注意力计算更低；方法在几何保真、跨视角一致性和高分辨率视觉质量上优于已有方案；免训练超分与融合方案进一步增强了无畸变透视空间的细节，并最终融合为ERP全景；消融表明结构化画布和布局感知掩码共同带来质量与效率收益，验证了表示与稀疏注意力的有效性。

1. [BeNice! Closing Looping's Inference-Memory Gap via KV-Sharing](https://arxiv.org/abs/2610.31633v1)
   - 分类：Efficient Inference / KV Cache
   - 研究价值：值得精读
   - 关联：直接针对循环架构推理显存瓶颈，属于高效推理与长上下文服务的关键优化。
   - 痛点：循环/looped 架构通过反复复用同一组层来提升能力而不增加参数量，但推理时每次递归都会生成独立 KV-cache，导致显存随递归深度线性增长，长上下文部署的缓存命中率、吞吐和首 token 延迟显著恶化。已有工作尝试跨深度共享 KV-cache，但 KV-shareability 的成因不清，甚至同构训练模型也未必稳定具备该性质，缺少可复现的启用方法。这使循环模型在真实服务中难以兑现固定参数量的成本优势。
   - 方法：论文提出两阶段方法：预训练阶段使用随机深度，诱导收缩性残差动态，使多次递归的表示趋向共同极限；后训练阶段提出 BeNice!，把最后一次递归的 KV-cache 广播到第一次递归，并训练模型产生兼容残差，同时保持原始质量。该方法可与多潜在注意力、Kimi delta 注意力等内存高效序列混合器以及 fp8/mxfp8/nvfp4 低精度 KV-cache 量化组合使用，从而把跨深度 KV 共享变成可训练、可组合的推理优化手段。
   - 结果：实验表明 BeNice! 在匹配标准微调未共享验证困惑度的同时实现 KV-shareability，说明共享缓存不必牺牲语言建模质量。在模拟低显存长上下文推理中，KV 共享将缓存命中率最高提升 31.4%，吞吐最高提升 23.6%，p90 首 token 延迟最高降低 83.6%。这些结果把循环架构的线性推理显存增长转化为可管理的缓存复用问题，并与低精度缓存压缩形成互补收益，对长上下文服务尤其关键。

2. [Low-Bit N-Gram Embeddings for Language Models](https://arxiv.org/abs/2610.31646v1)
   - 分类：Model Compression / Quantization
   - 研究价值：值得精读
   - 关联：直接降低语言模型辅助参数显存，属于部署侧高效推理与模型压缩的重要方向。
   - 痛点：n-gram 嵌入表被越来越多开放权重语言模型用于提升性能，它存储短 token 序列的学习表示并在处理时检索，但显存开销巨大，例如 DeepSeek-V4.1-Flash 的 Engram n-gram 记忆分配了 1960 亿参数。对部署而言，这部分参数直接抬高显存占用和成本，而简单删除又会损失 n-gram 表带来的验证损失收益，因此需要在不破坏效果的前提下压缩表内存。现有量化研究多关注主干权重，缺少针对 n-gram 表的方法与比特分配系统分析。
   - 方法：论文提出把 n-gram 嵌入以低精度存储，并系统比较不同量化方法与各表之间的比特分配，而不是对整张表采用单一精度。作者在从零训练的 nanochat、Llama 和 GPT-2 系列模型上评估四比特及更低比特方案，并测试短微调能否恢复少比特带来的性能损失。进一步地，论文把节省下来的内存再投资于更大的 n-gram 表，并在 DeepSeek-V4.1-Flash 与 Qwen3.8-Flash-Next 等已有大模型上验证低比特表的可迁移性。
   - 结果：四比特 n-gram 表节省约 75% 的表内存，同时保留超过 99% 的加入 n-gram 表带来的验证损失改善；更少比特会带来更大性能下降，但短微调可恢复显著部分。把节省内存再投资于更大的低比特表，可以在仍少于原始全精度表内存的情况下超过原表性能。在 DeepSeek-V4.1-Flash 和 Qwen3.8-Flash-Next 上，低比特表节省 47-55% 表内存，困惑度上升低于 1.2%，下游任务性能基本保持。

3. [Rethinking Sequence Compression with Test-time Regression](https://arxiv.org/abs/2610.31574v1)
   - 分类：Sequence Compression / Efficient Attention
   - 研究价值：值得精读
   - 关联：面向高效注意力与多模态 token 压缩，提供可替代池化/投影的通用压缩原语。
   - 痛点：序列压缩是高效语言模型和多模态模型的关键信息瓶颈：块稀疏注意力需要把长序列压成少量摘要，多模态 LLM 需要合并视觉 token，但主流池化或学习投影压缩器仍会明显损失性能。现有方法通常把压缩当作固定池化或附加投影，缺少一个既能端到端学习、又能在前向中高效求解的通用压缩原语，导致效率与质量难以兼得。尤其当压缩比提高时，简单池化会丢失判别信息，而复杂学习模块又引入额外开销。
   - 方法：论文从测试时回归视角重新定义序列压缩：输入 token 定义一个回归问题，回归的拟合系数直接构成压缩表示。该回归问题通过反向传播端到端学习，但其系数在前向过程中以闭式解高效计算，因此不需要额外的迭代求解器。基于此提出 TTR-Compressor，作为池化和投影压缩的通用替代，并分别用于块稀疏注意力的压缩器和多模态大模型的视觉 token merger；该方法把压缩器设计转化为可学习的回归目标。
   - 结果：在块稀疏注意力中，TTR-Compressor 相比基于注意力的压缩器大幅提升 RULER 性能，说明回归系数能保留更有效的长上下文信息。在视觉 token 合并中，它稳定优于标准 MLP merger，并在使用少 55.6% 视觉 token 的情况下匹配其性能。结果确立了测试时回归作为高效语言与多模态模型序列压缩的有效基础原语，并展示了跨任务复用潜力，尤其适合高压缩比场景。

**主要痛点**
- 长上下文与循环模型的 KV-cache 显存随深度或长度线性增长，制约吞吐和首 token 延迟。
- n-gram 表等辅助参数占用大量显存，缺少低比特压缩与逐表比特分配的系统方案。
- 序列压缩与测试时推理剪枝在质量、多样性和计算开销之间难以平衡。

**方法趋势**
- 跨深度 KV 共享与收缩残差训练；低比特 n-gram 嵌入量化与内存再投资；测试时回归闭式系数压缩；pass@k 目标剪枝。

**结果信号**
- KV 共享提升缓存命中率与吞吐并降低 p90 TTFT；四比特 n-gram 表节省约 75% 表内存；TTR-Compressor 在 RULER 与视觉 token 合并上更优。

   - 痛点：元强化学习需要在有限交互中快速适应未见任务，但经典循环智能体把长历史压缩进隐状态，难以保留细粒度任务证据；Transformer 方法虽能检索历史轨迹，却因二次复杂度导致内存和计算开销过高，限制长上下文任务推断与部署。现有方法还缺少在元测试阶段利用神经记忆进行测试时训练的能力，导致对未见任务族泛化不足。因此，如何在低训练预算下同时兼顾线性复杂度、长程任务推断与测试时适应，是该方向的关键瓶颈。

   - 结果：在未见过的 Meta-World ML10/45 测试环境中，METTA 在较低训练预算和较短墙钟时间下取得超过 50% 的成功率；在长上下文、稀疏奖励的 PointMaze 任务上，它优于 Transformer 基线并表现出更有结构的探索行为。实验还显示该方法在元测试阶段能利用测试时训练继续适应，而不仅是依赖训练分布内的快速适应。结果说明神经记忆为可扩展、可适应的长上下文元强化学习提供了高效路径。

   - 痛点：复杂地形上的人形机器人移动需要准确落脚和全身协调，但纯强化学习在缺乏运动参考时很难通过奖励设计和探索获得自然且鲁棒的全身协同；参考轨迹方法虽然动作自然，却受限于训练数据中的预设轨迹，难以适应新地形和接触变化。现有方法还缺少可显式预测未来接触并据此条件化控制的接口，导致感知、接触规划与全身控制彼此割裂。如何把运动数据只作为训练先验，同时保留 RL 在环境中的探索与适应能力，是当前人形机器人学习的关键痛点。
   - 方法：论文提出一个以接触为接口的学习框架：自监督注意力接触规划器从本体与环境观测预测未来身体-环境接触，接触条件化的跟踪器把这些接触计划转化为协调的全身运动；运动数据仅作为训练先验，策略学习的是接触感知的运动结构而非直接复制关节轨迹。随后通过微调阶段把学到的接触规划与跟踪能力用于探索原始运动数据未覆盖的地形变化。部署时仅依赖机载观测、无需参考输入，从而把接触规划、接触条件跟踪和强化学习微调统一起来。
   - 结果：在复杂地形上，该单一策略能够利用数据驱动的运动先验获得自然的全身协调，同时通过强化学习发现环境相关行为；微调后可在原始运动数据未覆盖的地形变化中继续提升适应性。实验覆盖多种复杂地形与接触条件，表明接触接口比直接轨迹跟踪或纯奖励探索更能兼顾自然性、鲁棒性和泛化。部署阶段完全依赖机载观测且不需要参考轨迹，展示了面向真实人形机器人移动的可行性。该结果支持将接触作为感知到控制的中间表示。

### 7. [AgentVQA: A Unified Benchmark for Agentic Visual Understanding](https://arxiv.org/abs/2610.31494v1)

- 来源：arXiv
- 关键词：agent, benchmark, reasoning, vision-language, THEM for reliable offline, adapting THEM for reliable
- 链接：<https://arxiv.org/abs/2610.31494v1>

**原始摘要**

Vision-language models (VLMs) can perform a broad range of tasks across diverse settings, yet their performance in agentic contexts remains poorly understood. Although online evaluations in simulators and real-world environments are essential for measuring interactive agent performance, they are costly and challenging to scale. Complementary offline VQA benchmarks can enable faster and more reliable comparisons across agentic domains, yet existing benchmarks remain limited and fragmented. To address this gap, we introduce AgentVQA, an offline benchmark for evaluating VLMs on realistic agentic scenarios across five agent domains: Web Agents, Robotics, Egocentric Videos, Games, and Spatial Planning. We build AgentVQA by manually selecting 1000 challenging, real-world agent examples from 23 source datasets and adapting them for reliable offline evaluation. The resulting benchmark preserves realistic scenarios from interactive environments across diverse domains, and its model rankings track those from corresponding online evaluations. Across the 22 evaluated models, the best achieves only 58.5% accuracy. Our cross-domain analysis shows that errors are driven primarily by failures to ground and maintain accurate representations of the current and evolving visual state, including localizing relevant UI elements, interpreting motion, tracking state changes over time, and inferring 3D spatial relationships, rather than by task misinterpretation or downstream logical reasoning.

### 8. [Training Small Language Models for Transferable Tool Selection](https://arxiv.org/abs/2610.31483v1)

**原始摘要**

As LLM agents operate over corpora of more than ten thousand tools, selecting the right tool for a complex multi-step user instruction becomes a central bottleneck.
