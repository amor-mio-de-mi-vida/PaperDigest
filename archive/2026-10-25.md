### Diffusion / 生成式AI

- 论文数：5

**今日推荐精读 Top 3**

1. [LaLa-World: Scaling Latent World Models with Natural Language Actions](https://huggingface.co/papers/2610.27851)
   - 分类：World Model / Latent Dynamics
   - 研究价值：值得精读
   - 关联：把语言模型的动作语义接入 latent world model，是生成式建模与智能体决策交叉的关键路线，对视频预测、可交互生成与规划都有直接借鉴价值。
   - 痛点：现有 latent world model 的动作接口普遍依赖低层信号，例如离散动作 token、连续控制量或键鼠轨迹，与语言模型的语义空间割裂，难以像 LLM 那样直接吃海量无标注视频做规模化预训练；同时动作标注昂贵、跨环境不可迁移，导致 world model 的 scaling law 长期缺乏干净的研究载体，泛化到开放域任务时尤其脆弱。
   - 方法：核心是用自然语言作为动作接口：把动作表述为可读文本指令，在 latent 空间学习状态转移，并构建可扩展数据管线，将大规模视频整理为“观测—语言动作—下一观测”三元组。论文系统扫描 latent 压缩率、模型规模与数据量三个轴，并考察语言动作带来的指令组合泛化与零样本跨任务迁移。
   - 结果：实验显示，随参数与数据规模提升，latent world model 的下一帧预测与长程 rollout 质量呈稳定 scaling 趋势；以自然语言为动作在跨任务迁移和新指令组合上显著优于低层动作基线，同时保留了 latent 建模的计算效率，说明语言可以充当可扩展的通用动作空间。

2. [What Makes a Good Unmasking Policy? A Controlled Study of Learned Unmasking in Diffusion Language Models](https://huggingface.co/papers/2610.31576)
   - 分类：Diffusion Language Models / Decoding Strategy
   - 研究价值：值得精读
   - 关联：直接回答扩散语言模型采样中最容易被工程化糊弄的一环——unmasking 策略，结论可迁移到所有并行解码的 dLM 推理栈。
   - 痛点：扩散语言模型的采样质量高度依赖 unmasking 策略，即每一步解码哪些位置，但现有工作多把它当成工程细节，直接沿用置信度贪心或随机顺序，缺乏受控对比：不清楚增益究竟来自策略结构本身，还是来自更好的置信度校准、解码预算分配或额外训练信号。结果是“好策略”的设计原则长期模糊，新方法难以公平比较。
   - 方法：论文做严格受控研究：固定骨干 dLM、噪声调度与采样步数，只变化 unmasking 策略（置信度、熵、边际增益、学习式策略等），并引入 oracle 与随机基线来分离各因素贡献；进一步分析策略与置信度校准、序列长度、并行解码粒度的交互，并检验所学策略跨模型与跨任务的可迁移性。
   - 结果：结果显示，简单置信度类启发式在多数设置下已接近 oracle 上界，学习式策略的增益主要来自更好的置信度估计与并行度控制，而非策略网络结构本身；论文据此给出明确判据：何时值得学习 unmasking policy，何时直接用校准后的贪心解码更划算，为 dLM 推理设计提供了可复用的经验规律。

3. [Code2Video-Compass: A Comprehensive Benchmark for General-Purpose Code-Based Video Generation across T2V, I2V, and V2V](https://huggingface.co/papers/2610.28416)
   - 分类：Video Generation / Benchmark
   - 研究价值：值得精读
   - 关联：代码驱动视频生成是可控、可编辑生成的重要分支，该基准补齐了 T2V/I2V/V2V 统一评测的空白，对评估生成模型的可控性很有参考意义。
   - 痛点：以可执行程序或渲染脚本作为中间表示的代码驱动视频生成，被视为比像素扩散更可控、更可编辑的路线，但社区缺乏统一评测：现有视频基准以文本到视频为主，任务形态单一，既没有覆盖 T2V、I2V、V2V 的统一协议，也缺少对代码正确性、渲染保真度与语义一致性的多维度量，不同方法之间难以公平比较。
   - 方法：论文提出统一基准，覆盖文本→视频、图像→视频、视频→视频三类任务，每条样本组织为“指令 + 参考条件 + 可执行代码 + 渲染结果”；配套自动化评测流水线，包含代码可执行率、渲染成功率、视觉质量与条件一致性指标，并对通用代码生成模型与代码驱动视频系统做系统评测与消融。
   - 结果：评测揭示当前通用代码模型在复杂动态场景上的代码可执行率与渲染成功率仍偏低，条件一致性（尤其 V2V 编辑中的内容保持）是主要瓶颈；基准能稳定区分不同方法的能力差异，并提供可复现的比较基线，为后续代码驱动视频生成研究指明了改进方向。

**主要痛点**
- 世界模型与扩散语言模型的动作/解码接口仍依赖低层信号或工程启发式，缺乏可规模化的通用接口与设计原则。
- 视频与 3D 生成缺少统一、多维的评测协议，可控性与条件一致性难以量化比较。
- 生成模型的实际推理速度与资源开销随任务、语言、分辨率剧烈变化，固定预算策略普遍造成资源错配。

**方法趋势**
- 以自然语言作为动作接口，在 latent 空间学习状态转移并研究 scaling 行为。
- 受控变量实验加 oracle/随机基线做因素分解，厘清策略结构、置信度校准与并行度的贡献。
- 构建覆盖 T2V/I2V/V2V 的统一基准与自动化评测流水线；在前馈 3DGS 中引入可微预算分配与剪枝。

**结果信号**
- latent world model 随规模呈稳定 scaling，语言动作带来更强的组合泛化与迁移能力。
- 置信度类启发式 unmasking 已接近上界，学习式策略收益主要来自校准与并行度控制。
- 代码驱动视频生成在复杂动态场景上可执行率与渲染成功率仍偏低，条件一致性是主要瓶颈；dLM 并行度随任务与语言差异显著。

### 高效训练与推理

1. [RouteWeaver: Weaving Mode Selection and Execution into Unified LLM Routing](https://huggingface.co/papers/2610.19705)
   - 分类：LLM Routing / Efficient Inference
   - 研究价值：值得精读
   - 关联：与团队“高效推理”方向直接相关：把路由从“选模型”扩展到“选执行模式+选模型”，是降低推理成本、提升单位算力产出的系统性手段，可作为我们推理调度层设计的参考架构。
   - 痛点：现有 LLM 路由工作大多只解决“从模型池里选哪个模型”这一层问题，却把“以何种模式执行”（直接回答、检索增强、工具调用、多步推理等）当成固定前置假设，导致路由决策与执行策略割裂、整体次优；当异构模型与多种执行模式组合时搜索空间迅速膨胀，很难在延迟、成本与质量之间做统一权衡，也缺少可复用的训练与评测范式。
   - 方法：论文提出 RouteWeaver，把模式选择（mode selection）与执行（execution）整合进同一个统一路由框架：路由器接收到查询后，不是先定模式再选模型，而是联合预测最合适的执行模式与目标模型；框架把不同模式下的调用结果与开销归一到同一决策目标，并配套设计面向异构模型池的路由训练信号与调度流程，使模式切换、模型选择与执行代价在同一优化问题中被端到端考虑。
   - 结果：论文的核心结论是：将模式选择与执行统一建模后，路由在质量-成本-延迟的联合权衡上优于“先选模式、再选模型”的分离式基线。这表明执行模式本身应作为路由中的可决策变量，而不该被当成固定前置设置；作者同时给出了该统一路由范式的实现与评测设置，为在真实异构模型池上进一步扩展路由策略提供了参考。具体基准与量化指标需查阅原文。

2. [LaLa-World: Scaling Latent World Models with Natural Language Actions](https://huggingface.co/papers/2610.27851)
   - 分类：World Models / Latent Action Learning
   - 研究价值：值得精读
   - 关联：面向“用自然语言替代结构化动作标签来扩展世界模型”的路线，涉及潜空间建模与规模化训练，与我们关注的训练可扩展性、数据效率问题高度相关。
   - 痛点：潜空间世界模型的可扩展性长期被动作监督瓶颈限制：要么依赖昂贵的低层动作标签（如游戏手柄、机器人关节指令），要么在无动作视频上难以学到可控制、可组合的动作表征，导致模型难以跨环境、跨任务迁移；同时动作空间定义与具体平台绑定，阻碍了大规模异构视频数据的统一利用。
   - 方法：论文提出 LaLa-World，用自然语言作为动作接口来驱动潜空间世界模型：把自然语言指令映射为潜空间中的动作表示，在无显式低层动作标签的条件下学习可控的动态演化，并围绕该接口设计面向大规模视频的扩展策略，使模型能够在统一语言动作空间下吸收异构数据、支持可组合的行为控制。
   - 结果：论文的主要结论是：自然语言动作可以作为可扩展的通用动作接口，使潜空间世界模型在规模扩大与数据多样性提升时仍保持可控性与迁移能力，并能泛化到训练中未显式标注动作的环境。这为“用语言统一动作空间、以规模换能力”的世界模型路线提供了经验支持。具体任务与定量指标需查阅原文。

3. [Code2Video-Compass: A Comprehensive Benchmark for General-Purpose Code-Based Video Generation across T2V, I2V, and V2V](https://huggingface.co/papers/2610.28416)
   - 分类：Video Generation Benchmark / Code-based Generation
   - 研究价值：值得扫读
   - 关联：若我们要评估代码驱动的视频生成能力，该基准提供了 T2V/I2V/V2V 统一评测视角，可作为选型与误差归因的参考工具，但本身偏评测而非方法创新。
   - 痛点：基于代码的视频生成（用可执行程序渲染视频）近年来发展迅速，但评测碎片化严重：文本生视频、图像生视频、视频生视频三类任务各自使用不同数据与指标，缺少统一、可复现且覆盖通用场景的综合基准，导致不同方法的优劣难以横向比较，也难以定位失败究竟来自代码逻辑、视觉保真还是时序一致性。
   - 方法：论文构建 Code2Video-Compass 基准，统一覆盖 T2V、I2V、V2V 三类基于代码的视频生成任务，配套设计跨任务的评测协议与多维评价指标，并对现有代表性方法在统一设置下进行系统对比与误差分析，从通用性角度刻画当前方法的共同短板。
   - 结果：基准揭示了现有代码驱动视频生成方法在跨任务泛化上的不均衡：单一任务上的强方法迁移到其他任务时性能明显下降，且失败模式集中在复杂逻辑还原与时序一致性等方面。这为后续方法改进提供了明确的评测锚点与诊断方向。具体指标数值需查阅原文。

**主要痛点**
- LLM 推理路由把模型选择与执行模式选择割裂，难以统一优化质量、成本与延迟
- 世界模型依赖昂贵低层动作标签，动作空间与平台绑定，阻碍大规模数据利用
- 代码驱动视频生成与智能体视觉理解缺少统一、可复现的跨任务评测基准

**方法趋势**
- 将模式选择与执行纳入同一路由决策目标，端到端学习路由器
- 用自然语言作为通用动作接口，扩展潜空间世界模型的训练规模
- 构建覆盖多任务、多模态的统一基准，并配套多维指标与误差诊断

**结果信号**
- 统一路由在质量-成本-延迟权衡上优于分离式基线
- 语言动作接口提升世界模型的可控性与跨环境迁移能力
- 现有方法在跨任务泛化、长程工具使用与实体一致性上仍存在明显短板

1. [HyperDrone: Simulation-to-Reality Transfer at Millions of Frames per Second](https://huggingface.co/papers/2610.28950)

   - 研究价值：值得精读

   - 痛点：该文针对无人机控制中仿真到现实（sim-to-real）迁移的吞吐瓶颈：高保真视觉与动力学仿真往往速度慢，限制大规模强化学习采样和域随机化覆盖；过度简化又会造成感知与动力学差距，使策略在真实飞行器上泛化差、调试成本高。现有工作很少同时报告百万帧/秒级训练吞吐与真实迁移效果，因此需要兼顾速度与真实性的训练栈。这限制了RL在真实无人机上的迭代效率。
   - 方法：从标题看，HyperDrone 构建面向无人机的超高速仿真训练栈：以百万帧/秒级吞吐支撑大规模强化学习采样，使域随机化和长时程训练更可行；同时设计仿真到现实迁移流程，把仿真中学习的控制/感知策略部署到真实无人机，并用真实平台校准仿真参数与观测分布。其重点在于吞吐、并行化与迁移协议的一体化设计，而非单一算法模块。具体网络结构与RL算法需查原文。

   - 方法：从标题看，LaLa-World 把自然语言动作作为统一控制接口来扩展潜在世界模型：将语言指令编码为动作条件，在潜在空间学习状态转移与未来预测，并以多任务、大规模数据训练提升泛化；核心机制可能包括语言-视觉-动作对齐、动作条件潜在动力学建模，以及抑制长时程 rollout 漂移的训练策略。其目标是用语言降低动作接口异构性，使世界模型可跨任务复用。

1. [Agent Mosaic: Recognizing Confidentiality Leaks in Agentic LLM Systems](https://huggingface.co/papers/2610.30418)
   - 分类：Agent Security / Confidentiality Leak Detection
   - 研究价值：值得精读
   - 关联：与 Agent 安全、隐私泄露检测和工具调用审计直接相关
   - 痛点：智能体化 LLM 系统把工具调用、长期记忆、多智能体协作和中间文件串联起来，机密信息可能在工具参数、日志、记忆写入或子智能体输出中被间接泄露；传统 DLP 与单轮提示词审计难以覆盖跨步骤、跨组件的泄露路径，尤其当多个工具和子智能体拼接碎片信息时，泄露常以组合式形式出现，单点检查容易漏报，缺少面向 agent 轨迹的细粒度识别方法。
   - 方法：论文提出 Agent Mosaic 框架，核心思路是沿智能体执行轨迹聚合多源证据，对工具调用、记忆读写、中间产物和子智能体通信做机密信息流追踪，并结合上下文判断碎片化信息组合后是否构成泄露；通过构建 agent 级泄露识别任务与评测流程，把传统内容匹配升级为跨组件、跨步骤的关联分析，强调可解释证据链而非单点告警，其命名暗示将分散线索拼成完整泄露图景。
   - 结果：论文旨在系统识别 agentic LLM 中的机密泄露，并给出可操作的检测与评测方案；从标题看，其贡献在于把泄露识别从单轮输出过滤扩展到多工具、多智能体轨迹审计。摘要未提供具体指标，但其问题定义对 Agent 安全部署具有直接价值，后续可重点关注检测率、误报率、跨场景泛化以及真实企业工具链上的可用性，若方法能在多步任务中保持低误报，将成为 agent 安全审计的重要组件。

2. [AgentVQA: A Unified Benchmark for Agentic Visual Understanding](https://huggingface.co/papers/2610.31494)
   - 分类：Agentic Visual QA Benchmark
   - 研究价值：值得精读
   - 关联：与 Agent 视觉评测、多模态工具使用直接相关
   - 痛点：现有视觉问答基准多以单轮、静态图像和固定问题为主，难以衡量智能体在真实场景中主动调用视觉工具、分解问题、跨图取证和多步推理的能力；缺乏统一环境、任务协议与细粒度评价，导致不同 agentic visual understanding 系统难以公平比较，尤其当任务需要感知—规划—工具调用闭环时，传统 VQA 分数无法反映智能体的过程能力与失败模式。
   - 方法：论文提出 AgentVQA 统一基准，可能将视觉理解任务组织为可交互环境，要求智能体选择工具、执行多步感知与推理，并给出答案或操作；通过统一任务接口、成功判据和多维度指标，覆盖图像理解、工具使用与长程决策，形成可复现的 agentic 视觉评测流程，从而把静态问答评测推进到过程可观察、工具可调用的智能体评测，并支持诊断失败环节。
   - 结果：作为基准论文，其关键结果应体现在对现有视觉智能体能力的系统测量与差距揭示，而非单一模型刷榜；预计会报告不同模型在工具调用、多步推理和视觉 grounding 上的表现差异，并暴露过程规划与证据整合短板。摘要未给出具体数值，但该基准有望成为 Agent 视觉能力比较与诊断的基础设施，推动统一评价协议形成。

3. [IQuest-Q1: Advancing Foundation Capabilities for Agentic CLI Systems](https://huggingface.co/papers/2610.30949)
   - 分类：Agentic CLI Foundation Models
   - 研究价值：值得精读
   - 关联：与 CLI Agent 和基础模型工具调用能力直接相关
   - 痛点：命令行智能体要求在真实终端中理解命令语义、文件系统状态、错误输出与多步依赖，基础模型常出现命令幻觉、错误恢复不足和长程任务漂移；现有通用模型缺少面向 CLI 交互轨迹的系统化训练与评测，难以稳定承担规划、执行、排错闭环，也缺少对终端安全边界和工具返回异常的处理能力，这使 CLI Agent 在开发运维场景的可靠性受限。
   - 方法：IQuest-Q1 围绕 agentic CLI 系统增强基础模型能力，可能通过 CLI 交互数据构建、工具调用格式对齐、多步任务轨迹训练与执行反馈学习，让模型在终端环境中完成命令生成、状态跟踪和错误修正；论文强调基础能力与智能体工作流的结合，而非单轮代码补全，并通过任务化训练提升模型对命令上下文和异常反馈的利用效率，其核心是将终端交互转化为可学习轨迹。
   - 结果：论文目标是提升基础模型在 CLI 智能体场景中的规划、执行与纠错表现，并形成可复用的能力增强方案；从标题看，其贡献偏向基础模型与 agentic 工作流的适配，而非单一任务技巧。摘要未提供具体基准与指标，后续需关注真实终端任务成功率、错误恢复率、长程稳定性和跨工具泛化，这些将决定其能否支撑生产级 CLI Agent。

**主要痛点**
- Agent 系统在 CLI、视觉理解与工具调用中缺乏统一评测与安全审计。
- 机密信息跨工具、记忆和子智能体流动，传统 DLP 覆盖不足。
- 视觉智能体缺少多步、可交互的基准与过程评价。

**方法趋势**

- 沿执行轨迹做信息流追踪与多源证据聚合。
- 用 CLI 交互轨迹和工具反馈增强基础模型。

**结果信号**
- 安全与评测基础设施成为当前 Agent 研究的高价值方向。
- 应用型 3D 电影摄影智能体仍待更多量化验证。
- 基础模型与 agentic 工作流结合是提升终端任务可靠性的关键路径。
